## 3. 📋 AI coding tool changelogs

*Cutoff: anything published after the 06-03 briefing (Claude Code v2.1.161; Codex `rust-v0.137.0-alpha.4`).*

### Claude Code ([changelog](https://code.claude.com/docs/en/changelog))

**v2.1.162 — June 3** (heavy QoL / fix release, ~25 items)
- 🆕 ⭐ **`claude agents --json` now includes `waitingFor`** — script-readable reason a session is blocked (e.g., permission prompt). Solves "why is my background migration session stalled" from a bash loop.
- 🆕 ⭐ **`--tools Grep`/`--tools Glob` no longer silently ignored on native builds with embedded search** — explicit listing now provides the dedicated search tools. Subagent definitions that wired tool allowlists tightly were probably dropping these without telling you.
- 🆕 **`/effort` confirms when your chosen level will persist as default** — fewer accidental quiet upgrades to `xhigh`.
- 🔧 **Clicking a slash-command in autocomplete fills it into the prompt** instead of immediately executing; Enter to run. Hits the "I just wanted to read the docs" muscle memory.
- 🐛 ⭐ **WebFetch permission rules now apply to built-in preapproved domains** — explicit `WebFetch(domain:…)` deny/ask/allow rules take precedence over the preapproved-host auto-allow. If your `.claude/settings.json` had a security-driven deny for `*.amazonaws.com` or similar, it was being silently ignored — verify it now bites.
- 🐛 ⭐ **MCP per-server `timeout` values below 1000 ms were being floored to a 1-second watchdog that aborted every tool call**; sub-1s values now fall back to `MCP_TOOL_TIMEOUT` and `claude mcp get` annotates them. If you'd set tight latency budgets on a local MCP server and seen "every call fails," this was it.
- 🐛 **Windows permission rules never matching when spelled with backslashes** (`~\`, `\\server\share`) or case-variant paths, and **Read deny rules not hiding files from Glob/Grep results** — both fixed. Real policy-bypass class for the Windows-side platform team.
- 🐛 **Silent startup hang when config dir is read-only or unwritable** — now starts with in-memory config and surfaces the error. Fixes the "blank screen" report from CI sandbox runs.
- 🐛 **LSP `workspaceSymbol` returning no results** — now accepts a `query` parameter and forwards it. Symbol search via LSP was broken; re-enable in agent definitions if you'd disabled it.
- 🐛 Several `claude agents` UX fixes: status text truncated at 60–120 cols on wide terminals, name column capped at 40, attach bouncing back to list, Ctrl+V image paste no-op in dispatch input.
- 🐛 Cross-session `SendMessage` silently breaking when `CLAUDE_CODE_TMPDIR`/`$TMPDIR` points at a deep path — fixed.
- 🐛 API 400 `no low surrogate in string` errors for emoji near a truncation boundary in classifier/MCP descriptions — fixed.
- 🔧 **Renames Windsurf → Devin Desktop** across `/ide`, `/terminal-setup`, `/scroll-speed` after the editor's rebrand.
- 🔧 Quieter startup (notices group by severity; warnings shorter with concrete fixes; failed turns show a compact warning line, not a multi-line red block).

## 4. 🛠️ Claude Code & MCP ecosystem (community, deep dive)

**`Piebald-AI/claude-code-system-prompts` is the most undervalued read-only audit asset in the ecosystem** ([repo](https://github.com/Piebald-AI/claude-code-system-prompts)). Decompiled npm bundle → all 27 builtin tool descriptions, sub-agent prompts (Plan/Explore/Task), and utility prompts (CLAUDE.md, compact, statusline, magic docs, WebFetch, Bash cmd, security review, agent creation), updated within minutes of each release. CHANGELOG covers 196 versions since v2.0.14, current at v2.1.161. **Two concrete uses**: (a) when v2.1.162's `WebFetch` permission-precedence behavior surprises you, read the actual WebFetch tool prompt and you'll find the auto-allow list verbatim; (b) when writing a custom agent, copy the Explore/Plan/Task prompts as a structural reference rather than inventing one. Pairs with the [tweakcc](https://github.com/tweakcc/tweakcc) overlay that lets you patch individual prompt files. Compliance-side: this is the only public source-of-truth for what Claude Code is actually telling the model on your behalf.

**Pragmatic Engineer's ["New trend: programming by kicking off parallel AI agents"](https://newsletter.pragmaticengineer.com/p/new-trend-programming-by-kicking) is the cleanest synthesis of the parallel-subagent norm.** Gergely's take: only senior+ engineers use it productively so far; **Anthropic engineer Sid Bidasaria** named it as his daily mode; **Armin Ronacher pulled back** ("only so much my mind can review"). Direct read for the migration: Boris Cherny (per the Pragmatic Engineer deep-dive) **ships 20–30 PRs/day running 5 parallel Claude instances** — that is now the public benchmark for what "good" looks like with the worktree-per-subagent pattern covered 06-03. Useful counterweight when planning the cadence of the Angular migration runs.

**Perplexity's [Bumblebee](https://github.com/perplexityai/bumblebee)** (open-sourced May 22; growing fast — flagged in the 06-04 round-up of trending repos but not previously covered here) — read-only supply-chain scanner that treats **`.claude/`, `.cursor/`, `.windsurf/` MCP configs as a security surface** alongside lockfiles and IDE extensions. Pure Go, zero non-stdlib deps, Apache 2.0. Covers eight package ecosystems plus MCP configs and Chromium/Firefox extensions. Direct fit for our pre-commit + audit pipeline: when v2.1.161 redacted `claude mcp list/get/add` secrets (06-03 briefing), Bumblebee is the complementary "what MCP servers are even installed on this dev's laptop" baseline. Install once on a representative laptop; treat its output as the inventory side of the MCP audit story.

**MCP spec movement (procedural note):** the [2026-07-28 release candidate](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) flagged 06-03 has had no new dot-revision since; conformance items unchanged.

## 8. 🎯 One thing to try today (≤30 min)

**Verify v2.1.162 actually enforces your `WebFetch` deny rules and your sub-1s MCP timeouts** — both were silently broken before today.

```bash
npm update -g @anthropic-ai/claude-code && claude --version   # expect 2.1.162

# 1. Add an explicit WebFetch deny for a preapproved host and confirm it bites:
#    (edit .claude/settings.json — under "permissions": { "deny": [...] })
#       "WebFetch(domain:docs.aws.amazon.com)"
#    Then in a session:
claude
> /tools
> Use WebFetch on https://docs.aws.amazon.com/...
# Expect: denied. Pre-v2.1.162 this would silently fetch.

# 2. Inspect any MCP server you'd set a tight timeout on:
claude mcp get <server-name>
# Look for the annotation flagging sub-1s values being ignored.
# If you'd set timeouts < 1000ms expecting fast failure, raise them deliberately
# now that the watchdog floor is gone.

# 3. Bonus — script-readable session-blocked-reason for the overnight migration cron:
claude agents --json | jq '.[] | {name, status, waitingFor}'
```

If the WebFetch deny rule didn't bite, the rule was previously a no-op. The MCP-timeout annotation is the first time you can tell from the config inspector that a timeout was being silently floored.
