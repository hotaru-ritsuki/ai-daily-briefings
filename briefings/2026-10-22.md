## 📋 3. AI coding tool changelogs (since 2026-10-21 briefing)

**Claude Code** — [docs changelog](https://code.claude.com/docs/en/changelog) (2.1.307 and 2.1.308 are new; page shows no dates; first ~100k chars read via summarizer):

**2.1.308** — 🐛 "bug fixes and reliability improvements" only.

**2.1.307**
- ⭐ 🐛 **HTTP MCP calls no longer double-sent** when the connection drops mid-call; only read-only/idempotent tools are retried. Matters for any MCP tool with side effects.
- ⭐ 🐛 MCP servers no longer marked failed/timed out in headless runs after the machine sleeps while connecting, and in `claude -p` on macOS a locked keychain now yields a clear reason instead of "needs authentication". Helps scheduled/headless runs.
- ⭐ 🆕 **`claude_code.safety_event` OpenTelemetry event** emitted whenever a permission rule, auto mode, safety check, hook or the sandbox stopped/prompted/redirected a tool call — an audit trail for how often your guardrails fire.
- ⭐ 🔧 Fork subagents launched together are told which launch is theirs; unparseable tool calls retry up to twice before the turn errors.
- 🆕 `/claude-api api-version` migrates API code to API version `2026-10-21`; `@claude review stop|off|pause` ends an `@claude review always` subscription on a PR.
- 🐛 `CLAUDE_CODE_DISABLE_1M_CONTEXT` no longer breaks `opus[1m]`-style aliases; `prompt-caching-scope` beta header no longer sent behind custom gateways; "Autocompact is thrashing" reduced for turns reading many PDF pages/images.
- 🔧 Self-hosted runner checkout hooks now stop after 30 min by default (`--checkout-hook-timeout-min`) — ⚠️ only if you run self-hosted runners. VS Code/cloud-session items omitted.

## 🎯 8. One thing to try today (≤30 min)

**Find which of your MCP tools are unsafe to retry, and watch your guardrails with the new OTel event.**
1. `claude update` (≥2.1.308), then `claude mcp list`.
2. For each server, list tools that write (create issue, post comment, send message). Those are the ones that were exposed to duplicate sends before 2.1.307; 2.1.307 now retries only read-only/idempotent tools, so make sure read-only tools are annotated as such by the server.
3. Enable telemetry to a local collector, e.g. `export CLAUDE_CODE_ENABLE_TELEMETRY=1 OTEL_LOGS_EXPORTER=console`, run a normal session, and count `claude_code.safety_event` entries — each one is a permission/sandbox/hook intervention. If a rule fires constantly, it's a candidate for allowlisting or a hook.
(Env var names are from memory of the Claude Code monitoring docs, not this changelog; verify before relying on them.)
