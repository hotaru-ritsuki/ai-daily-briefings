## 3. 📋 AI coding tool changelogs

**Claude Code — v2.1.280 (Sep 22)** ([changelog](https://code.claude.com/docs/en/changelog))
- ⭐🆕 **Opus 5.5 added and set as default Opus** (1M ctx, $4/$20, $0.20 cache reads). Also: **default model on Pro/Team Standard moved Sonnet→Opus**, matching higher tiers — check `/status` if you budget by model. Why it matters: your CC sessions silently upgraded; verify effort level (a pre-`/effort`-per-model saved level no longer carries to new models like Opus 5.5 — it starts at its default).
- ⭐🐛 **Symlink-write security fix:** writes through a symlinked path were judged by their in-tree spelling, so `acceptEdits`/allow-rules/auto-mode could approve a write that actually **lands outside the tree**. Now the prompt names the real target. Relevant to your permissioned auto-mode workflows.
- ⭐🔧 **Auto-mode retry hardening:** actions a safety check declined to review are now denied once (no infinite retry), and unanswered checks back off and stop after 10 in a row — fewer runaway loops.
- 🆕 `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` overrides the 2,048-char cap on MCP tool descriptions/server instructions — useful if a JetBrains/DB server's tool docs were being truncated.
- 🔧 [VSCode] added typed `/skills`, `/plan`, `/sandbox`, `/chrome`, `/status`, `/export` dialogs; plan-approval card now offers "Yes, and use auto mode."
- 🐛 Large stability batch: fixes for the `role 'system' must precede assistant` and `advisor_20260301` proxy 400s, resumed-session crashes, and prompt-cache misses on host-app model switches.

Meanwhile remote OAuth-secured servers (GitHub, Vercel, Linear, Supabase, Stripe) are the 2026 default over local stdio ([WorkOS](https://workos.com/blog/everything-your-team-needs-to-know-about-mcp-in-2026)).

## 8. 🎯 One thing to try today (≤30 min)

**Re-baseline your cost on Opus 5.5 before you assume the price cut is free money.** The cache-read drop ($0.50→$0.20) only pays off if your sessions actually hit cache. Do this:

```bash
claude update           # ensure ≥ 2.1.280
claude
/model                  # confirm Opus 5.5 is selected (now default)
# run one representative task on a real repo, then:
/cost                   # note cache-read % and total; the new /cost names thinking-mode cache-miss causes
```

If cache-read % is low, your CLAUDE.md or MCP tool descriptions are probably churning the prefix — trim them (and note the new `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` cap). Ten minutes of measurement tells you whether to move CI/triage traffic to GPT-6 Luna and keep Opus for the hard tasks.
