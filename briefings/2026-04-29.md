## 8. 🎯 One thing to try today (≤30 min)

**Extract your legacy app's design system with `design-extract` and generate migration-ready tokens.**

```bash
# 1. Install the MCP server
npx @anthropic-ai/claude-code mcp add design-extract -- npx @manavarya09/design-extract

# 2. Or use the CLI directly
npx @manavarya09/design-extract https://your-legacy-app.internal --output ./design-tokens

# 3. Outputs: DTCG tokens, Tailwind v4 config, Figma variables, shadcn/ui theme
# 4. Feed the tokens into your Angular 18 component library as a migration baseline
```

This bridges the "how do we ensure visual parity?" gap in your AngularJS → Angular 18 migration. Instead of manually auditing CSS, you get a machine-readable design system from the running legacy app that you can diff against the new build.
