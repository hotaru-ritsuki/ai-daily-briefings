## 4. 🛠️ Claude Code & MCP ecosystem (community)

- **AWS Labs expanded its database MCP coverage** with new **MSSQL and Oracle MCP servers for RDS**, plus an **AWS Security Agent MCP server**, in the June `2026.06` train ([awslabs/mcp](https://github.com/awslabs/mcp)). For the Spring Boot data layer this is the cleanest path to letting Claude Code introspect schema/queries against a managed Oracle/MSSQL instance without a hand-rolled JDBC tool — and it's first-party AWS, which matters for the MRM supply-chain conversation.
- **[sunnamed434/awesome-mcp-registry](https://github.com/sunnamed434/awesome-mcp-registry)** — an AI-curated, **weekly self-updating** MCP directory that discovers servers from GitHub + the official registry and scores each with a transparent **0–100 trust score** (AI rubric + verifiable metrics). Useful as a vetting front-door before adding any community MCP server to a financial-services config — i.e. a defensible "we checked supply-chain provenance" artifact.
- **SubagentStop hook now carries `hookSpecificOutput.additionalContext`.** The 2026 payload lets a SubagentStop hook *extend* a subagent's turn with new context instead of treating completion as a binary pass/fail ([pattern writeup](https://www.mindstudio.ai/blog/claude-code-agentic-workflow-patterns)). Concretely: a leaf migration subagent that finishes without running the component's spec can be sent back with the failing test names injected, rather than bubbling up an error. Worth wiring into the migration subagent tree.

## 9. 📣 Shareable angle

**Hook:** "Microsoft made its SRE agent 30 points more accurate not by adding tools — by deleting 100 of them."

**Draft:** Microsoft's Azure SRE Agent team lifted its "Intent Met" score from 45% to 75% on novel incidents by replacing 100+ bespoke tools with a plain filesystem the agent greps and reads — because frontier models were trained on exactly that workflow. The lesson for anyone wiring MCP servers onto a coding agent: every narrow tool you add is context you're spending and a path you're constraining; sometimes the highest-leverage move is to expose the codebase as files and get out of the way.
