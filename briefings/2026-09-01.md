## 8. 🎯 One thing to try today (≤30 min)

**Trial the GSD context-rot pattern from the community fork on one real task.** It's the fastest way to feel whether atomic-plan-in-fresh-context actually keeps your main session lean vs. your hand-rolled plan files:

```
npx get-shit-done-cc@latest    # or clone the fork: github.com/open-gsd/get-shit-done-redux
```

Read the installed slash commands first (it's a prompt/command system, not magic), then run a multi-step task — a migration slice or a Playwright scaffold — and watch your main-session context stay low while subagents burn theirs. *Alt (≤10 min):* if you run Codex, `codex upgrade` to 0.152.0 and set a per-tool output cap on your noisiest MCP server (§3) — the tightest single win this window.
