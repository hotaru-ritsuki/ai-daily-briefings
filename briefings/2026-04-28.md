## 4. 🛠️ Claude Code & MCP ecosystem

- **Fork subagents** are the headline community feature. The `CLAUDE_CODE_FORK_SUBAGENT=1` flag makes children inherit the parent's full conversation and share its prompt cache prefix. Practical impact: for five parallel subagents working on the same codebase, total input tokens drop from ~244K to ~89K. This is the single biggest cost lever for parallel workflows ([buildthisnow.com](https://www.buildthisnow.com/blog/guide/mechanics/claude-code-fork-subagent), [claudefast](https://claudefa.st/blog/guide/agents/sub-agent-best-practices)).

Note: SSE endpoint deprecated after June 30; point clients to `https://mcp.atlassian.com/v1/mcp` ([Atlassian blog](https://www.atlassian.com/blog/announcements/atlassian-rovo-mcp-ga)).

- **Anthropic published official subagent guidance**: rule of thumb is 10+ files or 3+ independent pieces of work → use subagents ([claude.com/blog](https://claude.com/blog/subagents-in-claude-code)).

## 8. 🎯 One thing to try today (≤30 min)

**Enable fork subagents and benchmark the token savings on a real task.**

```bash
# 1. Upgrade to latest
claude --upgrade  # confirm 2.1.121

# 2. Enable fork subagents
export CLAUDE_CODE_FORK_SUBAGENT=1

# 3. Open Claude Code in your migration repo and try a parallel task:
#    "Refactor these 5 AngularJS services to Angular 18 injectables,
#     using one subagent per service. Work in parallel."

# 4. Check /usage after — compare input tokens against what you'd
#    expect without fork (hint: should be dramatically lower)
```

Fork subagents share the parent's prompt cache prefix, so children 2–N pay a fraction of the input cost. For your AngularJS→Angular migration where you're touching many files with shared context, this is the single biggest cost reduction available.
