## 3. 📋 AI coding tool changelogs

_Cutoff: entries after 2026-05-07 (v2.1.132 and Codex 0.129.0-alpha.14, the last versions covered)._

### Claude Code — 2.1.133 (May 7) ([changelog](https://code.claude.com/docs/en/changelog))

- 🆕 ⭐ **`worktree.baseRef` setting** (`fresh` | `head`) — controls whether `--worktree`, `EnterWorktree`, and agent-isolation worktrees branch from `origin/<default>` or local `HEAD`. ⭐ *Set to `head` for migration branches where you need subagents to see unpushed work.*
- 🆕 ⭐ **Hooks receive effort level** via `effort.level` JSON field and `$CLAUDE_EFFORT` env var. ⭐ *Gate expensive pre/post-tool hooks (e.g., lint, type-check) to only run at `high`+ effort.*
- 🆕 `sandbox.bwrapPath` and `sandbox.socatPath` managed settings (Linux/WSL).
- 🆕 `parentSettingsBehavior` admin key (`first-wins` | `merge`).
- 🔧 Improved focus mode behavior; memory released from warm-spare workers under pressure.
- 🐛 ⭐ **Fixed subagents not discovering project, user, or plugin skills.** ⭐ *If your subagents couldn't find custom skills, this is the fix.*
- 🐛 Fixed parallel sessions 401 after refresh-token race, `/effort` in one session changing others, `Edit`/`Write` allow rules scoped to drive root, MCP OAuth not respecting `HTTP(S)_PROXY`/mTLS, network drive Read/Write/Edit, Remote Control stop not fully canceling.

### OpenAI Codex CLI — 0.129.0 stable (May 7) ([releases](https://github.com/openai/codex/releases))

The Rust rewrite shipped as a stable release. Highlights:

- 🆕 ⭐ **Modal Vim editing** in the composer (`/vim`, configurable default mode). ⭐ *Claude Code added vim mode in 2.1.118; Codex now matches.*
- 🆕 Redesigned resume/fork picker, raw scrollback mode, `/ide` context injection, workspace-aware `/diff`.
- 🆕 Plugin workspace sharing with access controls, marketplace removal/upgrades, remote bundle sync.
- 🆕 Hooks browsable via `/hooks`, support before/after compaction and `PreToolUse` context injection.
- 🐛 Linux sandbox reliability across older `bwrap`, symlink-protected paths; Windows ConPTY/PowerShell fixes.
- 🔧 Vendored Bubblewrap updated to 0.11.2 (security); standalone `bwrap` fallback for npm/DotSlash.

Pre-releases `0.130.0-alpha.1` through `alpha.4` (May 7–8) have no published notes.
