## 8. 🎯 One thing to try today (≤30 min)

**Today: demote Fable 5, update to Claude Code v2.1.178, and exercise the new `Tool(param:value)` permission primitive on your migration agents.** This is the rollback for the 06-11 §8 experiment.

```bash
npm update -g @anthropic-ai/claude-code && claude --version   # expect 2.1.178

# 1. Reverse the Fable 5 pin from 06-11 in .claude/settings.json:
#    "model": "claude-opus-4-8",
#    "fallbackModel": ["claude-sonnet-4-6", "claude-haiku-4-5"]
# Remove "claude-fable-5" entirely — the auto-fallback works, but explicit is safer.

# 2. Add parameter-scoped permission rules to the migration-sweeper agent
#    (new in v2.1.178). E.g. deny the agent from spawning Opus subagents
#    but allow Sonnet/Haiku, so the orchestrator's budget stays predictable:
cat >> .claude/settings.json <<'EOF'
{
  "permissions": {
    "deny": [
      "Agent(model:opus*)",
      "Bash(command:rm -rf*)",
      "Bash(command:git push --force*)"
    ]
  }
}
EOF

# 3. Sanity-check that nested .claude/skills/ resolution works for the
#    monorepo-with-features layout (also new in v2.1.178):
mkdir -p src/app/features/portfolio/.claude/skills
# drop a portfolio-specific verification skill there; confirm /plugin list
# shows it as "portfolio:verification" alongside the root-level one.

# 4. Check the Agent-SDK credit-pool ledger from yesterday's go-live:
claude status --usage   # expect a separate "Agent SDK" line item

# 5. While you're here: try Codex's /import path against your .claude/
#    config — first vendor-built migration utility, worth a 5-min test
#    even if you don't switch:
codex --version              # expect rust-v0.140.0
codex /import claude-code
```

The reason to do this today: the Fable 5 demotion is *required* if you pinned it last week; the `Tool(param:value)` rules are the first real *parameter-scoped* security primitive Claude Code has shipped; and the Agent-SDK credit pool is now actually billing. Three things, one update.
