## 4. 🛠️ Claude Code & MCP ecosystem (community deep-dive)

The community signal today is **portable, role-structured skill/agent bundles converging on the same shape** — a lifecycle of specialized agents (plan/implement/review/debug) with quality gates between them, packaged to run across CC, Codex, Cursor and Copilot.

- **[mubaidr/gem-team](https://github.com/mubaidr/gem-team)** is the sharpest example: role-specific agents + *risk-based* gates (cheap tasks get light verification, HIGH-complexity tasks get the full TDD + review treatment), resumable plans with persistent IDs, and intelligent model routing. The explicit framing — "40–60% less context per task through scoped handoffs" + prompt caching for ~10× cost reduction — is exactly the context-budget discipline worth stealing even if you don't adopt the whole framework.
- **[0xDarkMatter/claude-mods](https://github.com/0xDarkMatter/claude-mods)** (51★, MIT) bundles 112 skills (TypeScript/React/Vue/Next.js, PostgreSQL/SQL, Docker/K8s/Terraform) plus `/save` and `/sync` commands for session continuity, and — more interesting — **hooks for supply-chain defense and prompt-injection detection** as deterministic safeguards. The prompt-injection/supply-chain hooks are the governance primitive to look at if you run CC against untrusted dependencies.
- **[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)** (widely starred; star figure looked inflated on fetch, treat as directional) packages senior-engineer workflows as skills across the lifecycle: `spec-driven-development`, `test-driven-development`, `context-engineering`, `frontend-ui-engineering`, `api-and-interface-design`, `code-review-and-quality`. This is the rare skill set aimed at app engineers in your stack, not Python data work — the companion to Osmani's "Code Agent Orchestra" essay covered Oct 4.
- **Spring Boot → Quarkus via Agent Skills** surfaced again (Quarkus published a walkthrough of migrating whole Spring Boot apps with Claude Code + migration Skills installed via `npx`). Primary page is egress-blocked here (see Run notes), but the pattern — deterministic migration packaged as a skill — is directly relevant if you ever touch Quarkus.

## 8. 🎯 One thing to try today (≤30 min)

Clone **addyosmani/agent-skills** and wire two skills into one of your Angular/TS repos:

```bash
git clone https://github.com/addyosmani/agent-skills
mkdir -p ~/.claude/skills
cp -r agent-skills/skills/test-driven-development ~/.claude/skills/
cp -r agent-skills/skills/code-review-and-quality ~/.claude/skills/
```

Then run `/test-driven-development` on a small feature and let the `code-review-and-quality` skill gate the diff. You're testing whether a *packaged* senior-engineer skill beats your ad-hoc prompting — and it costs you one feature's worth of time to find out. (Sibling move: try CC 2.1.292's new Agent-tool `effort` param to run that review subagent at lower effort and compare quality.)
