## 📋 3. AI coding tool changelogs (since 2026-10-22 briefing)

**Claude Code** — [docs changelog](https://code.claude.com/docs/en/changelog) (2.1.308 and 2.1.309, both dated Oct 22; 2.1.308 was already covered as bug-fix-only; page read via summarizer, first 100k chars):

**2.1.309**
- ⭐ 🐛 **Sandbox hardening**: Bash startup files no longer run outside the sandbox; macOS `denyWrite` globs now work through symlinks; sandboxed commands can't edit the `--mcp-config` file; Linux write denies no longer lift when a background command outlives the session. Matters if you rely on the sandbox for unattended runs.
- ⭐ 🐛 **Permission-check fixes**: compound `cd … && git` commands now prompt properly, an `Edit(path)` deny rule now also blocks a Bash redirect to that path in subshell cases, and a disabled MCP server is no longer reconnected by a later prompt in print/SDK sessions.
- ⭐ ⚠️ `claude ultrareview` now requires workspace trust; in scripts/CI pass `--trust-workspace` (or set `CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1`) or it refuses.
- ⭐ ⚠️ `sed -i` now gets the normal Bash prompt and runs as written, and is no longer undone by `/rewind`.
- ⭐ 🔧 In bypass-permissions mode (Desktop/VS Code), dangerous `rm`/`rmdir` are now denied immediately with a rewrite hint instead of prompting, so unattended sessions keep going; commands excluded from the sandbox ask before writing to its write-list paths when the sandbox can't run.
- 🔧 Worktree creation no longer fetches git objects on demand (partial clones fetch first); worktree-isolation guard fixes for zsh arithmetic and locale-prefixed commands.
- 🔧 `/claude-api` skill: Managed Agents subagent teams now built on `multiagent_20261001` with dynamic workflows on by default instead of `coordinator`; adds API tracing and OTel destination management via service account keys.
- 🐛 Split-pane agent teammates now inherit the leader's `--tools`/deny rules; repeated compaction after reading a very large nested CLAUDE.md fixed (oversized files now load only their start); Claude no longer writes role names as `@mentions` that notify real GitHub users.
- Omitted: VS Code, Claude Tag/Slack, cloud-session and self-hosted-runner items unless noted.

**OpenAI Codex** — [releases](https://github.com/openai/codex/releases):

**0.164.0 (Oct 23, stable)**
- ⭐ 🆕 `/presets`: ten numbered slots for saved prompts/slash commands — a lightweight analogue of custom slash commands.
- ⭐ 🆕 Inline arguments on `/model` and `/permissions` (model, reasoning effort, speed, permission profile) — faster switching mid-session.
- ⭐ 🆕 Enterprise MCP connections can authenticate via Codex account grants or dedicated sign-in, including OAuth clients needing secrets.
- 🆕 Image previews in the fullscreen transcript on Kitty/Sixel terminals; credentials masked in remote Bash/Zsh snapshot sessions; Bedrock setup wizard on by default.
- 🐛 Failed compaction no longer leaves partial summaries; resume finds compressed histories and restores thread settings; queued prompts wait for pending permission choices; macOS sandbox checks hardened against case-variant paths and replaceable symlinks.
- 🔧 Lower disk usage (pruned installs, bounded daemon logs). Alphas 0.164.0-alpha.11–12 and 0.163.0-alpha.11.2 are superseded.

## 🎯 8. One thing to try today (≤30 min)

**Harden unattended runs with 2.1.309, then test that your guardrails actually hold.**
1. `claude update`, then confirm with `claude --version` (≥2.1.309).
2. In a scratch repo, enable the sandbox and add a deny rule, e.g. `Edit(./secrets/**)` in `.claude/settings.json`. Then ask Claude to "append a line to secrets/x.txt using a bash redirect inside a subshell" — before 2.1.309 some subshell forms could slip past the Edit deny; now it should be blocked. Note the result either way.
3. If you run `claude ultrareview` in CI, add `--trust-workspace` after the PR number/base branch (or the env var above), or the job will refuse.
4. Optional: if you run Codex too, `codex --version` and try `/presets` to save your standard "review this diff" prompt in slot 1.
