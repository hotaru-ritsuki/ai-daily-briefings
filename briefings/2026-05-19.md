## 3. 📋 AI coding tool changelogs

_Cutoff: entries after 2026-05-15 (v2.1.143 / Codex 0.131.0-alpha.22)._

### Claude Code — 2.1.144 (May 19) ([changelog](https://code.claude.com/docs/en/changelog))

- 🆕 ⭐ **`/resume` for background sessions** — sessions started via `claude --bg` or Agent View now appear in the resume list, marked with `bg`. ⭐ *Reconnect to overnight migration agents without hunting through `claude agents` — they show up alongside interactive sessions.*
- 🆕 ⭐ **`/model` is session-scoped** — changes the model for the current session only. Press `d` in the model picker to set a default for new sessions. ⭐ *Eliminates the footgun where changing model in one Agent View session silently changed it in others.*
- 🆕 Plugin update timestamps in `/plugin` browse and discover panes.
- 🔧 Elapsed duration in background subagent completion notifications (e.g. "Agent completed · 3h 2m 5s").
- 🔧 Renamed "extra usage" to "usage credits" across CLI; `/extra-usage` is now `/usage-credits` (old name still works).
- 🔧 Fewer spurious tool errors: `head`/`tail` file views now satisfy the read-before-edit check; "no matches" from grep-like tools no longer reported as failures.
- 🔧 ⭐ Improved recovery from pre-response stream stalls — retries streaming once instead of falling back to slower non-streaming. ⭐ *Faster recovery from transient API hiccups during long agent runs.*
- 🔧 SDK/headless MCP startup: pre-wait now overlaps startup (up to 2s faster with slow MCP servers).
- 🐛 ⭐ **Fixed MCP servers with paginated `tools/list` only returning the first page, silently dropping tools.** ⭐ *If your MCP servers expose many tools and some were mysteriously missing, this is the fix.*
- 🐛 Fixed startup hanging up to 75s when `api.anthropic.com` is unreachable (captive portal, firewall, VPN) — now times out after 15s.
- 🐛 Fixed progressive terminal display corruption in very long sessions.
- 🐛 Fixed macOS background sessions crashing under Full Disk Access-protected folders.
- 🐛 Fixed resumed sessions picking up another session's `/model` choice.
- 🐛 Fixed MCP images with unsupported MIME types (e.g. SVG) breaking the conversation.
- 🐛 Fixed `/bg` and `←`-detach not preserving directories added via `/add-dir`.
- 🐛 Fixed `claude agents` or `claude logs <id>` hanging when background service is unresponsive — now times out after 10s.
- 🐛 ~15 additional background-agent, Windows, and rendering fixes.

### OpenAI Codex CLI — 0.131.0 stable (May 18) ([releases](https://github.com/openai/codex/releases))

- 🆕 ⭐ **Richer TUI with token usage metrics and permission mode display.** ⭐ *Codex now shows what you're spending per session — a feature Claude Code still lacks in-session.*

## 4. 🛠️ Claude Code & MCP ecosystem

- **12-Factor Agents is trending hard (~20.8K stars)** — HumanLayer's language-agnostic manifesto for building reliable LLM-powered production software, inspired by the original 12-Factor App. Key principles: own your control flow (don't let frameworks call your code), treat humans as high-latency tools, limit agents to 3–20 steps and chain micro-agents in a deterministic DAG, unify execution and business state in a single thread event log. Not a framework — a set of design constraints. If you're building agent harnesses for migration work, the "own your prompts" and "small focused agents" factors are directly applicable ([GitHub](https://github.com/humanlayer/12-factor-agents), [humanlayer.dev](https://www.humanlayer.dev/12-factor-agents)).
- **Claude Code 2.1.144's MCP pagination fix is more significant than it looks** — if you run MCP servers that expose >20 tools (common with database connectors, the Google MCP Toolbox, or Salesforce Data 360), previous versions silently dropped everything past the first page. You may have been running with a subset of your configured tools without knowing it. After upgrading, run `/mcp` and verify your tool counts.
- **MCP ecosystem hit 14,000+ servers** — governance transferred to Linux Foundation's AAIF. Context7 (Upstash, ~54K stars, 890K weekly npm downloads) is the most-used MCP server overall. Playwright MCP (~30K stars) is second. The ecosystem has matured past the "interesting experiment" phase ([WorkOS](https://workos.com/blog/everything-your-team-needs-to-know-about-mcp-in-2026)).
- **Codex 0.131.0's `codex doctor` sets a useful precedent** — Claude Code has `/doctor` for plugin diagnostics but nothing equivalent for the full stack (auth, network, MCP, terminal, config). Worth watching whether Anthropic adds something similar.

## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns

- **"Effective Context Engineering for AI Agents"** — [Anthropic Engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents). Anthropic's definitive practitioner guide. Key insight: the most common failure mode is bloated tool sets — "if a human engineer can't definitively say which tool should be used, an AI agent can't either." Covers system prompts, tool design, message history management, memory, and compaction. If you read one thing on agent design this month, make it this. ~15 min. *(Published earlier but newly surfacing in practitioner circles this week; included because it wasn't in the last 7 briefings' article sections.)*
- **"Harness Design for Long-Running Application Development"** — [Anthropic Engineering](https://www.anthropic.com/engineering/harness-design-long-running-apps). Three-agent architecture (planner → generator → evaluator) for multi-hour autonomous coding sessions. The evaluator uses Playwright MCP to click through the running product and test behavior against explicit contracts. 5–15 iteration cycles, up to 4 hours per run. *Directly applicable to migration work — the evaluator pattern prevents quality drift in long agent sessions.* ~12 min.
- **"12 Factor Agents: Principles for Building Reliable LLM Applications"** — [HumanLayer](https://www.humanlayer.dev/blog/12-factor-agents). The companion blog post to the trending repo. Core argument: most successful production agents aren't magical autonomous beings — they're well-engineered traditional software with LLM capabilities sprinkled in at key points. The "own your control flow" and "pre-fetch context" factors are the most actionable for migration harnesses. ~10 min.
- **"Demystifying Evals for AI Agents"** — [Anthropic Engineering](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents). Evaluation strategies that work across real-world agent deployments. Key distinction: a transcript (what the agent said) vs. an outcome (what actually changed in the environment). Without evals, teams get stuck in reactive loops — catching issues only in production. *If you're deploying migration agents, eval design is the difference between "it seems to work" and "it reliably works."* ~12 min.

### 6b. General AI engineering reading

- **"Context Engineering Has Eaten Prompt Engineering"** — [Rashid Mahmood (Medium)](https://medium.com/@codewithrashid/context-engineering-has-eaten-prompt-engineerin-eb3a869c0362). By early 2026, context engineering has crystallized into a framework with named strategies, named failure modes, and practitioner literature. Covers the scratchpad pattern (agent writes notes to itself) and the memory pattern (agent persists facts across sessions). A useful synthesis of where the field stands now. ~8 min.
