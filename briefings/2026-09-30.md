## 4. 🛠️ Claude Code & MCP ecosystem (community side)

- **The open-sourced Codex harness** ([DevDay recap](https://openai.com/index/devday-2026-recap/)) is the notable ecosystem event: the coordination loop behind "dots" is now readable, so cross-pollinating its compaction/tool-search patterns into your CC subagent setups is on the table. The **Agents API** also exposes computer-use + multi-agent primitives to app builders.
- **[`mvschwarz/openrig`](https://github.com/mvschwarz/openrig)** (~2.6k★) — runs **Claude Code *and* Codex as one coordinated team**: define topologies in YAML (`RigSpec` — pods, edges, continuity policies), boot with one command, agents talk via `rig send`/`broadcast`/`chatroom`, snapshot/restore team state across sessions. Runs on tmux (macOS/Linux). This is the cleanest published take yet on the CC-plus-Codex split-brain workflow people hand-roll.
- **[`DeusData/codebase-memory-mcp`](https://github.com/DeusData/codebase-memory-mcp)** — an MCP server that lets coding agents understand large codebases without re-scanning files each turn; directly relevant to context exhaustion in Angular/Spring monorepos.
- Community subagent write-ups worth a skim: [developersdigest's "Agent Teams, Subagents & MCP 2026 playbook"](https://www.developersdigest.tech/blog/claude-code-agent-teams-subagents-2026) frames the orchestration surface as subagents (who) × MCP (what they touch) × hooks (when to pause/validate) — a useful checklist against your own `.claude/`.
