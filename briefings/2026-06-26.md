## 3. 📋 AI coding tool changelogs

### Claude Code — v2.1.191 (Jun 24) + v2.1.193 (Jun 25) · [changelog](https://code.claude.com/docs/en/changelog)

**v2.1.193:**
- ⚠️⭐ **`claude_code.assistant_response` OTel log event** — logs the model's response text; defaults to following `OTEL_LOG_USER_PROMPTS` if `OTEL_LOG_ASSISTANT_RESPONSES` is unset, so prompt-logging deployments silently gain response-logging on upgrade. The governance gotcha of the day (§1).
- 🆕⭐ **`autoMode.classifyAllShell`** routes *all* Bash/PowerShell through the auto-mode classifier, not just arbitrary-code-execution patterns. Tighter blast-radius control for unattended runs in a regulated repo.
- 🔧⭐ **Auto-mode denial reasons** now surface in the transcript, the denial toast, and `/permissions` recent-denials — you can finally see *why* a headless run was blocked.
- 🔧 **MCP `headersHelper` re-runs and reconnects on 401/403**, plus a startup notice when servers need auth; bash-mode (`!`) file-path autocomplete.

**v2.1.191:**
- 🐛⭐ **Hooks with comma-separated matchers (e.g. `"Bash,PowerShell"`) were silently never firing** — now fixed. If you split hook matchers that way, they weren't running; re-check your `.claude/` hooks.
- 🔧⭐ **MCP reliability:** capability discovery (`tools/list`/`prompts/list`/`resources/list`) and OAuth discovery/token requests now retry transient network errors with backoff; headless environments skip the browser popup. Fewer flaky JetBrains/remote-MCP starts.
- 🆕 **`/rewind` can resume from before a `/clear`**; stopping a background agent is now permanent (no resurrection).
- 🔧 **~37% less CPU during streaming** (text updates coalesced to 100ms) and reduced long-session memory growth.

### OpenAI Codex — `rust-v0.142.2` stable (Jun 25) · [releases](https://github.com/openai/codex/releases)
- 🆕⭐ **MCP tools now default to tool search when supported** — Codex stops dumping every tool definition into context and discovers them on demand, the same "don't front-load the tool list" shift Claude Code made. Relevant if you run MCP-heavy Codex sessions.
- 🔧 PowerShell commands with uninspectable AST regions now require approval; remote stdio MCP servers accept absolute working dirs; remote HTTP(S) image inputs return validation errors; clearer Bedrock expired-credential guidance.

**Action:** `npm update -g @anthropic-ai/claude-code` → v2.1.193 (set `OTEL_LOG_ASSISTANT_RESPONSES=0` first if you log telemetry); Codex users `→ rust-v0.142.2`.

## 4. 🛠️ Claude Code & MCP ecosystem

- **Semantic code search as an MCP is the practical story this week.** [`zilliztech/claude-context`](https://github.com/zilliztech/claude-context) (~12k★) indexes your codebase into a vector store (Zilliz/Milvus) with **incremental Merkle-tree indexing** so re-indexing only touches changed files, **AST-aware chunking** so retrieved snippets are syntactically whole, and pluggable embeddings (OpenAI/VoyageAI/Ollama/Gemini). Their controlled eval claims **~40% token reduction at equivalent retrieval quality** — unverified by me, but the architecture is the right shape for a codebase too big to grep into context every turn. This is a cleaner alternative to the "files over tools" pattern when the file tree alone is too large to skim (§8).
- **Two harnesses converged on "tool search" this week.** Codex 0.142.2 making MCP tool-search the default (§3) lands the same idea Claude Code already uses: don't inject all tool schemas up front, discover them on demand. If you author MCP servers, this rewards *fewer, well-named, well-described* tools over sprawling toolsets — the model now pays to find yours.
- **Plugin bundles keep maturing.** [`2389-research/claude-plugins`](https://github.com/2389-research/claude-plugins) (~74★) packages 28 plugins + 4 MCP servers around concrete workflows — **TDD, multi-agent orchestration, iterative refinement, specialized review panels, PR assistance** — each installable in one command. Small repo, but the TDD and iterative-refinement plugins are worth reading as patterns even if you don't adopt them wholesale.
- **`claude mcp login` / `claude mcp logout`** (recent CLI addition) authenticate MCP servers without opening `/mcp`, with `--no-browser` stdin redirect for SSH — handy for provisioning servers in headless/CI sessions ([search summary](https://releasebot.io/updates/anthropic/claude-code)).

## 8. 🎯 One thing to try today (≤30 min)

**Wire `claude-context` to your migration repo so the agent searches the whole codebase instead of drowning in it.** Quickest path with an OpenAI embedding key + a free Zilliz Cloud token:

```bash
export OPENAI_API_KEY=sk-...          # or VOYAGE / Gemini / local Ollama
export MILVUS_TOKEN=...               # free Zilliz Cloud tier, or run Milvus locally
claude mcp add claude-context -- npx -y @zilliz/claude-context-mcp@latest
```

Then in a Claude Code session: *"Index this repo, then use claude-context to find every component that still depends on `$scope` or `angular.module` and list them with file paths."* The point is to compare token spend and retrieval quality against your usual grep-into-context flow on one real migration query — if the ~40% token-reduction claim holds on your codebase, it changes the economics of every unattended run. Repo + setup: [zilliztech/claude-context](https://github.com/zilliztech/claude-context). *(~20 min.)*
