## 3. 📋 AI coding tool changelogs

**Claude Code** — fetched [changelog](https://code.claude.com/docs/en/changelog). New since 07-17's v2.1.212:

- **v2.1.214 (Jul 18)** ⭐ ⚠️ — a **permission-hardening train**. The one that bites: single-segment `dir/**` **allow** rules (e.g. `Edit(src/**)`) now match only `<cwd>/dir`, not `dir/` at any depth — write `**/dir/**` for any-depth. (`deny`/`ask` rules keep their any-depth match; single-segment `dir/**` hook `if:` conditions also narrowed to `<cwd>/dir`.) Also: PowerShell 5.1 permission-bypass closed; Bash checks fail-closed on FD-redirect forms and always prompt on commands >10,000 chars; `docker`/Podman daemon-redirect flags (`--url`, `--connection`, remote mode) now prompt; `file -m/--magic-file`/`-f` no longer auto-allowed as read-only.
- **v2.1.214 (Jul 18)** 🆕🐛 — adds an **`EndConversation` tool** (Claude can end sessions with abusive/jailbreak users), a **progress heartbeat** for long-silent tool calls, and reasoning-effort in the `subagentStatusLine` payload. Fixes worth noting: **scheduled tasks were rejecting their own configured prompt as untrusted input** (now delivered as the assigned task — relevant to anyone running Claude Code on a schedule); prompt-caching mid-conversation system block now works behind LLM gateways/custom base URLs; `pkill -f` no longer killing the CLI's own process on Linux.

**OpenAI Codex** — fetched [GitHub Releases](https://github.com/openai/codex/releases). Still **no new stable past 0.144.5**; the `0.145.0` alpha train advanced to **alpha.23 (Jul 17)**, all with empty release bodies. Nothing user-facing to adopt (07-17 noted this through alpha.20).

## 4. 🛠️ Claude Code & MCP ecosystem (community)

- **`@playwright/cli` is the notable ecosystem move.** Microsoft split browser automation into two paths: the MCP server (protocol, structured tools) *and* a plain-shell `@playwright/cli` companion, plus a Chrome extension that connects MCP to an already-open browser using your default profile — cookies, logged-in state included ([playwright-mcp](https://github.com/microsoft/playwright-mcp)). For a financial platform where every meaningful E2E path sits behind auth, driving the real logged-in session beats re-implementing login in the harness.
- **Skills-over-MCP keeps hardening as the durable layer.** The pattern: once you run 3+ MCP servers, wrap them in **Skills** (`SKILL.md`) that invoke the same tools the same way every time, with enforced output shape and refuse-to rules — cited production examples for PR review, test-gap analysis, migration safety, changelog ([Clarista guide](https://www.clarista.io/blog/claude-code-mcp-plugins-guide)). For an AngularJS→Angular migration a "migration-safety" skill that always runs the same checks is more repeatable than ad-hoc prompting — and complements v2.1.214's tighter allow-rule matching.
- **Eval infra is getting agent-driven.** [awslabs/llm-evaluation-system](https://github.com/awslabs/llm-evaluation-system) (new this month) lets you *describe* an eval in natural language; an agent generates the dataset, configures a **multi-judge jury** (Claude Sonnet, Nova Pro, Nemotron each scoring different aspects), runs it, and returns a PDF — and ships an MCP server for IDE use. A concrete answer to "how would I even A/B Kimi K3 vs Fable 5 on my components" from §8.
- **Spec-driven orchestration** continues to mature: Coordinator / Implementor / Verifier agents run against a *living spec* that updates as implementation proceeds ([Pathmode](https://pathmode.io/blog/orchestration-era-needs-intent)) — worth watching if you coordinate more than 2–3 agents.

## 8. 🎯 One thing to try today (≤30 min)

**A/B Kimi K3 against Fable 5 on one real frontend component — via OpenRouter, no local weights needed.** Take a PrimeNG component you'd normally hand to Fable 5, send the same prompt to both, and diff the output for structure, accessibility, and how close it lands to your conventions. First command:

```bash
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"moonshotai/kimi-k3","messages":[{"role":"user","content":"Build a PrimeNG standalone Angular 18 table component with sorting, filtering, and a11y labels for a transactions grid."}]}'
```

At $3/$15 per M this costs cents. If K3 holds up on frontend, it's a credible open fallback to pin in a config for when you want weights you control (Jul 27).

## 9. 📣 Shareable angle

**Hook:** "My scheduled AI agent was rejecting its own instructions as a security threat."

**Draft:** Claude Code v2.1.214 quietly fixed a bug where scheduled tasks refused their own configured prompt as "untrusted input" — a neat illustration of the real tension in autonomous agents: the same prompt-injection defenses that keep an agent safe can lock it out of the job you scheduled it to do.
