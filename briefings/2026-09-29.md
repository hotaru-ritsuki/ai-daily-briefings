## 4. 🛠️ Claude Code & MCP ecosystem (community)

- **[`agentproto/ts`](https://github.com/agentproto/ts)** is the standout for your stack: a TypeScript agentic runtime that runs any coding agent in the background, gates its work before it lands, and *projects* the same tools/skills/agents/workflows into CLI, HTTP, MCP, SDK, Mastra and the Vercel AI SDK. Its Sep 22 + Sep 27 releases landed **`@agentproto/eval`** with a full suite of style scorers and `@agentproto/eval-reporters` — i.e. eval-driven agent dev in TS, not Python. Directly relevant if you want CC-style subagents wired into an Angular/Node surface.
- **JetBrains MCP got a testing upgrade you'll feel:** the [IDE Index MCP Server v5.19.0](https://plugins.jetbrains.com/plugin/29174-ide-index-mcp-server) (Sep 26) makes `ide_run_tests` **stream results while the run is still executing** — passed/failed/error counts and failures reported incrementally. For an IntelliJ + Playwright/Spring user, that means an agent sees red tests mid-run instead of waiting for the whole suite.
- **Behavioral skills keep out-scaling code skills.** [`multica-ai/andrej-karpathy-skills`](https://github.com/multica-ai/andrej-karpathy-skills) — a single CLAUDE.md encoding four rules (Think Before Coding, Simplicity First, Surgical Changes, Goal-Driven Execution) from Karpathy's Jan-2026 complaints — is reportedly past 210k combined stars ([TechTimes](https://www.techtimes.com/articles/316798/20260518/karpathy-inspired-claudemd-passes-220000-combined-github-stars-four-rules-that-stop-ai-breaking.htm)). Worth reading as a menu, not a template — the "surgical changes / don't touch orthogonal code" rule is the one most worth stealing into your own CLAUDE.md.
