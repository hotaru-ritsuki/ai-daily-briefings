## 3. 📋 AI coding tool changelogs

_Cutoff: entries after 2026-05-09 (v2.1.138 / Codex 0.130.0)._

### Claude Code — 2.1.139 (May 11) ([changelog](https://code.claude.com/docs/en/changelog))

- 🆕 ⭐ **Agent View (Research Preview)** — a unified dashboard of every Claude Code session: running, blocked on you, or done. Run `claude agents` to open it; press left arrow from any session to return to it. ⭐ *The multi-session management layer Claude Code has been missing. Directly useful for running parallel migration tasks.*
- 🆕 ⭐ **`/goal` command** — set a completion condition and Claude loops autonomously until it's met. Works in interactive, `-p`, and Remote Control modes. Live overlay shows elapsed time, turn count, and token usage. ⭐ *Combine with Agent View for "launch a migration task, set the goal, monitor from the dashboard" workflows.*
- 🆕 ⭐ **Hook `continueOnBlock`** config option for `PostToolUse` — set to `true` to feed the hook's rejection reason back to Claude and continue the turn instead of blocking. ⭐ *Hooks can now guide rather than gate — reject a pattern but let Claude self-correct instead of stopping.*
- 🆕 ⭐ **Hook `args: string[]` field** (exec form) — spawns the command directly without a shell, so path placeholders never need quoting. ⭐ *Eliminates shell-injection edge cases in hooks with dynamic paths.*
- 🆕 ⭐ **MCP stdio servers receive `CLAUDE_PROJECT_DIR`** in their environment, matching hooks. Plugin configs can reference `${CLAUDE_PROJECT_DIR}` in commands. ⭐ *MCP servers can now be project-aware without manual path passing.*
- 🆕 `claude plugin details <name>` — shows component inventory and projected per-session token cost.
- 🆕 `/scroll-speed` command with live preview; transcript view navigation (`?` for shortcuts, `{`/`}` to jump between user prompts).
- 🔧 Compaction prompt now asks the model to preserve sensitive user instructions.
- 🔧 `/mcp` Reconnect picks up `.mcp.json` edits without a restart; shows HTTP status and URL on failure.
- 🔧 Subagent API requests carry `x-claude-code-agent-id` / `x-claude-code-parent-agent-id` headers (OTEL spans include matching attributes).
- 🐛 Fixed deadlock where expired credentials blocked `claude auth login`/`logout`/`status` with no recovery path.
- 🐛 Fixed `autoAllowBashIfSandboxed` not auto-approving commands with shell expansions (`$VAR`, `$(cmd)`).
- 🐛 Fixed hooks writing to the terminal corrupting on-screen interactive prompts — hooks now run without terminal access.
- 🐛 Fixed unbounded memory growth from HTTP/SSE MCP servers streaming non-protocol data (capped at 16 MB per SSE frame).
- 🐛 Fixed `Skill(name *)` wildcard permission rules not working as prefix match.
- 🐛 Fixed spurious "stream idle timeout" 5 min after response completed.
- 🐛 Fixed mouse wheel scrolling speed in Cursor and VS Code 1.92–1.104.
- 🐛 ~25 additional UI, keyboard, rendering, and plugin fixes.
- 🆕 [VS Code] `Cmd/Ctrl+Shift+T` reopens the most recently closed session tab.

## 8. 🎯 One thing to try today (≤30 min)

**Upgrade to 2.1.139 and try Agent View + `/goal` on a real task.**

```bash
# 1. Upgrade
claude --upgrade  # confirm 2.1.139

# 2. Open Agent View
claude agents

# 3. From the Agent View input, launch a task with a goal:
#    Type a prompt like:
#    "Migrate the legacy-filters directive in src/app/filters/
#     from AngularJS to Angular 18 standalone component.
#     /goal All tests pass and ng build succeeds with no type errors."

# 4. Watch it appear as a row in the dashboard. It will loop
#    autonomously until the goal is met (or ask for help).

# 5. While it runs, launch a second task from the same dashboard:
#    "Write Playwright e2e tests for the newly migrated filters component.
#     /goal All Playwright tests pass."

# 6. Press left arrow to jump into a running session for details.
#    Press Esc to return to the dashboard.

# 7. Also test the new /mcp hot-reload:
#    Edit .mcp.json while Claude is running, then /mcp > Reconnect.
#    It should pick up your changes without a restart.
```

Agent View + `/goal` is the most significant workflow change to Claude Code since Routines. Instead of babysitting a single session, you can dispatch multiple migration tasks from a single dashboard and let each one loop until its goal is met. The parallel-migration-tasks workflow is now built in.
