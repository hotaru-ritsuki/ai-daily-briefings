## 8. 🎯 One thing to try today (≤30 min)

**Verify you're hardened against v2.1.183's new auto-mode failure classes** — they bite specifically when agents run unattended, which is exactly your headless/cron posture.

```bash
# 1. Update:
npm update -g @anthropic-ai/claude-code   # expect 2.1.183

# 2. Catch stale model pins now that v2.1.183 warns on agent-frontmatter models:
grep -RIn "claude-fable-5\|claude-\(sonnet\|opus\)-4-20250514" ~/.claude/ .claude/ 2>/dev/null
#    Any hit in an agent frontmatter now surfaces a deprecation warning on stderr in -p.

# 3. If you run scheduled/webhook-triggered sessions in auto mode, confirm you're
#    past the v2.1.183 fix: re-run one scheduled job and verify a webhook delivery
#    can no longer auto-approve a pending permission prompt or set the session title.

# 4. Make the destructive-command posture an explicit managed-policy lever
#    (v2.1.183 enforces much of this in auto mode by default, but deny rules
#     also cover non-auto sessions):
#    .claude/settings.json
#    { "permissions": { "deny": [
#        "Bash(command:git reset --hard*)",
#        "Bash(command:git clean -fd*)",
#        "Agent(model:claude-fable-5*)"
#    ] } }
```

The payoff is a one-session confirmation that the failure modes you can't see in an unattended run — webhook-as-keyboard, stale-model fallback — are actually closed in your config.
