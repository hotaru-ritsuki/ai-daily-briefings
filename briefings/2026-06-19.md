## 3. 📋 AI coding tool changelogs

*Cutoff: published after the 06-16 briefing (Claude Code v2.1.178; Codex `rust-v0.140.0` stable).*

### Claude Code ([changelog](https://code.claude.com/docs/en/changelog))

**v2.1.183 — Jun 19**
- 🆕 ⭐ **Auto-mode blocks destructive git** (`reset --hard`, `checkout -- .`, `clean -fd`, `stash drop`), `commit --amend` on non-agent commits, and `terraform/pulumi/cdk destroy` without an explicit stack. ⭐ The first content-aware destructive-command class in auto mode — directly relevant to running agents against a writable financial-services repo.
- 🐛 ⭐ **Scheduled-task / webhook deliveries were treated as keyboard input** and could approve a pending action or set the session title in auto mode — now classified as task notifications. ⭐ Real auto-mode privilege-confusion fix; audit any cron/webhook-triggered sessions.
- 🆕 ⭐ Deprecated/auto-updated-model **warning now covers models set in agent frontmatter** (stderr in `-p`). ⭐ Catches stale `claude-*-4-20250514` and `claude-fable-5` pins in subagent configs.
- 🆕 `attribution.sessionUrl` setting to omit the claude.ai session link from commits/PRs — useful if you don't want session URLs in financial-repo history.
- 🐛 WebSearch returning empty in subagents fixed; MCP auth servers exposing auth-stub tools in headless/SDK mode fixed; teammate-started background tasks no longer killed when the teammate ends its turn.

**v2.1.181 — Jun 17**
- 🆕 ⭐ **`/config key=value`** to set any setting from the prompt (e.g. `/config thinking=false`), in interactive, `-p`, and Remote Control. ⭐ Faster than editing `settings.json` for one-off toggles.
- 🐛 ⭐ **Foreground subagents were spawning unbounded nested chains** — now respect the same 5-level depth limit as background subagents. ⭐ Closes a gap in the v2.1.172 depth model.
- 🐛 ⭐ Prompt caching not reading on custom `ANTHROPIC_BASE_URL` and Foundry (per-request attestation token) fixed; `awsCredentialExport` short-lifetime creds no longer refresh every minute and now accept `aws configure export-credentials` JSON. ⭐ Both bite the Bedrock/gateway perimeter setup.
- 🐛 `claude mcp get`/`list` now shows `! Connected · tools fetch failed` instead of a false `✓`; Bun runtime bumped to 1.4; plus a large batch of TUI/startup-latency fixes.

**v2.1.179 — Jun 16**
- 🐛 Mid-stream connection drops preserve partial responses (no raw error, no stuck spinner); WSL2 mouse-wheel scroll regression (2.1.172) fixed; a `denyRead`/`allowRead` glob over a large tree no longer bloats the Bash tool description into an unusable session on Linux.

### OpenAI Codex CLI ([releases](https://github.com/openai/codex/releases))

**`rust-v0.141.0` stable — Jun 18** ([tag](https://github.com/openai/codex/releases/tag/rust-v0.141.0)) — ends the empty-body streak
- 🆕 ⭐ **Encrypted Noise relay channels** for remote executors; cross-platform remote execution preserves executor-native working dirs and shells. ⭐ The transport hardening the regulated-perimeter story needed.

- 🆕 TUI input prompts auto-resolve after inactivity with a countdown; realtime clients gain explicit speech/response controls.
- 🔧 ⭐ **TLS P-521 certificate support** for enterprise proxies; SQLite pinned past a WAL-reset corruption fix; tool-search caching cuts latency/memory in large sessions.
- 🐛 ⭐ **Hook-trust bypass now persists through `codex exec` start/resume, and PostToolUse hooks correctly reject code-mode tool calls.** ⭐ Hook-enforcement gap closed; re-test any code-mode hook policies.

## 8. 🎯 One thing to try today (≤30 min)

**Verify you're hardened against the new auto-mode failure classes, then wire `/config` into the loop.** Both v2.1.181 and v2.1.183 close gaps that bite specifically when agents run unattended.

```bash
# 1. Update both:
npm update -g @anthropic-ai/claude-code   # expect 2.1.183
codex --version                            # expect 0.141.0

# 2. Catch stale model pins now that v2.1.183 warns on agent-frontmatter models:
grep -RIn "claude-fable-5\|claude-\(sonnet\|opus\)-4-20250514" ~/.claude/ .claude/ 2>/dev/null
#   Any hit in an agent frontmatter now surfaces a deprecation warning on stderr in -p.

# 3. Try the new prompt-level config toggle instead of editing settings.json:
claude
> /config thinking=false
> /config --help            # list every shorthand key

# 4. If you run scheduled/webhook-triggered sessions in auto mode, confirm you're
#    past the v2.1.183 fix (webhook deliveries no longer count as keyboard input
#    and can't approve a pending action). Re-run one scheduled job and watch it
#    cannot auto-approve a permission prompt.

# 5. Lock the destructive-command posture explicitly while you're here:
#    .claude/settings.json
#    { "permissions": { "deny": [
#        "Bash(command:git reset --hard*)",
#        "Bash(command:git clean -fd*)",
#        "Agent(model:claude-fable-5*)"
#    ] } }
```

v2.1.183 now enforces much of step 5 in auto mode by default, but the explicit deny rules make it a managed-policy lever (and survive non-auto sessions).

## 9. 📣 Shareable angle

**Hook:** *"Claude Code v2.1.183 quietly fixed a bug where a webhook could approve your agent's permission prompts."*

> Two of this week's Claude Code fixes only matter if you run agents unattended: webhook/scheduled deliveries were being treated as keyboard input (and could approve a pending action in auto mode), and foreground subagents could spawn unbounded nested chains past the 5-level depth limit. The lesson for anyone moving from interactive to headless agents: the failure modes you don't see in the terminal are exactly the ones that show up at 3am on a schedule.
