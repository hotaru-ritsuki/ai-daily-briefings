## 4. 🛠️ Claude Code & MCP ecosystem (deep dive)

The one thing worth real attention this week is the **MCP `2026-07-28` migration**, now that builder-side "what breaks" analyses have landed to complement last briefing's RC announcement. If you run or author MCP servers, this is a dated deprecation you can plan against:

- **Sessions are gone → stateless core.** Protocol version, client info, and capabilities now ride inline in a `_meta` field on every request; servers route on an `Mcp-Method` header and can run behind a plain round-robin load balancer with no sticky sessions or shared session store ([MCP.Directory](https://mcp.directory/blog/mcp-2026-07-28-release-candidate), [Stacktree "what breaks"](https://stacktr.ee/blog/mcp-2026-spec-changes)). Clients may cache `tools/list` up to the server's `ttlMs` — which is exactly the "don't front-load every tool schema" pressure both CLIs already apply.
- **`tasks/list` removed; long work moves to the Tasks extension.** A server answers `tools/call` with a task handle; the client drives `tasks/get` / `tasks/update` / `tasks/cancel`. `tasks/list` was cut because it can't be scoped safely without sessions ([spec RC](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)). *If any of my servers expose long-running calls, this is the surface that changes.*
- **Six OAuth SEPs tighten auth.** Clients must validate the `iss` parameter per RFC 9207 (mix-up-attack defense), and OpenID Connect `application_type` is now required during Dynamic Client Registration ([WorkOS breakdown](https://workos.com/blog/mcp-2026-spec-agent-authentication)). This is the OAuth-refresh surface Claude Code and Codex both just fixed on the client side — the server side now has to match.
- **MCP Apps (SEP-1865)** ships as the first official extension for server-rendered UIs, with every UI-initiated action routed through the same JSON-RPC consent/audit path as a direct tool call — the audit-trail property I'd want before putting any MCP UI in front of a regulated workflow. **SEP-2596** guarantees ≥12 months between deprecation and removal, so this is the last hard cutover for a while.

Practical read: budget an afternoon before Jul 28 to test your servers against the RC. Beyond the spec, nothing net-new on the `.claude/` config / subagent-library front since the VoltAgent and awesome-claude-plugins items covered 07-08/07-09.
