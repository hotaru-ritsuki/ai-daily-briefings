## 3. 📋 AI coding tool changelogs (since 2026-10-29 briefing)

### Claude Code
- **2.1.314 (Oct 30)** — fetched from the [GitHub releases page](https://github.com/anthropics/claude-code/releases); the notes were truncated, so this list is partial. 2.1.313 does not appear on that page, so I can't say what it contained.
  - 🆕 ⭐ `permissions.blockWritesOutsideWorkingDirectories`: file-writing tools refuse paths outside the working directories in every permission mode. Useful as a hard stop for subagents and `bypassPermissions` runs.
  - 🆕 Idle compaction in VS Code and the Desktop Code tab: a conversation over 200K tokens that sits idle is summarised, and the summary is used on your next message if the prompt cache expired. Not the CLI, so it doesn't change your terminal use.
  - 🆕 Claude apps gateway: per-upstream IdP `groups` lists and a Bedrock `guardrail_trace`. Admin-side only.
  - 🐛 ⭐ A PreCompact hook's output is capped at 10,000 characters, so a chatty hook no longer breaks compaction. Check any PreCompact hooks you wrote.
  - 🐛 `claude -p` now prints startup errors and exits 1 rather than exiting 0 silently. Matters for scripts and CI.
  - 🔧 `claude ultrareview` and `claude remote-control` refuse untrusted folders immediately when `CI` is set.
  - 🐛 Fixes for "Invalid effort level" when an admin caps effort, Bedrock `/compact` with many images, Foundry model fallback, a TLS cross-signed root cert error, and vim-mode, `/resume` and Remote Control bugs.

### OpenAI Codex ([releases](https://github.com/openai/codex/releases))
- **0.166.0 stable (Oct 29)**, after alpha.1–6.
  - 🆕 GPT-6.1 Terra added to the bundled, Vertex AI and Bedrock model catalogs.
  - 🆕 Keyboard-driven transcript navigation with search and configurable shortcuts.
  - 🆕 `codex queue --resume` resumes unloaded threads after queueing a message; `codex doctor --network-only` runs connectivity and WebSocket diagnostics.
  - 🔧 Clearer explanations for safety blocks in the TUI, with safer follow-up prompts.
  - 🐛 ⭐ Approval and permission settings now persist across resume and fork. This was a gap that could silently change your sandbox after resuming.
  - 🐛 Reasoning-token accounting no longer triggers premature compaction; app-server startup/shutdown races fixed.

## 8. 🎯 One thing to try today (≤30 min)
**Lock writes to the project directory and test it with a subagent.**
1. Update: `claude update` (check `claude --version` shows 2.1.314).
2. In `.claude/settings.json` add:
   ```json
   { "permissions": { "blockWritesOutsideWorkingDirectories": true } }
   ```
3. Start a session and ask: "Write a file called x.txt to /tmp using the Write tool." It should be refused, including with `--permission-mode acceptEdits`.
4. Then ask a subagent to do the same, and note whether refusal is consistent.
Success: refusal in every mode. Also run `/hooks` and check any PreCompact hook's output stays under 10,000 characters.
