## 4. 🛠️ Claude Code & MCP ecosystem (community side)

With both daily tools effectively frozen, the interesting ecosystem signal this week is **observability-by-binding** — and `wrapture` is the cleanest example:

- **[`wrapture`](https://github.com/GrahamDumpleton/wrapture)** (alpha, built on `wrapt`) lets you attach bindings to Python call sites — stub a method in a test, trace it in production — *without modifying the observed code*, configured entirely from a TOML file. On top sits **OpenTelemetry export**: the same recorded events go to any OTLP backend as traces/metrics/correlated logs, with W3C `traceparent` propagation, switched on by one `[otel]` table ([Willison writeup](https://simonwillison.net/2026/Sep/11/wrapture/), [Dumpleton's intro](https://grahamdumpleton.me/posts/2026/08/introducing-wrapture/)). The pattern — one vocabulary that spans test-double → trace → production telemetry — is worth stealing for how you instrument agent tool calls.
- **Provider routing got a sober guide.** Willison's [*So you want to use OpenRouter?*](https://simonwillison.net/2026/Sep/11/so-you-want-to-use-openrouter/) walks the tradeoffs of a single API in front of many model providers — the failure modes (silent provider substitution, inconsistent tool-calling, pricing drift) more than the pitch. Relevant if you're abstracting model access behind a gateway in a Spring service.
- **Harness engineering now has a canonical reading list:** [`ai-boost/awesome-harness-engineering`](https://github.com/ai-boost/awesome-harness-engineering) curates tools, patterns, evals, memory, MCP, permissions, observability, and orchestration — the discipline this briefing has tracked for two weeks, in one place to diff your own `.claude/` setup against.

## 8. 🎯 One thing to try today (≤30 min)

**Add production-grade tracing to a Python script without touching its code, using `wrapture`.** Even in a Java/Angular shop you have Python glue somewhere — a build script, a data job. Instrument one function end-to-end in under 30 minutes:

```bash
pip install wrapture
```

Then write a small TOML that binds a trace to one function and enables the `[otel]` export to a local OTLP collector ([docs](https://wrapture.readthedocs.io/en/latest/)). The payoff isn't the tracing itself — it's internalizing the binding model so you can apply the same test-double → trace → telemetry pattern when you instrument agent tool calls.
