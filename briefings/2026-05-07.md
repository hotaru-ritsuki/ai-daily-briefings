### Claude Code — 1 release ([changelog](https://code.claude.com/docs/en/changelog))

- **2.1.132 (May 6)** — 22 changes:
  - 🆕 `CLAUDE_CODE_SESSION_ID` env var exposed to Bash subprocess, matching the `session_id` passed to hooks.
  - 🆕 `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` opts out of fullscreen alt-screen renderer, keeping conversation in terminal's native scrollback.
  - 🆕 "Pasting…" footer hint during `Ctrl+V` image paste.
  - 🔧 Updated `/tui fullscreen` startup banner to describe lower memory usage, mouse support, auto-copy on select.
  - 🐛 ⭐ **Fixed external SIGINT (IDE stop button, `kill -INT`) not running graceful shutdown** — terminal modes now restored and `--resume` hint printed instead of abrupt exit. ⭐ *If you use IntelliJ ACP's stop button, sessions now exit cleanly and are resumable.*
  - 🐛 ⭐ **Fixed JetBrains IDE 2025.2 terminal scroll-wheel** — spurious arrow keys, wrong-direction events, and runaway acceleration all resolved. ⭐ *Direct fix for your IntelliJ ACP daily workflow.*
  - 🐛 ⭐ **Fixed unbounded memory growth (10GB+ RSS) when a stdio MCP server writes non-protocol data to stdout.** ⭐ *Prevents OOM kills in multi-server setups with chatty MCP servers.*
  - 🐛 ⭐ **Fixed Bedrock and Vertex 400 errors when `ENABLE_PROMPT_CACHING_1H` is set.** ⭐ *The 1-hour cache TTL fix from 2.1.129 was generating provider errors on Bedrock/Vertex — now actually works end-to-end.*
  - 🐛 Fixed MCP servers that connect but fail `tools/list` — now retry once and show "connected · tools fetch failed" in `/mcp`.
  - 🐛 Fixed `--resume` failing with `no low surrogate in string` when tool error truncation split an emoji.
  - 🐛 Fixed fullscreen blank screen after sleep/wake or `Ctrl+Z`/`fg`.
  - 🐛 Fixed pasting text starting with `/` silently swallowed or triggering unknown-command reply.
  - 🐛 Fixed mouse wheel scrolling too fast in VS Code 1.92–1.104 (upstream xterm.js bug workaround).
  - 🐛 Fixed `--permission-mode` flag ignored when resuming plan-mode sessions.
  - 🐛 Fixed cursor landing mid-grapheme on Indic conjuncts/ZWJ emoji with `Ctrl+E/A/K/U/arrow`.
  - 🐛 Fixed vim operators corrupting NFD accented characters.
  - 🐛 Fixed `Alt+T` (thinking toggle) on macOS terminals without "Option as Meta".
  - 🐛 Fixed slash command autocomplete capped at ~3–5 visible entries instead of scaling with terminal height.
  - 🐛 Fixed statusline `context_window` showing cumulative session totals instead of current usage.
  - 🐛 7 additional fixes (clipboard, `/effort` override, `/status` model, dead keyboard on Windows, MCP auth retries, dialog spacing).

## 4. 🛠️ Claude Code & MCP ecosystem

- **Code w/ Claude 2026 developer conference (May 6, SF)** — the event effectively served as a live showcase for the autonomous-dev product stack Anthropic has shipped over the past two months. Key themes: (1) **Auto Mode** now available on Max and Team with Enterprise/API rollout imminent — a background AI classifier evaluates each tool call, blocking dangerous actions while letting safe ones proceed; (2) **CI Auto-Fix** runs in the cloud, watches PRs for CI failures and review comments, pushes fixes autonomously, and asks rather than guesses on ambiguous situations; (3) **Code Review** uses a fleet of specialized agents (logic errors, security, boundary conditions, API misuse, conventions) — internal review coverage at Anthropic jumped 16% → 54% with <1% false positives; (4) **Routines** highlighted as the async-automation primitive — schedule/API/GitHub-event triggered, run as full cloud sessions with no permission prompts. London event May 19, Tokyo June 10 ([Code w/ Claude](https://claude.com/code-with-claude), [Simon Willison](https://simonwillison.net/2026/May/6/code-w-claude-2026/)).
- **Salesforce Data 360 MCP Server (Developer Preview)** — open-source, connects ~200 Salesforce Data 360 API operations to any MCP client via stdio. Uses a facade-tool architecture (3 high-level tools instead of 200 individual ones), inspired by Cloudflare's MCP research on tool management at scale. Java 17+, single-user/single-org in preview ([Salesforce Dev Blog](https://developer.salesforce.com/blogs/2026/05/introducing-the-data-360-mcp-server-developer-preview), [GitHub](https://github.com/forcedotcom/d360-mcp-server)).
- **Splunk MCP Server reached GA** — bridges AI agents with Splunk's observability data. If your platform's ops team uses Splunk, agents can now query logs and metrics directly ([Splunk Community](https://community.splunk.com/t5/Product-News-Announcements/What-s-New-in-Splunk-AI-Vol-01-MCP-Hosted-Models-amp-SPL-AI/ba-p/758587)).
- **MCP gateway pattern gaining traction** — Microsoft's `mcp-gateway` project for Kubernetes-native environments is becoming the standard approach for managing the growing number of MCP servers. Multiple community guides now recommend gateways over flat server lists for setups with 10+ servers.
