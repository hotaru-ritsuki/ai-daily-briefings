### OpenAI Codex — [0.167.0](https://github.com/openai/codex/releases/tag/rust-v0.167.0) (Nov 6, stable)
- 🆕 ⭐ **`codex agents --no-daemon`:** a command center listing running agents, with unread markers on finished results. This matters because running several Codex tasks in parallel previously meant switching between terminals.
- 🆕 ⭐ **Patch review inside approval prompts:** you see the diff in the prompt where you approve or reject the edit. This brings Codex's approval flow closer to Claude Code's edit permissions.
- 🆕 **Switch connected backends from the session picker:** your draft is kept when you switch.
- 🆕 **Cloud provider setup in "Sign in another way":** includes Google Cloud Vertex AI.
- 🆕 **Local image previews in the composer:** image paths in the transcript are also clickable now.
- 🆕 **Opt-in system proxy settings for macOS and Windows** under `/experimental`. Useful behind a corporate proxy.
- 🐛 **Saved chats no longer disappear after switching model providers.** Ctrl+L now clears the screen while keeping history (Ctrl+T brings it back).
- 🐛 **Network approval prompts** close when their request ends, and only one prompt per endpoint shows at a time.
- 🐛 **Auto-compaction handles failed responses and missing usage data.** This should mean fewer broken long sessions.
- 🔧 **The `openai-docs` skill now suggests documented replacements when you migrate off deprecated models.**

- **[google/skills](https://github.com/google/skills)**: official Agent Skills for Google products. Some are bundled as **"Google product plugins (Skills + MCP servers)"**.
  - **Install:** `claude plugin marketplace add google/skills`, then `claude plugin install <plugin>@google-plugins`. Alternatively, `npx skills add google/skills` lets you choose per skill and per agent.
  - **Coverage:** GKE, Cloud Run, BigQuery, AlloyDB, Spanner, IAM/Cloud Armor, Logging/Monitoring and the Well-Architected pillars, plus a remote MCP server for API Gateway (public preview).

Expect AWS and Azure to follow. Your team will then need a policy for allowed marketplaces, and `deniedMcpServers` (2.1.318) is part of that policy.

## 8. 🎯 One thing to try today (≤30 min)
**Run two parallel Codex 0.167 tasks on your Angular repo and supervise them from the new command center, then compare it with Claude Code background agents.**
1. Run `npm i -g @openai/codex@0.167.0 && codex --version`.
2. Create two worktrees, for example `git worktree add ../app-signals` and `git worktree add ../app-e2e`. Use [worktrunk](https://github.com/max-sixty/worktrunk) if you already have it.
3. In the first worktree, run `codex "Migrate src/app/<feature>/<x>.component.ts from @Input/@Output to signal inputs/outputs; keep the template API identical; run ng test for that spec only."`
4. In the second, run `codex "Write one Playwright test for the <feature> happy path using existing page objects; do not touch src/."`
5. From a third terminal, run `codex agents --no-daemon` and watch both. When approvals come in, use the **inline patch review** to accept or reject each edit.
6. Repeat task 1 in Claude Code as a background subagent and compare: time until the first useful diff, how many approval interruptions you got, and whether either agent ran tests you didn't ask for.

**Success criteria:** you can tell which tool's supervision UI you'd want for 3+ parallel agents. Write down one concrete reason; it's the post in §9.
