**Claude Code** — [docs changelog](https://code.claude.com/docs/en/changelog) (versions newer than 2.1.304; the page shows no dates for these):

**2.1.305**
- ⭐ 🆕 **`sandbox.allowNestedUserNamespaces`** lets sandboxed Linux commands create user namespaces (needed for Chromium/rootless podman). Relevant to Playwright in the sandbox, but the docs warn it can bypass the sandbox's file protections.
- ⭐ 🆕 **`CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS`** — unattended retry mode notices a usage limit lifted before its reset; pairs with last week's watchdog cap for scheduled routines.
- ⭐ ⚠️ **`allowedMcpServers` no longer filters `managed-mcp.json` stdio servers that use `${VAR}` only in `env`** — use `deniedMcpServers` to block one; check managed MCP policy.
- ⭐ ⚠️ Desktop-mounted plugins lose `allowed-tools` when `allowManagedPermissionRulesOnly` is set.
- ⭐ 🐛 Gateway rejecting tool search no longer fails requests (retry without it; regression from 2.1.304).
- ⭐ 🐛 Workflow resume serves completed `pipeline()`/`parallel()` agents from the journal instead of re-running; MCP servers passed by cloud sessions/SDK `setMcpServers` are no longer overridden by same-named settings servers; new worktrees in bare repos start from the default branch and unchanged subagent worktrees are cleaned up.
- 🔧 MCP consent dialogs less prone to accidental Enter-accept; Code Review re-reviews no longer open with LGTM while blocking findings are open; `/usage` warnings become one-line fixes (`f` to apply); `/artifacts` delete keys changed (1/Enter keep, 2 delete).
- 🐛 `/effort` and `/autocompact` honor `modelOverrides` regardless of case or `[1m]` tag; full-disk Bash errors are readable; Claude Tag, VS Code, self-hosted runner fixes (omitted).

**2.1.306**
- 🐛 `claude -p` in cloud sessions no longer reports "Not logged in" when started without the session's env vars.
- ⭐ 🐛 Fixed an API error being masked as "prompt is too long" (plus a needless compaction) in sessions with many MCP tools — relevant if you load many servers.

## 🛠️ 4. Claude Code & MCP ecosystem (community)

- [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) turns a codebase and docs into a queryable knowledge graph through a Claude Code skill, no vector store — a candidate for navigating a large Angular/Spring monorepo without embeddings.
- [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill): install with `npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit`. Each candidate finding is re-checked by a fresh verifier trying to *disprove* it, and findings land as confirmed / needs-validation / rejected. Requires an OS-enforced sandbox if it executes target code.
- [wshobson/agents](https://github.com/wshobson/agents) (~41k★) is a plugin marketplace spanning Claude Code and Codex; [sickn33/agentic-awesome-skills](https://github.com/sickn33/agentic-awesome-skills) catalogs 2,600+ skills with a local MCP server. Both are catalogs — skim for patterns rather than installing wholesale.
