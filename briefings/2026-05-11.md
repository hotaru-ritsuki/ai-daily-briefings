## 8. 🎯 One thing to try today (≤30 min)

**Clone GitHub Spec-Kit and run it against one migration module.**

```bash
# 1. Clone
git clone https://github.com/github/spec-kit.git
cd spec-kit

# 2. Install
npm install -g @github/spec-kit

# 3. In your Angular migration repo, initialize a spec for one module:
cd /path/to/your/migration-repo
spec-kit init --scope src/app/legacy-module

# 4. Walk through the four phases with Claude Code:
#    "Using the spec-kit spec in specs/legacy-module/,
#     generate the migration plan from AngularJS to Angular 18.
#     Follow the Specify → Plan → Tasks → Implement phases.
#     Do not write code until the Plan phase is reviewed."

# 5. Review the generated spec.md and plan.md before letting
#    Claude proceed to implementation. The whole point is that
#    you approve the contract before code is written.
```

Spec-Kit is the most directly useful new repo for migration work this week. It forces the "review the plan before the agent writes code" discipline that prevents wasted agent runs. The four-phase structure maps naturally to migration contracts.
