## 8. 🎯 One thing to try today (≤30 min)

**Set your Auto-Mode baseline *before* it flips your next session.** Auto mode is the default for Pro/Max/Team starting today — for a financial repo, decide deliberately rather than inherit it. In Claude Code:

```bash
claude update
claude            # then, in-session:
/permissions      # review current mode; add deny rules for the irreversible stuff
```

Add explicit `deny` rules for anything you never want auto-run near this repo (force-push, prod deploys, `rm -rf`, external network calls), e.g. in `.claude/settings.json`:

```json
{ "permissions": { "deny": ["Bash(git push --force*)", "Bash(rm -rf*)"] } }
```

Then run a throwaway task on a scratch branch and watch what the classifier waves through vs stops. If the deny list holds and nothing risky slips past, you've got a defensible human-oversight story for the migration repo; if something slips, you've found it on a branch that doesn't matter instead of in a review. Admins can pin a different default via managed settings ([docs](https://code.claude.com/docs/en/changelog)).
