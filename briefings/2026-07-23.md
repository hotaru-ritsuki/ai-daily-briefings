- ⭐ 🔧 `/code-review` now runs as a **background subagent** and keeps stacked slash-commands as its review target — review work stops filling the main conversation. *Matters:* this is my daily review loop; less context pressure per pass.
- ⭐ 🔧 Claude **no longer auto-launches `/deep-research`** — manual invocation only (mirrors the v2.1.215 `/verify` + `/code-review` change and the earlier auto-run clawbacks). *Matters:* fewer surprise long-running turns.
- ⭐ 🔧 **Auto mode** stops popping permission dialogs for dangerous-`rm`, background-`&`, and suspicious-Windows-path cases — the auto-mode classifier adjudicates them instead; plan mode likewise defers un-provably-read-only Bash to the classifier. *Matters:* fewer interrupts in auto mode, but the classifier is now the guardrail — worth watching on a financial repo.
- ⭐ 🔧 Skills with `context: fork` now **run in the background by default** (`background: false` to opt out). *Matters:* forked skills won't block my main loop.
- 🐛 Fixed Windows paths with `\u`-prefixed segments (e.g. `C:\Users\unicorn`) being mangled into CJK; fixed left-arrow discarding the conversation with no undo; fixed a doomed-request retry loop after context overflow; agent-frontmatter hooks now require the agent folder to have accepted workspace trust.
