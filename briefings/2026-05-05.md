### Claude Code — 2 releases ([changelog](https://code.claude.com/docs/en/changelog))

- **2.1.128 (May 4)**
  - 🆕 `--plugin-dir` accepts `.zip` plugin archives
  - ⚠️ MCP: `workspace` is now a reserved server name (existing ones skipped with warning)
  - 🔧 ⭐ MCP reconnection no longer floods conversation with full tool lists — re-announced tools summarized by prefix. ⭐ *Fixes the noise when an MCP server drops and reconnects mid-session.*
  - 🔧 ⭐ `EnterWorktree` creates branches from local HEAD instead of `origin/<default-branch>` — unpushed commits no longer dropped. ⭐ *Critical if you use worktree-based subagents on branches with unmerged work.*
  - 🐛 ⭐ Fixed 1M-context sessions falsely blocked with "Prompt is too long". ⭐ *Was causing unnecessary autocompaction on Opus 4.7.*
  - 🐛 ⭐ Fixed parallel shell calls: failing read-only command no longer cancels siblings. ⭐ *Unblocks safe parallel grep/find patterns.*
  - 🐛 ⭐ Fixed sub-agent prompt cache (~3x `cache_creation` reduction). ⭐ *Direct cost savings on fork-subagent workflows.*
  - 🐛 20+ other fixes: crash on >10MB stdin, vim Space in NORMAL mode, Bedrock region prefix, stale remote-control status lines, `/plugin update` never detecting new npm versions.

- **2.1.126 (May 1)**
  - 🆕 ⭐ `/model` picker lists models from custom gateway's `/v1/models` endpoint. ⭐ *If you proxy through a gateway, models auto-populate now.*
  - 🆕 `claude project purge [path]` — delete all Claude Code state for a project.
  - 🔧 ⭐ `claude auth login` accepts OAuth code pasted in terminal when browser callback fails (WSL2, SSH, containers). ⭐ *Finally fixes the headless auth dance.*
  - 🔧 Removed per-file malware-assessment reminder that caused spurious refusals on binary reads.
  - 🔒 Fixed `allowManagedDomainsOnly`/`allowManagedReadPathsOnly` being ignored when higher-priority managed-settings source lacked a `sandbox` block.
  - 🐛 ⭐ Fixed deferred tools unavailable to skills with `context: fork` and subagents on first turn. ⭐ *Was silently breaking fork-subagent tool access.*
  - 🐛 15+ other fixes: image paste >2000px, OAuth race conditions, stream idle timeout after Mac sleep, CJK text rendering on Windows.

## 8. 🎯 One thing to try today (≤30 min)

**Install the Angular Toolkit MCP server and run a migration audit on your legacy codebase.**

```bash
# 1. Add the MCP server to your Claude Code config
claude mcp add angular-toolkit -- npx @push-based/angular-toolkit-mcp

# 2. Also add the official Angular CLI MCP if you haven't
claude mcp add angular -- npx @angular/mcp

# 3. Start Claude Code in your migration repo and ask:
#    "Scan the src/app directory for deprecated AngularJS patterns.
#     For each, generate a migration contract showing the Angular 18
#     equivalent with type signatures."

# 4. Compare output against your existing migration backlog
```

Two purpose-built MCP servers for Angular migration now exist. The push-based toolkit identifies deprecated usage patterns; the official Angular MCP ensures generated code follows current best practices. Together they close the "is this migration correct?" validation gap.
