## 3. 📋 AI coding tool changelogs

**Claude Code v2.1.237 (Aug 20)** ([changelog](https://code.claude.com/docs/en/changelog)):

- ⭐ 🆕 **"Concise" output style** — Claude leads with results and skips preamble/narration while doing the work just as thoroughly; select under Output style in `/config`. *Matters:* less scrollback noise in unattended/batch runs and cleaner transcripts to audit.
- 🐛 Fixed **prompt caching for sessions behind an LLM gateway or custom base URL** — relevant if I ever route through a proxy for the financial repo.

**Claude Code v2.1.236 (Aug 19)** — a large release; the ones I'd actually use:

- ⭐ 🆕 **`ANTHROPIC_DEFAULT_MODEL`** sets the model new sessions start on; a `/model` pick still overrides and *persists across restarts* (unlike `ANTHROPIC_MODEL`). *Matters:* deterministic model pinning for scheduled runs without hard-locking interactive overrides.
- ⭐ 🆕 **`notify_when_idle` on cross-session `SendMessage`** — one-shot idle ping from another local session, no polling (macOS/Linux). *Matters:* clean hand-off signal for background/parallel agent work.
- ⭐ 🔧 **Sandbox (macOS): wildcard read-deny rules (e.g. `**/.env`) now take precedence inside allowed read regions**, cover matched dirs' contents, and can't be bypassed by renaming the denied file. *Matters:* closes a secret-exfil gap — directly relevant to the regulated codebase.
- 🔧 **Auto-mode hardening:** `Monitor` allow-rules are now set aside so Monitor commands get reviewed like Bash; the classifier uses Claude-API defaults (incl. severity scoring) on Bedrock/Vertex/Foundry and with telemetry off; the git-status check can no longer be fooled by `status.showUntrackedFiles=no`.
- 🔧 `/goal`: an idle session parked behind long background work now self-checks-in at 30 min → 1h → 2h instead of waiting for me.
- 🐛 Slash-command typos now report the error instead of silently running the closest fuzzy match; SIGTERM in print/SDK mode no longer records a fake interrupted turn (exits 143 cleanly) — both matter for scripted/CI invocations.

## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns

- **[Context Engineering: A Practical Guide for AI Agents](https://sourcegraph.com/blog/context-engineering)** (Sourcegraph) — practical pillars for building context pipelines that survive production, with the recommendation to **split intake/lookup/drafting/approval into small auditable sub-agents** rather than one agent carrying the whole task. *~12 min. The auditable-sub-agent framing maps cleanly onto a regulated migration pipeline.*
- **[Effective Context Engineering for AI Agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)** (Anthropic Engineering) — the "just-in-time" pattern (keep lightweight identifiers, load data at runtime via tools) and how CC's own compaction works. *~15 min. The canonical reference for why my subagents should fetch context, not preload it.*
- **[Spec-Driven Development: A Spec-First Approach to AI-Native Engineering](https://developer.microsoft.com/blog/spec-driven-development-ai-native-engineering/)** (Microsoft for Developers) — spec-as-artifact, code-as-build-output; multiple implementors run while a verifier catches conflicts before merge. *~10 min. The pragmatic caveat — "not every task needs a spec; spec overhead is real" — is the part most SDD hype skips.*
- **[The Tower Keeps Rising](https://lucumr.pocoo.org/2026/7/13/tower-keeps-rising/)** (Armin Ronacher, Jul 13) — agents let each engineer ship in parallel *without* the PR/review/interface negotiation that used to keep the team's shared mental model in sync. *~9 min. The structural cost of parallel agent work, not the speed story — worth re-reading before scaling parallel subagents on a shared codebase.*
- **[Agentic Coding Guide 2026: Claude Code, Codex & 5 Patterns](https://www.teamday.ai/blog/complete-guide-agentic-coding-2026)** (Teamday) — a concrete taxonomy of five working agentic-coding patterns across CC and Codex. *~14 min. Useful as a checklist to name the patterns I'm already using ad-hoc; skim for the ones I'm not.*

## 8. 🎯 One thing to try today (≤30 min)

**Pin your unattended-run model and turn on the new Concise output style** — both shipped in the last 48h and both directly improve scheduled/batch sessions.

1. Update: `claude update` (need ≥ v2.1.237).
2. Pin the model your scheduled runs should default to, persistently:
   ```bash
   export ANTHROPIC_DEFAULT_MODEL=claude-opus-4-8   # a /model pick still overrides + persists
   ```
3. In an interactive session: `/config` → **Output style** → **Concise**, then run a throwaway task and compare the transcript density against your usual runs.

Bonus (5 min): from a second terminal, test the new coordination primitive — have a background session `SendMessage` you with `notify_when_idle` and confirm you get exactly one idle ping, no polling.
