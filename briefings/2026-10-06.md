## 4. 🛠️ Claude Code & MCP ecosystem (community deep-dive)

- **Kernel-level agent sandboxing goes mainstream.** [NVIDIA OpenShell](https://blogs.nvidia.com/blog/secure-autonomous-ai-agents-openshell/) splits into three parts — a **Gateway** (sandbox lifecycle + fleet policy), a **Supervisor** (intercepts requests in real time), and the **Sandbox** (Landlock + seccomp-BPF enforcement). The design point that matters: policy is declarative YAML applied *at the OS level*, out of the agent's reach, so "don't read `~/.aws`" is enforced by the kernel rather than hoped for via a system prompt. [Tigera's write-up](https://www.tigera.io/blog/nvidia-openshell-secures-the-agent-who-governs-the-fleet/) is the clear-eyed counterpoint: it secures a single agent well, but fleet-level network governance is still your problem. This is the strongest answer yet to "how do I let an agent loose in a regulated codebase without trusting it."
- **Skills keep consolidating as the portable unit.** [mattpocock/skills](https://github.com/mattpocock/skills) (details in §5) is the TS-native counterpart to last week's `NVIDIA/skills` — same pattern (`SKILL.md` + scripts + one-level-deep refs), different audience. Worth diffing his TDD and diff-review skills against your own `.claude/skills/` before you write another from scratch.
- **MCP tooling churn worth a glance:** [FastMCP v4 "Fort Knocks"](https://gofastmcp.com/updates) is the stable rewrite for the new MCP protocol on a rebuilt Python SDK v2 (old-protocol clients handled by per-connection negotiation) — the baseline to build on if you author MCP servers.

## 8. 🎯 One thing to try today (≤30 min)

Clone Matt Pocock's skills and run his diff-review skill on a real Angular/TS change — a low-friction way to compare a well-authored skill against your own:

```bash
git clone https://github.com/mattpocock/skills.git
# copy one skill into your project, e.g. the TDD or review skill:
mkdir -p .claude/skills && cp -r skills/.agents/review .claude/skills/review
# then in Claude Code, on a branch with a real diff:
#   /review   (or ask it to invoke the review skill on the current diff)
```

Read the `SKILL.md` first — the interesting part is how a TS practitioner scopes acceptance criteria and keeps the body tight. **Deeper follow-up (>30 min):** stand up [NVIDIA OpenShell](https://docs.nvidia.com/openshell/home) with a YAML policy denying credential paths + external network, then run a Claude Code task inside it — the regulated-repo dry run.
