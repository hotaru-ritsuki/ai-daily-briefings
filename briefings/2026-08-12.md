## 3. 📋 AI coding tool changelogs

**Claude Code — v2.1.225–228 (Aug 8–11)** ([changelog](https://code.claude.com/docs/en/changelog)). v2.1.224 was covered 08-07; these four are the net-new diff:

- ⭐ 🐛 **(228) Skills synced from claude.ai are hardened** — they no longer shadow local commands or MCP prompts, descriptions are sanitized/labeled, and bodies can't run `!` commands or expand `@` files. *Why it matters:* closes an injection path if you sync skills down from the web app.
- ⭐ 🐛 **(228) Session cleanup was deleting contents inside a project's memory folder** — fixed. *Why it matters:* silent loss of `CLAUDE.md`-adjacent memory is exactly the kind of bug you don't notice until context is already gone.
- ⭐ ⚠️ **(228) Write tool now allows newer models to overwrite an existing file they haven't read this session** (matching Edit's rules). *Why it matters:* a real behavior change — an agent can now clobber a file without a prior Read, so lean harder on your diff/review gate.
- ⭐ 🆕 **(225) `SendMessage` can start a conversation with a Remote Control session on *another machine* by name** — extends last week's cross-session primitive across machines, with a confirmed recipient never silently swapped for a same-named local session.
- 🆕 **(225)** Gateway **spend-limit** support in the usage warning (names the cap + reset time); **workspace-trust prompt for `claude agents`** in untrusted dirs.
- 🐛 **(227)** Fixed **every Bash command failing under `claude-code-action` with `allowed_non_write_users`** on GitHub-hosted runners — relevant if you run CC in CI. **(226)** was reliability-only.
- 🔧 **(228)** Cross-session messages now render sender + body inline; Vertex AI credential failures now fail in seconds instead of retrying for minutes.

**OpenAI Codex — no new stable.** Latest stable remains **0.147.0 (Aug 7, covered)**. The **0.148.0-alpha** train advanced (alpha.1 → ~alpha.9, Aug 7–12) with no promotion to stable — nothing net-new to act on for daily use ([releases](https://github.com/openai/codex/releases)).

## 4. 🛠️ Claude Code & MCP ecosystem (community deep dive)

- **Superpowers is the community-CC story this week.** Jesse Vincent's [obra/superpowers](https://github.com/obra/superpowers) got accepted into the **official Anthropic plugin marketplace**, which is the real news — it's no longer a copy-a-repo affair. The design worth stealing even if you don't adopt it: skills **trigger automatically** (no `/invoke` by name), and the methodology is opinionated — `brainstorming` refuses to write code until it's asked clarifying questions, `test-driven-development` enforces RED→GREEN→REFACTOR with a watch-it-fail step, and `using-git-worktrees` isolates each implementation on its own branch ([Marc Nuri](https://blog.marcnuri.com/superpowers-claude-code-skills-framework)). The satellite repos — [superpowers-marketplace](https://github.com/obra/superpowers-marketplace) (curated plugins) and [superpowers-skills](https://github.com/obra/superpowers-skills) (community-editable) — mean it's a maintained ecosystem, not one person's dotfiles.

Worth a read specifically because it's a security-conscious org's opinion on what a hardened `.claude/` setup looks like, which maps to my regulated-repo constraints.
