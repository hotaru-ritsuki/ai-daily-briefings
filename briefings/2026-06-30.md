## 3. 📋 AI coding tool changelogs

### Claude Code — v2.1.196 (Jun 29) · [changelog](https://code.claude.com/docs/en/changelog)
One release since the 06-29 briefing's v2.1.195.
- ⭐ 🔒 **`claude mcp list`/`get` no longer spawn `.mcp.json` servers that a repo self-approved via a committed `.claude/settings.json`** — untrusted workspaces now show `⏸ Pending approval`. Closes a quiet local-code-exec path on shared repos. (🐛/⚠️ — a behavior tightening.)
- ⭐ 🔒 **Remote Control is disabled when `ANTHROPIC_BASE_URL` points to a non-Anthropic host** — stops a proxied/self-hosted gateway from driving your session.
- ⭐ 🔧 **`/code-review` token usage cut ~25%** — directly cheaper on every review.
- 🆕 **Org default models** — admins set it in the console; shows as "Org default" / "Role default" in `/model` when you haven't picked one. Plus readable session default-names and Cmd/Ctrl-click file attachments in chat.
- 🐛 Fixes: `claude agents --dangerously-skip-permissions` no longer silently falls back to auto mode; `/deep-research` no longer misreports verifier failures as "all claims refuted"; MCP OAuth `invalid_scope` failures; `/context` showing 0 tokens on Bedrock; PowerShell `git diff`/`git grep` false failures. Stream-idle watchdog is now **on by default** (`CLAUDE_ENABLE_STREAM_WATCHDOG=0` to disable).
