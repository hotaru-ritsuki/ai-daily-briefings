## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns
- **[The Coming Loop](https://lucumr.pocoo.org/2026/6/23/the-coming-loop/)** (Armin Ronacher) — argues some work already runs cleanly in autonomous *loop mode* — code porting, perf benchmarking, security scanning, PoC generation — while cautioning that letting agents loop erodes the human *comprehension* that keeps software maintainable. *Takeaway:* pick loop-mode tasks by whether you can cheaply verify the output, and budget separate time to actually understand agent-produced migration diffs. ~10 min. *(Summarized from search + HN discussion; lucumr 403'd to my fetcher.)*
- **[Spec-Driven Development with AI Coding Agents](https://zeroshot.ghost.io/spec-driven-development-with-ai-coding-agents/)** — the specify→plan→task→implement loop, where the spec is the artifact humans own and review and the implementation is what agents derive from it. *Takeaway:* "drift — confident code that solves the wrong problem" is the real 2026 failure mode; a written spec is the cheapest defense for AngularJS→Angular parity work. ~9 min.
- **[Claude Code's dynamic workflows, road-tested](https://thenewstack.io/claude-code-dynamic-workflows-test/)** (The New Stack) — a hands-on run of the parallel-subagent orchestration (feature shipped Jun 2), including the **Bun Zig→Rust port**: ~750k lines of Rust, **99.8% of the existing test suite passing**, 11 days first-commit-to-merge ([InfoQ](https://www.infoq.com/news/2026/06/dynamic-workflows-claude-code/)). *Takeaway:* the strongest public evidence yet that agent-driven *language/framework migration* is viable when a comprehensive test suite is the oracle — which is exactly the precondition to invest in before your Angular push. ~8 min.
- **[Agentic Engineering Patterns](https://simonw.substack.com/p/agentic-engineering-patterns)** (Simon Willison) — his consolidated position that **deterministic mechanical constraints beat probabilistic behavioral instructions**: if a rule matters, encode it as a hook/check the agent runs, not a CLAUDE.md sentence. *Takeaway:* move your migration invariants (no `any`, no deprecated PrimeNG imports) out of prose and into a lint/hook the agent must pass. ~7 min.
