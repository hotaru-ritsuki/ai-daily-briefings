## 8. 🎯 One thing to try today (≤10 min)

Wire **Playwright MCP** into Claude Code and have the agent drive your app directly:

```
claude mcp add playwright -- npx -y @playwright/mcp@latest
```

Then, in a session on a project with an existing Playwright spec, ask: *"Open the app, reproduce the failing test in the browser, and propose a fix to the selector."* You get agent-driven, a11y-tree-based browser control with no screenshot round-trips. **Alt (bigger payoff, more setup):** [`zilliztech/claude-context`](https://github.com/zilliztech/claude-context) for semantic code search — follow its README quickstart for the `claude mcp add` line plus an embedding backend.
