### Claude Code ([changelog](https://code.claude.com/docs/en/changelog))

**v2.1.181 — Jun 17** (v2.1.180 not published)
- 🐛 ⭐ **Prompt caching not reading on custom `ANTHROPIC_BASE_URL` / Foundry** (per-request attestation token changed every turn) — fixed. ⭐ Silent cost leak for anyone on a gateway; see §1.
- 🐛 ⭐ **Foreground subagents could spawn unbounded nested chains** — now respect the same 5-level depth limit as background subagents. ⭐ Closes a runaway-cost path in the orchestrator-per-feature pattern.
- 🆕 ⭐ **`/config key=value`** sets any setting from the prompt (e.g. `/config thinking=false`); works in interactive, `-p`, and Remote Control. ⭐ Mid-session toggles without editing `settings.json`.
- 🆕 `CLAUDE_CLIENT_PRESENCE_FILE` suppresses mobile push while you're at the machine; `sandbox.allowAppleEvents` (macOS); bundled Bun upgraded to 1.4.
- 🔧 Subagent panel polish (idle auto-hide after 30s, 5-row cap), restyled MCP OAuth page, line-by-line streaming of long paragraphs, auto-retry on mid-thinking connection drops.
- 🐛 `/recap` and forks using the previous model right after a switch; subagent "Thinking" duration showing the parent's elapsed time; **`claude mcp get`/`list` falsely showing `✓ Connected` when `tools/list` fails** (now `! Connected · tools fetch failed`); IDE selection line numbers off-by-one (IntelliJ + VS Code).

**v2.1.179 — Jun 16**
- 🐛 Mid-stream connection drops now preserve partial responses instead of a raw error; **WSL2 mouse-wheel scroll regression (from 2.1.172) fixed**; a `denyRead`/`allowRead` glob over a large tree no longer bloats the Bash tool description into an unusable session on Linux; `Ctrl+O` subagent transcript; faster plugin loading in remote sessions.

## 4. 🛠️ Claude Code & MCP ecosystem (community side)

**The multi-harness single-source pattern just got its reference implementation.** [`wshobson/agents`](https://github.com/wshobson/agents) (~36.6K★, pushed Jun 2026) maintains 84 plugins / 192 agents / 156 skills / 102 commands from a **single Markdown source that compiles to six harnesses** — Claude Code, Codex CLI, Cursor, OpenCode, Gemini CLI, Copilot — each getting idiomatic native artifacts, not lowest-common-denominator translations. Install with `/plugin marketplace add wshobson/agents` (Claude Code) or `npx codex-marketplace add wshobson/agents` (Codex). This is the concrete answer to last week's "dual-target your SKILL.md frontmatter" advisory, and it ships a **`plugin-eval` framework** (static structural analysis + LLM-judge semantic scoring) — the missing quality gate for community skill libraries.

**MCP spec freeze is dated: Jul 28, 2026** ([Medium overview](https://medium.com/@balajibal/mcps-upcoming-2026-release-is-a-big-deal-1d15990f121f)). Headline changes: a **stateless core**, first-class extensions, better authorization, formal deprecation rules, and full JSON Schema for tools. The stateless-core move matters for anyone running MCP behind a gateway — worth reading before authoring new servers this quarter.

**v2.1.181's `claude mcp get/list` honesty fix is a real ops win** — servers that were green-but-broken (connected, but `tools/list` failing) now surface the failure. Re-run `claude mcp list` after upgrading; you may discover a server you thought was healthy never exposed its tools.

## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns

1. **[Effective harnesses for long-running agents](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)** — Anthropic Engineering. The initializer-agent (sets up env once) + coding-agent (incremental progress each session) split, designed to survive across many context windows. The most directly applicable pattern for a multi-week, multi-window migration sweep. ~10 min.
2. **[Datasette agent 0.2a0: human-approved `execute_write_sql`](https://simonwillison.net/tags/claude-code/)** — Simon Willison, Jun 16. First-hand account of adding a user-approval gate before an agent writes to a database — the concrete shape of human-in-the-loop for irreversible tool calls, which maps 1:1 onto write-gating in a financial-data context. ~5 min.
3. **[Loop Engineering: coding-agent loops that run while you sleep](https://explainx.ai/blog/loop-engineering-coding-agents-claude-code-guide-2026)** — Five durable patterns: a loop is cron plus a decision-maker (model picks the next action each tick), every iteration resets to fixed anchor files (PROMPT.md/specs/AGENTS.md), progress lives on disk and in git not in a growing conversation, one discrete unit of work per tick. Good checklist for headless overnight runs. ~9 min.
4. **[9 Parallel AI Agents That Review My Code](https://hamy.xyz/blog/2026-02_code-reviews-claude-subagents)** — HAMY. A concrete Claude Code subagent setup: nine parallel reviewers (linter, security, test-coverage-with-ROI, dedup/complexity) that self-validate before a task is marked done. The pattern that v2.1.178's `Tool(param:value)` + foreground-depth cap now make safe to run at scale. ~8 min.

## 8. 🎯 One thing to try today (≤30 min)

**Install `wshobson/agents` and run its `plugin-eval` against one skill, then re-audit your MCP health.** This is the first community library with a built-in quality gate, and it doubles as a way to verify last week's allowlist-bypass fix.

```bash
# 1. Update both tools:
npm update -g @anthropic-ai/claude-code   # expect 2.1.181
codex --version                           # expect 0.141.0

# 2. Catch any MCP server that was green-but-broken before v2.1.181:

# 3. Add the multi-harness marketplace and install one reviewer plugin:
#    (in Claude Code)
#    /plugin marketplace add wshobson/agents
#    /plugin install code-review@wshobson-agents

# 4. Run the same plugin's eval to see the LLM-judge score before trusting it:
#    inspect plugins/<name> and the plugin-eval/ harness in the repo

# 5. Verify the gateway cache fix actually bit (if you run a gateway):
#    /config <toggle a setting>            # confirm /config works in your shell
#    then watch cache-read tokens climb across turns instead of staying at 0
```

The payoff: a curated, eval-scored reviewer subagent you can wire into the migration loop today, plus confirmation that your gateway is no longer silently disabling prompt caching.
