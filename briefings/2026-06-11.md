## 8. 🎯 One thing to try today (≤30 min)

**Update to Claude Code v2.1.172 and rebuild your migration sweeper as a 2-level sub-agent tree, with Fable 5 at the leaves on the free window.**

```bash
npm update -g @anthropic-ai/claude-code && claude --version   # expect 2.1.172

# 1. Pin Fable 5 + the existing fallback ladder in .claude/settings.json:
#    "model": "claude-fable-5",
#    "fallbackModel": ["claude-opus-4-8", "claude-sonnet-4-6", "claude-haiku-4-5"]
# (Fable is free on Pro/Max through June 22 — exercise the rate-limit ceiling before then.)

# 2. Scaffold a 2-level sub-agent tree (orchestrator → sweeper → verifier):
mkdir -p .claude/agents
cat > .claude/agents/migration-sweeper.md <<'EOF'
---
name: migration-sweeper
description: For a given AngularJS feature module, port to Angular 18 standalone+signals.
  Spawn a verification sub-agent after each component; never commit on red.
tools: [Read, Write, Edit, Bash, SendMessage]
model: claude-fable-5
---
You are the per-feature sweeper. After each ported component, delegate verification
to the `migration-verifier` sub-agent. Surface its `additionalContext` into your
next planning turn; do not commit unless it returns pass=true.
EOF
cat > .claude/agents/migration-verifier.md <<'EOF'
---
name: migration-verifier
description: Run ng test + Playwright for the just-ported component; report structured result.
tools: [Bash, Read]
model: claude-haiku-4-5
---
EOF

# 3. Smoke-test the nesting (the v2.1.172 feature):
claude -p "Use the migration-sweeper agent to port src/app/features/portfolio.
It should spawn migration-verifier after each component change."

# 4. Watch the agents panel; v2.1.172 fixes the stuck-active + 30s phantom-spinner classes.
claude agents --json | jq '.[] | {name, status, parent, depth, waitingFor}'

# 5. While you're here: port one existing claude -p cron to Managed Agents
#    before June 15 (4 days). The scheduling primitive is in the public beta
#    Console; no scheduler infrastructure to maintain.
```

The reason to do this today: every day before June 22 is free Fable-5 capacity, the v2.1.172 depth ceiling makes the 2-level tree real for the first time, and the Managed Agents port is the last clean window before the credit-pool split changes the bill model.
