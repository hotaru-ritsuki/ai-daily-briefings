## 4. 🛠️ Claude Code & MCP ecosystem (community side)

**GitHub MCP Server: secret scanning now GA** (May 5, not previously covered) — The `run_secret_scanning` tool is out of preview for repos with GitHub Secret Protection enabled. A Claude Code agent can check for exposed credentials before commit or PR open, without leaving the MCP context. Worth wiring into any hook that precedes a `git push`. ([GitHub Changelog](https://github.blog/changelog/2026-05-05-secret-scanning-with-github-mcp-server-is-now-generally-available/))

**Salesforce Data 360 MCP Server** (Developer Preview, open-source, stdio) — wraps ~200 REST API ops behind 3 facade tools: `search` (intent-based tool discovery), `payload_examples`, `execute`. The facade pattern is the practical answer to the "200 tools is too many" problem when wrapping a complex API like your Spring Boot backend — expose 3 facades and let the model discover the right one by intent. Requires Java 17 + Maven 3.9. ([Salesforce Developers Blog](https://developer.salesforce.com/blogs/2026/05/introducing-the-data-360-mcp-server-developer-preview))

**Slack MCP Server new tools** (May 13, not previously covered) — adds add reactions, create channel, list channel members, list emoji, read files. If Slack is in your CI/ops notification path, these extend what a Claude Code agent can automate. ([Slack Developer Changelog](https://docs.slack.dev/changelog/2026/05/13/new-mcp-tools/))

**`MessageDisplay` hook (v2.1.152)** — new Claude Code event type that runs before assistant message text renders. Opens a clean pattern for migration workflows: strip token-counting annotations from output, inject formatted migration-status blocks, or gate on a regexp before display.

## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns

**"Agentic Coding in 2026: A Practical Guide for Big Code"** — [Sourcegraph Blog](https://sourcegraph.com/blog/agentic-coding) (~May 21, 10 min)
Distinguishes "vibe coding" from real agentic architecture at enterprise scale: scope the task, provide context infrastructure (code search + internal docs + architectural conventions), set acceptance criteria. The line "techniques that work on a side project fall over on a 2,000-repo monorepo with twelve years of accumulated decisions" is the most precise description of your migration constraints I've seen in a blog post.

**"The Slog is Real: Possibilities and Limitations of AI-Assisted AngularJS Migrations"** — [HeroDevs Blog](https://www.herodevs.com/blog-posts/the-slog-is-real-possibilities-and-limitations-of-ai-assisted-angularjs-migrations) (~8 min)
First-hand account of a research spike: agents fail on whole-project scope but work well on focused sub-tasks with human checkpoints. The 30–40% effort reduction is achievable but requires deliberate architecture, not agentic autopilot. Essential reading before your next migration planning session.

**"Five Claude Code Workflow Patterns"** — [MindStudio Blog](https://www.mindstudio.ai/blog/claude-code-agentic-workflow-patterns) (~7 min)
Practical taxonomy: spec-driven dev, subagent handoffs, eval-gate, staged commit, and context-priming. Useful as a shared vocabulary for reviewing existing Claude Code setup against known patterns.

**"Agentic AI Engineering Playbook: Coding, Review, Ops 2026"** — [DigitalApplied](https://www.digitalapplied.com/blog/agentic-ai-engineering-team-playbook-coding-review-ops-2026) (~12 min)
End-to-end coverage of Claude Code settings → hooks → skills → subagents, focusing on wiring the coding, review, test, and ops surfaces to share a context substrate. More prescriptive than most — treats hooks and subagents as plumbing, not add-ons.

### 6b. General AI engineering reading

**"Project Glasswing and Claude Mythos Show the New AI Security Bottleneck"** — [Penligent](https://www.penligent.ai/hackinglabs/project-glasswing-and-claude-mythos/) (~6 min)
Argues the constraint isn't AI's ability to find vulns — it's the remediation pipeline (who patches, in what order, at what speed). Useful framing if your platform team needs to triage the upstream OSS risk from Mythos findings.
