## 3. 📋 AI coding tool changelogs

### Claude Code — v2.1.186 (Jun 22) · [changelog](https://code.claude.com/docs/en/changelog)
The first entry since v2.1.185. Large release; the ones that matter to you:
- 🐛 ⭐ **`Agent(type)` deny rules and `Agent(x,y)` allowed-types restrictions were not enforced for named subagent spawns** — fixed. Real permission-bypass class; audit any subagent allow/deny config after upgrading.
- 🔧 ⚠️ ⭐ **`!` bash commands now auto-trigger a Claude response to their output** (was context-only). Opt out with `"respondToBashCommands": false`. A default-behavior change — worth knowing before it surprises a scripted session.
- 🆕 ⭐ **`claude mcp login <name>` / `logout <name>`** authenticate MCP servers from the CLI without the interactive `/mcp` menu, with `--no-browser` stdin redirect for completing OAuth **over SSH** — the missing piece for authing MCP servers on a headless regulated host.
- 🔧 ⭐ **Background subagents now surface permission prompts in the main session** (showing which agent is asking; Esc denies just that tool) instead of auto-denying — fixes a silent-failure mode in the orchestrator-per-feature pattern.
- 🔧 ⭐ **`/review <pr>` now uses the same engine as `/code-review medium`** — your agent-PR-review and your interactive review now share one code path; no more two-quality-bars problem.
- 🐛 **Workflow `agent({schema})` subagents abort after 5 schema-validation failures** instead of looping forever — caps a runaway-cost path in the subagent tree.
- ⚠️ **`CLAUDE_CODE_MAX_RETRIES` now caps at 15**; for unattended/cron sessions use `CLAUDE_CODE_RETRY_WATCHDOG` instead. Check your headless env.
- 🔧 Minor: `f` to filter `/workflows` by status; Skills section in `/plugin` Installed; `MEMORY.md` compaction reminder near size limit; skill frontmatter now accepts kebab/snake/camelCase; agent-team teammates inherit the leader's `--effort`.

### OpenAI Codex — `rust-v0.142.0` stable (Jun 22) · [release](https://github.com/openai/codex/releases/tag/rust-v0.142.0)
First new stable since `rust-v0.141.0` (Jun 18). The empty-bodied 0.142-alpha churn (06-21/06-22) has resolved into a real release:
- 🆕 ⭐ **Multi-agent delegation as a configurable mode** — disabled / explicit-request-only / proactive, set at thread *and* turn level. A governance dial for "how much can this agent fan out," which is the bounded-autonomy lever you want documented for an examiner.
- 🆕 ⭐ **Rollout token budgets** — track usage across agent threads, emit remaining-budget reminders, and **abort turns when exhausted**. Hard per-run spend ceiling, first-party.
- 🆕 ⭐ **Indexed web search** — live queries, but page access restricted to **server-approved URLs only**. The regulated-egress shape (search without uncontrolled fetch) for a perimeter deployment.
- 🔧 **Sandbox intent now carries through to remote-execution servers with semantic denial reporting**; exec-server and stdio MCP sessions survive transient disconnects (signed-URL refresh, retry-safe stdin) — continues the 06-18 regulated-remote-exec thread.
- 🔧 Plugins now sort into OpenAI Curated / Workspace / Shared-with-me; `/usage` redeems earned limit-reset credits; reduced startup latency (deferred DNS, warmed caches).

## 8. 🎯 One thing to try today (≤30 min)

**Build a minimal "loop-engineered" runner for one migration component** — the day's theme, made concrete, in a throwaway worktree:

```bash
git worktree add ../mig-loop-test HEAD && cd ../mig-loop-test
cat > SPEC.md <<'EOF'
Migrate the next un-migrated AngularJS component listed in TODO.md to a
standalone Angular 18 signal-based component. Run its Playwright spec.
If green, commit and remove it from TODO.md. Do exactly ONE component, then stop.
EOF
for i in $(seq 1 5); do
  claude -p "Read SPEC.md and TODO.md, do exactly one unit of work, commit, exit." \
    --permission-mode acceptEdits || break
  grep -q . TODO.md || { echo "TODO empty — done."; break; }
done
```

Each iteration is a **fresh context** that reads repo state + the task list from disk, does one unit, commits, exits — the Ralph-style reset Osmani's essay describes. Watch where it drifts: that tells you which guardrail (a tighter SPEC, a verify step, a token cap) the loop actually needs. Then add Codex's `rollout token budget` or `loop-cost` (§4) to bound it.
