### Claude Code — **v2.1.274 (Sep 17)**

The largest release in a week, weighted heavily toward MCP and gateway reliability. Entries worth your attention:

- **⭐ 🐛 MCP transport fixes** — Streamable-HTTP tool calls no longer time out at ~5 min when a longer per-server `timeout` is set; `http` servers that only speak legacy HTTP+SSE now connect even when the first request returns 422/4xx; prompts/resources refresh on list-changed notifications even without a declared `listChanged`. *Why:* removes the most common silent MCP hangs.
- **⭐ 🔧 MCP auth clarity** — a 403 `insufficient_scope` is no longer reported as an expired sign-in; the error now names the missing permissions and points to `/mcp` re-auth. New `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` bounds how long the first non-interactive turn waits for connecting servers (`0` = don't wait). *Why:* fewer misdiagnosed MCP failures in headless/CI runs.
- **⭐ ⚠️ Two Bash-sandbox security tightenings** — commands that loop over or assign certain special shell variables now ask permission, and worktree-isolated sessions now **refuse** Bash with certain nested shell expansions. *Why:* if you run agents under worktree isolation or sandbox in CI, these close real bypasses (a previously-approved wrapper may now prompt).
- **⭐ 🔧 `/code-review` no longer fans out into many subagents** by default on untuned models — it uses leaner inline review prompts. *Why:* cheaper/faster reviews; re-check your review budget.
- **🐛 Reliability:** sessions stuck retrying "unexpected tool_use_id" 400s now self-heal or exit cleanly with a `/rewind` hint; hook-driven sessions (e.g. active `/goal`) compact instead of dying with "Prompt is too long"; a resumed session no longer loses an active `/goal`.
- **🔧 Cloud/web:** a "Compare against" branch picker in the cloud-session diff view; routines skip-and-retry for up to 72h on a missing GitHub connection instead of switching off at the first failed check.
- **🔧 Bedrock/Vertex/Foundry + telemetry-disabled installs** now default to the v2 MCP client and 2026-07-28 negotiation (opt out via `MCP_SDK_GENERATION=v1` / `MCP_PROTOCOL_NEGOTIATION=legacy`).

## 8. 🎯 One thing to try today (≤30 min)

**Install a Playwright skill and have Claude write a test by driving the real UI.** From your project root:

```bash
claude plugin install github.com/lackeyjb/playwright-skill
```

Then prompt: *"Open the [some page] in a browser, exercise [some flow], and write a Playwright test that asserts the behavior you observed."* The point is the loop — the agent *verifies against a live browser first, then writes the test*, instead of hallucinating selectors. Compare the generated spec against one you'd hand-write; if the selectors and assertions hold, you've got a repeatable, team-distributable test-gen skill (vs. per-dev MCP wiring). If `plugin install` isn't your path, clone [willmarple/playwright-skill](https://github.com/willmarple/playwright-skill) and drop it in `.claude/skills/`.
