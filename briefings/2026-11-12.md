## 4. 🛠️ Claude Code & MCP ecosystem (community)

- **Approved commands are a secrets store, and Apiiro measured how often they leak.** Findings from the [CSA note](https://labs.cloudsecurityalliance.org/research/csa-research-note-claude-code-settings-secret-leak-20261108/) and [Apiiro coverage](https://letsdatascience.com/news/apiiro-finds-claude-code-approvals-leak-secrets-into-public-99d400fd):
  - **Scale:** 104,185 public `settings.local.json` files, of which 1,122 contain secrets. A wider scan of shared settings files and chat logs counted 2,539 secrets in 1,994 repos.
  - **What leaked:** database passwords, Supabase service keys, npm/GitHub tokens and AWS keys.
  - **The gap:** Claude Code [gitignores the file when it creates it](https://docs.claude.com/en/docs/claude-code/settings). Apiiro reports that if the file is already tracked, later approvals keep being appended to it with no warning.
  - **Fix:** rotate first, then run `git rm --cached`.
  - **Lesson:** don't put credentials inline. Keep them in env vars, so the allow rule stores `$PGPASSWORD`, not the value.
- **Postman Desktop installed its own plugins into Claude Code and Codex without asking.** [The New Stack](https://thenewstack.io/postman-plugin-coding-agents/) traces it to a developer's logs from Postman 12.33.4 on macOS.
  - [One report](https://dev.ua/en/news/postman-1793785667) says the installer pre-approved its own hook's trust hash, skipping Codex's review step.
  - Postman's uninstall doesn't fully revert the changes.
  - **Takeaway:** other apps on your machine now write to your agent configs. Diff `~/.claude/` and `~/.codex/` from time to time. A dotfiles repo makes that a 10-second check.
- **Google's [Modern Web Guidance](https://github.com/GoogleChrome/modern-web-guidance-src) gives agents current web-platform knowledge.** It's a skills package plus a CLI covering about 250 platform features: `search` finds guides, `retrieve` fetches one, and `legacy-scan` flags outdated patterns.
  - It steers agents from polyfills and heavy JS toward native APIs: CSS layout, forms, a11y, performance.
  - It's directly useful against PrimeNG-era CSS and form habits. It's a CLI, not an MCP server, so it's cheap on context.
- **Parallel-agent desktop apps keep multiplying after Meta bought Conductor.** [Paradev](https://github.com/ParadevAI/Paradev) (formerly Superset) is MIT-licensed:
  - Each task gets its own worktree.
  - Diff review, PR checks and an in-app browser with port detection are built in.
  - It ships an **MCP server, so an agent can create and manage other agents' workspaces**.
  - It supports Claude Code, Codex, Cursor Agent and about 20 more.
  - [paseo](https://github.com/getpaseo/paseo) does similar orchestration from desktop and mobile.
- **Antigravity `/swarm` shows a pattern you can copy** ([details](https://cellcog.ai/blog/google-antigravity-swarm/)):
  - A coordinator creates named workers in isolated worktrees, plus one `@verifier` per 2–4 workers.
  - Verifiers run tests and send defects back to the worker that owns the code, over a shared message board.
  - In Claude Code you can approximate this with a `verifier` subagent definition and a shared `tasks.md`, instead of having the main agent review everything.

4. **[ParadevAI/Paradev](https://github.com/ParadevAI/Paradev)** (~16.2k ★, MIT). A worktree-per-task desktop app for running about 25 CLI agents in parallel, with an MCP server and an SDK.

## 8. 🎯 One thing to try today (≤30 min)

**Run `shadcn/improve` on one Angular feature branch, with Fable planning and a cheaper model executing.**

1. In a scratch clone of your Angular repo, run `npx skills add shadcn/improve`, then start Claude Code with `/model claude-fable-5-2`.
2. Run `/improve branch` to audit only what your current branch changes. Read the plan files it writes to `plans/` and check that each one stands alone: files, acceptance criteria, test command.
3. Pick the smallest plan. Switch to Sonnet or Haiku with `/model` and run `/improve execute plans/<file>.md`. It works in a disposable worktree, and Fable reviews the result.
4. Compare: did the cheap executor pass `ng test --watch=false` and your Playwright smoke test on the first try?

**Success criteria:** at least one plan carried out correctly by the cheaper model. If so, keep the plan template as `.claude/commands/plan-for-cheap.md`.

*Side task (5 min, do it first):* run `git ls-files | grep 'settings.local.json'` in every repo. If anything shows up, rotate the credentials it holds, then run `git rm --cached .claude/settings.local.json` and add the file to `.gitignore`.

## 9. 📣 Shareable angle

**Hook:** "Your agent's allowlist is a credential store. Treat it like one."
**Draft:** This week, 1,122 public repos turned out to contain Claude Code approval files with live passwords and keys, because "don't ask again" saves the whole command, secrets included. The fix isn't fewer approvals; it's never typing a secret where an agent can save it: env vars, a secrets manager, and a pre-commit hook that checks `.claude/`.
