## 3. 📋 AI coding tool changelogs

### Claude Code
- **v2.1.216 (Jul 20)** — 🆕 ⭐ new `sandbox.filesystem.disabled` setting: skip filesystem isolation while *keeping* network-egress control. *Matters:* lets me run agents against my local checkout without FS sandboxing but still block exfiltration — a middle sandbox tier I didn't have.
- **v2.1.216 (Jul 20)** — 🔧 ⭐ fixed a quadratic slowdown in long sessions where message normalization cost grew with turn count (multi-second stalls, slow resumes). *Matters:* my MCP-heavy sessions are exactly the long-session case.
- **v2.1.216 (Jul 20)** — 🐛 worktree-isolation hardening (subagents could redirect git into the shared checkout via `git -C`/`GIT_DIR`; `.claude` symlink could redirect workflow/scheduled-task writes outside the project); `/rewind` no longer restores through symlinks/hard links; auto mode no longer denies commands on a stale "HTTP 401" after token rotation.
- **v2.1.217 (Jul 21)** — 🔧 ⚠️ ⭐ concurrent-subagent cap (default 20) + subagents no longer spawn nested subagents by default. *Matters:* see §1 — behavior change for fan-out workflows.
- **v2.1.217 (Jul 21)** — 🐛 ⭐ fixed a memory leak where truncated MCP tool outputs kept the full untruncated result in memory all session; fixed Opus 4.8 auto-compact never firing on Bedrock; fixed Windows auto-update leaving `claude.exe` missing. 🆕 minor: `:emoji:` shortcode autocomplete.
