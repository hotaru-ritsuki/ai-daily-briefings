## 8. 🎯 One thing to try today (≤30 min)

**Build a minimal Cloudflare-style multi-reviewer as a Claude Code dynamic workflow.** With v2.1.202's new setting in play, run `/config` → set **Dynamic workflow size**, then prompt:

> *"Author a dynamic workflow that reviews the current PR diff across 4 dimensions — correctness, security, Angular/RxJS pitfalls, and test coverage — runs each as its own agent, verifies every finding with a skeptic pass, and returns only confirmed findings, most-severe first."*

Use [Cloudflare's post](https://blog.cloudflare.com/ai-code-review/) as the design reference for the reviewer roles. Or, to see the built-in version first: **`/code-review high <pr#>`**. Either way you get a repeatable, costed review harness for migration PRs in one sitting.
