## 4. 🛠️ Claude Code & MCP ecosystem (community)
- **[NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology)** (Apache-2.0):
  - **What it does:** builds an ontology (terms, relationships, reviewed SQL attributes) from database metadata, and people certify it before agents use it.
  - **MCP side:** it ships an MCP server (`uvx --from "git+…#subdirectory=mcp" auto-ontology-mcp`) with read-only tools, three agent skills for coding agents, and setup for Cursor and Claude Desktop.
  - **Why it's interesting:** answers come back with the SQL and steps, so they can be audited, and queries run under the caller's own database permissions.
  - **Caveat:** the full stack needs Docker Compose plus an NVIDIA API key, so this is heavier than a typical `npx` server.

  Per the README; I haven't run it.
- **[jakubkrehel/skills](https://github.com/jakubkrehel/skills)** (~10.9k★, +1.9k this week): 14 interface skills packaged as a Claude Code plugin (`/plugin marketplace add jakubkrehel/skills`).
  - Most useful for you: `better-accessibility` (keyboard, focus, ARIA, WCAG 2.2) and `interface-review`, which you invoke yourself to review a branch or PR for UI regressions.
  - It isn't tied to any framework, so it should work on Angular templates. That's untested.
- **[scenario-labs/skills](https://github.com/scenario-labs/skills)** (trending) is a template for pairing skills with a remote MCP server. The skills teach the agent the workflow, and `claude mcp add --transport http scenario https://mcp.scenario.com/mcp` provides the tools. The domain (images, video, 3D) is irrelevant to you; the skill-plus-MCP packaging is the part worth copying.
- **Pattern to notice:** this week's trending list is dominated by design/UI skill packs (hallmark, impeccable, jakubkrehel). Skills are becoming the way to share taste and conventions, while MCP servers carry capabilities. That's the same split as Anthropic's [steering guide](https://claude.com/resources/articles/steering-claude-code-skills-hooks-rules-subagents-and-more) covered yesterday.

## 8. 🎯 One thing to try today (≤30 min)
**Run an accessibility and UI-regression review of one PrimeNG feature with a skill pack, and compare it with your own review.**
1. In a scratch branch of your Angular app, start Claude Code and run `/plugin marketplace add jakubkrehel/skills`, then `/plugin install interfaces@interfaces`.
2. Pick one dense screen, such as a `p-table` with filters plus a `p-dialog` form. Ask: *"Use the better-accessibility skill on `src/app/<feature>/` — keyboard order, focus trap in the dialog, ARIA on the table filters. Report only; no edits."*
3. Run `/interface-review` on your last UI PR's branch to see what it would have caught.
4. Check the findings against reality: tab through the screen yourself, and run a Playwright `@axe-core/playwright` scan if you have one.

**Success criteria:** at least one real issue you hadn't spotted, and a false-positive rate you'd accept in CI. If it passes, turn the prompt into a `.claude/commands/a11y-review.md` command scoped to `*.html` and `*.component.ts`.
