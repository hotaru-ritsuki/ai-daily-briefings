## 3. 📋 AI coding tool changelogs (must-have)

### Claude Code — **v2.1.273 (Sep 15)**

A large, almost entirely bug-fix/reliability release. The entries worth your attention:

- **⭐ 🐛 Auto-compact fired too early** — the context meter and auto-compact counted advisor-tool turns at ~2× their real size, tripping compaction at about half the real window. Fixed. *Why:* directly explains premature compaction in long sessions.
- **⭐ 🐛 Two sandbox/permission security fixes** — Bash commands the permission checker can't fully analyze no longer skip the prompt under `permissions.blockReadsOutsideWorkingDirectories`, and a subshell hiding a dangerous `rm` in bypass mode is now caught. *Why:* if you run agents under bypass/sandbox in CI, these were real holes.
- **⭐ 🔧 Reverted the 2.1.268 deny-rule check on unanalyzable Bash lines** (`eval`, `env -C`) — commands like `time -p make build` prompt again instead of being wrongly denied. *Why:* if a build/test wrapper started getting blocked recently, this restores it.
- **⭐ 🐛 Subagent/background-agent false failures** — a subagent whose final streamed reply omitted token usage or a model id was reported as failed with its result dropped; also fixed SDK/`stream-json` dropping a backgrounded subagent's remaining messages. *Why:* fan-out reliability — silent lost results are the worst failure mode.
- **🆕 Gateway hint headers** (`x-claude-code-request-class`, `-agent-type`, `-compaction`, …) via `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`, for routing/observability at an LLM gateway.
- **🆕 Fork a `--remote-control` / `/remote-control` session from the Claude app** as a background session on your machine.
- **🔧 MCP:** a disconnect that exhausts auto-reconnect now notifies and points at `/mcp`. **🔧 Bedrock/Vertex/Foundry** auto mode now uses the *local* classifier by default (`CLAUDE_CODE_AUTO_MODE_SERVER=1` to opt back into server-side).
- **🐛 Scheduled tasks** no longer run in the wrong session after `.claude/scheduled_tasks.json` is copied into another folder (e.g. a new worktree). **🐛 Skills** synced from claude.ai now move to recoverable trash (not silently persist) when an org turns Skills off.
- **🔧 Code Review:** merging the base branch into a PR that had "Additional findings" no longer forces a full re-review; a whole `REVIEW.md` is no longer discarded over an @-mention or wrapped code span.

## 4. 🛠️ Claude Code & MCP ecosystem (community deep-dive)

The theme this week is **AI-in-CI and packaged regulated workflows** — the community catching up to what §3/§6a make official.

- **Test-impact-analysis is becoming a first-class agent-era concern.** Anthropic's CI post (§6a) is the marquee, but the pattern for the rest of us is the same: as agents multiply PRs, blanket test runs stop scaling, and *selecting* the affected test subset per change becomes the gate.
