## 8. 🎯 One thing to try today (≤30 min)
**Measure what your MCP tool schemas cost you, then try the code-mode alternative.**
1. In a project with your usual MCP servers (e.g. Playwright, GitHub), run `/context` in Claude Code and note the tokens under MCP tools.
2. Disable the heaviest server (`/mcp`), and compare. If it's several thousand tokens, that's the baseline Codemode-style approaches aim to remove.
3. For a code-mode comparison, read Cloudflare's [Code Mode docs](https://developers.cloudflare.com/agents/model-context-protocol/codemode/) and try the same task through a single "run code" tool.
Success criterion: same task result with fewer tokens and a log you can read afterwards.
