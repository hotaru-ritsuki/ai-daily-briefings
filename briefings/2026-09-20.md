## 1. 🔥 Top 3 things I shouldn't miss today

- **⚡ Cloudflare open-sourced [`security-audit-skill`](https://github.com/cloudflare/security-audit-skill)** (16.8k stars, MIT, trending +3k/day) — a six-phase agent skill that runs an *adversarial* audit: the agent that finds an issue never validates it, and findings land as schema-checked JSON tagged `confirmed` / `needs_validation` / `rejected`. Why it matters to you: a drop-in security pass for your Spring Boot/Angular repos via `npx skills add`, and the discoverer-never-validates pattern is directly stealable for reviewing your own agent-generated PRs. §8 runs it in <30 min.
- **⚡ Skill supply-chain risk is now measured, not hypothetical** — a scan of **22,511 public skills surfaced 140,963 findings**, and Snyk's earlier ToxicSkills study put **13.4% of audited skills at a critical issue** ([The New Stack](https://thenewstack.io/ai-agent-skills-security/)). Why it matters: since CC 2.1.275 syncs the skills you enable on claude.ai straight into terminal sessions, an unaudited skill is now a dependency with code-execution rights on every box you sign into — audit what you've turned on.
- **Anthropic shipped [Messages API on-demand compaction](https://platform.claude.com/docs/en/build-with-claude/compaction) (beta, `compact-2026-09-04`, in `anthropic-sdk-python` v1.6.0)** — you send a `compaction` param, get back a *signed* compaction block, and replay it in place of prior turns, keeping recent turns (and preserved thinking) verbatim. Why it matters: if you build agents on the API in Java/TS, you now control context compaction deterministically instead of leaning on client-side auto-compact ([release notes](https://platform.claude.com/docs/en/release-notes/overview)).

## 4. 🛠️ Claude Code & MCP ecosystem (community deep dive)

The week's real community shift is **skills becoming the packaging unit — and skill *supply chain* becoming the pressing problem.** Three threads:

1. **"Deploy a skill" is displacing "build an agent."** The fastest-growing repos this week are all specialized, production-grade *skills* rather than generic frameworks — [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) (97k) as a general engineering-skills set, and Cloudflare's audit skill (§1) as the security exemplar. `npx skills add <repo> --skill <name>` is emerging as a harness-agnostic install path (works across CC/Codex/Cursor, not Claude-branded).
2. **Skills are unaudited dependencies with code-exec rights.** They bundle scripts that run on your machine, so the [22,511-skill audit](https://thenewstack.io/ai-agent-skills-security/) is the wake-up: treat a community skill like any npm package and read the source before enabling — doubly so now that claude.ai-enabled skills flow to the terminal. The practical stack people recommend is CC's built-in `/security-review` (reasons about data flow, free) *paired with* a deterministic scanner like the Semgrep MCP server for repeatable findings ([ssojet roundup](https://ssojet.com/blog/ai-agent-security-qa-skills), [adversa.ai resources](https://adversa.ai/blog/top-ai-coding-agent-security-resources-september-2026/)).
3. **Verified-findings-as-a-trust-layer.** Cloudflare's schema-validated `confirmed/needs_validation/rejected` output is the interesting design move — machine-readable findings a CI gate can consume without a human re-reading raw agent prose. Worth copying for your Playwright/test-automation reviews.

## 8. 🎯 One thing to try today (≤30 min)

**Run Cloudflare's verified security-audit skill on one repo.** Pick a Spring Boot service or an Angular app you know well (so you can sanity-check the findings):

```bash
npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit
# then, in your agent session:
#   "security audit this codebase"
```

Read the JSON output, not just the markdown report: look at how it separates `confirmed` from `needs_validation`, and note which findings survived the adversarial validator. Payoff: a real security pass on a repo you own, *and* a working example of the discoverer-never-validates pattern you can port into your own review skills so agent findings arrive pre-triaged instead of as unverified prose. (Review the skill's bundled scripts first — per §4, it's a dependency with code-exec rights, even coming from Cloudflare.)
