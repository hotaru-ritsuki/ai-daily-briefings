## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns

- **[Stop Making TUIs](https://sockpuppet.org/blog/2026/08/20/stop-making-tuis/)** — Thomas Ptacek (~6 min). The cost of a "good enough" native GUI has collapsed to near-zero when an agent uses a framework the blessed way, so building terminal UIs for personal/internal tools is now a choice against ergonomics, not for pragmatism. Willison's [companion note](https://simonwillison.net/2026/Aug/21/stop-making-tuis/) adds the agent-workflow angle. *Takeaway:* re-test your "it's just a CLI" reflex for internal tooling.
- **[Conceptual integrity and counting lines of code](https://simonwillison.net/2026/Aug/19/conceptual-integrity-and-counting-lines-of-code/)** — Simon Willison (~5 min). Why LOC is an actively misleading metric in the agent era, and how conceptual integrity (one coherent design vision) matters more when agents can generate volume cheaply. *Takeaway:* review agent output for design coherence, not diff size.
- **[Context Engineering: A Practical Guide for AI Agents](https://sourcegraph.com/blog/context-engineering)** — Sourcegraph (~10 min). Curating the smallest high-signal token set as the core discipline, with concrete tactics for keeping subagent contexts scoped before they degrade. *Takeaway:* pairs directly with the ACE delta-context pattern in §5.
- **[ACE: Evolving Contexts for Self-Improving LLMs](https://sambanova.ai/blog/ace-open-sourced-on-github)** — SambaNova (~8 min). The Generator/Reflector/Curator split and why incremental delta updates beat monolithic context rewrites on latency and quality (cites +10.6% on agent tasks vs baselines — vendor-reported, treat as directional). *Takeaway:* a named architecture for the "self-improving playbook" idea you can actually clone.

### 6b. General AI engineering reading

- **[Anthropic will embed watermarks in AI outputs](https://www.artificiallawyer.com/2026/08/13/anthropic-will-embed-watermarks-in-ai-outputs/)** (~4 min). All Claude outputs from Aug 2 carry invisible machine-readable marking to satisfy EU AI Act Art. 50(2). *Takeaway:* if you generate customer-facing content via Claude in a regulated product, provenance marking is now handled upstream — but verify your downstream transforms (PDF render, Handlebars templating) don't strip it.

## 8. 🎯 One thing to try today (≤30 min)

**Test the "Stop Making TUIs" thesis on your own stack.** Pick one thing you currently do via a terminal script or ad-hoc CLI and have Claude Code one-shot it as a real GUI instead:

```
claude "Build a single-file standalone Angular 20 component using PrimeNG that <does my X — e.g. previews a Handlebars template against sample JSON>. Make it runnable with `ng serve`, no backend, mock the data."
```

The point isn't the tool — it's calibrating how good agent-built GUIs now are *in your blessed frameworks* vs. your assumption that a GUI is "not worth it." If it's usable in one shot, that reflex is out of date. (Prefer the memory angle instead? `git clone https://github.com/TencentCloud/TencentDB-Agent-Memory` and run its local pipeline over a repo to see Code-Graph memory in action — zero external API.)
