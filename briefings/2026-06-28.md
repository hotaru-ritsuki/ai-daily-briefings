## 8. 🎯 One thing to try today (≤30 min)

**Re-auth github-mcp-server v1.5.0 with built-in OAuth and turn on its code-quality findings tool.** Pull the latest server, drop your `GITHUB_PERSONAL_ACCESS_TOKEN` from the MCP config, and let the STDIO server do the OAuth handshake on first connect — then point Claude Code at a migration PR and ask it to use the new findings tool for review. Start here:

```bash
# in your Claude Code MCP config, update the github server, then:
claude mcp restart github   # triggers the OAuth login flow on reconnect
```

Release notes + setup: <https://github.com/github/github-mcp-server/releases>. Bonus if you have extra time: copy Grinstead's pattern (§6a) and add a `migration-verifier` subagent via `/agents` whose only job is to approve/reject another agent's diff against acceptance criteria.
