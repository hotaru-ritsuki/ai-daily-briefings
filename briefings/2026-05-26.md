## 4. 🛠️ Claude Code & MCP ecosystem (community)

**[anthropics/cwc-long-running-agents](https://github.com/anthropics/cwc-long-running-agents)** is the companion repo from Code w/ Claude London (May 2026) that shipped the patterns from Anthropic's two harness engineering posts as standalone, readable files. Not previously covered:

- **PROGRESS.md checkpointing** — the agent maintains a structured log at every git commit; each restart re-reads it to reconstruct state without context overflow. Directly solves "agent loses the thread on session restart" that kills overnight migration runs.
- **Fresh-context evaluator** — a separate subagent with no Write/Edit tools grades work from a clean context window that never saw the build. The eval isn't biased by the generation agent's full context.
- **verify-gate.sh hook** — PostToolUse hook that blocks execution if the agent tries to skip its own verification step.

These three files are readable in 20 minutes and applicable directly to long-horizon migration work.

The patterns in cwc-long-running-agents are the operational implementation of Anthropic's context engineering principles (covered in the May 8 briefing) — worth re-reading that if you haven't applied any of it yet. The fresh-context evaluator and PROGRESS.md pattern are specifically for the scenario the May 8 article didn't address: crossing context window boundaries across sessions.

**[anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)** (15.8K stars, +1,441 today) — Anthropic's official plugin bundles for 11 job functions (Engineering, Legal, Finance, Marketing, Support, Product, Data Analysis, and more). The Engineering plugin covers standups, code review, architecture decisions, incident response, and debugging — complete bundles (skills + subagents + slash commands + MCP connectors) intended as customizable starting points.
