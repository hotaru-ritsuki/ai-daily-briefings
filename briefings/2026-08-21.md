## 4. 🛠️ Claude Code & MCP ecosystem (community)

- **"Retrieval-as-tools" (A-RAG) is the reframe worth internalizing** — instead of stuffing retrieved docs into context at pipeline time, expose *three tools* (keyword search, semantic search, chunk-read) and let the agent pull incrementally per reasoning step ([Builder Radar, wk of Aug 16](https://buttondown.com/Builder-Radar/archive/builder-radar-week-of-august-16-2026/)). For an app dev this is the cleaner MCP-server shape for our own knowledge bases than a monolithic RAG endpoint.
- **The "meta-harness" cluster is the dominant GitHub theme this week** — tools that sit *above* individual coding agents to orchestrate/switch between them, several clearing 50k★; **context-compression** is emerging as its own layer (`headroom`, `context-mode`) ([Builder Radar](https://buttondown.com/Builder-Radar/archive/builder-radar-week-of-august-16-2026/)).
- **Shared `.claude/` config repos worth cribbing:** [`nolte/claude-shared`](https://github.com/nolte/claude-shared) (skills+agents symlinked into `~/.claude`, settings merged — kills per-repo drift) and [`alexeygrigorev/.agents`](https://github.com/alexeygrigorev/.agents) (one repo spanning Claude Code **and** Codex — matches my cross-harness setup).
- **Angular's own MCP server** (v20.2+) exposes `get_best_practices`, `find_examples`, and — the useful one — `onpush_zoneless_migration` (analyzes the component dependency graph before applying zoneless CD) plus an experimental `modernize` tool ([angular.dev/ai/mcp](https://angular.dev/ai/mcp)). In my stack; §8.
