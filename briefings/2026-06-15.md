### Claude Code ([changelog](https://code.claude.com/docs/en/changelog))

**v2.1.177 — June 13** (the politically loaded one)
- ⚠️ ⭐ **Access to Claude Fable 5 temporarily suspended for all users per US government directive.** ⭐ Selecting Fable 5 in `/model` silently falls back to Opus 4.8.
- 🐛 macOS background agents now appear as "Claude Code" in Privacy & Security and keep permission grants across upgrades — long-standing irritant, finally fixed.
- 🐛 ⭐ Stateful MCP server reconnect loop fixed (v2.1.147 regression — anyone running long-lived MCP servers behind a flaky network was hitting this).
- 🐛 ⭐ API gateway receiving user OAuth credentials fixed — credential-leak class bug, sweep transcripts if your shop runs a custom gateway.

**v2.1.176 — June 12**
- 🆕 Session titles generated in the conversation's language (pin via `language` setting).
- 🆕 `footerLinksRegexes` setting for regex-matched link badges in the footer — useful for surfacing Jira/Linear ticket IDs from CLAUDE.md context.
- 🔧 ⭐ Bedrock credentials from `awsCredentialExport` now cached until `Expiration` instead of a hardcoded 1 hour — the platform team will care.
- 🐛 ⭐ `availableModels` enforcement tightened — alias picks can no longer be redirected to a blocked model via `ANTHROPIC_DEFAULT_*_MODEL` env vars; `/fast` refuses to switch outside the allowlist.
- 🐛 Auto mode failing on Fable 5 for orgs without Opus 4.8 enabled — fixed (academic now).
- 🐛 `/cd` + worktree moves no longer report previous directory's git branch.
- 🐛 Linux sandbox failing to start when `.claude/settings.json` is a symlink with an absolute target — fixed.

**v2.1.175 — June 12**
- 🆕 ⭐ `enforceAvailableModels` managed setting — the allowlist now constrains the Default model too, and user/project settings can't widen a managed list. ⭐ The compliance hook the enterprise-MCP-policy track has been moving toward all month.

**v2.1.174 — June 12**
- 🆕 `wheelScrollAccelerationEnabled` setting for fullscreen mode.
- 🐛 ⭐ Skill hot-reload no longer re-sends the *entire* skill listing when one skill changes — silent token waste fixed, matters once your `.claude/skills/` has dozens of entries.
- 🐛 Workflow tool `agent()` sub-agents missing per-agent attribution headers — fixed.
- 🐛 Pre-warmed background workers failing with "Could not resolve authentication method" when claimed after idle — fixed.
- 🆕 \[VSCode] Usage attribution in `/usage` dialog.

## 8. 🎯 One thing to try today (≤30 min)

**Audit your `.claude/` tree for silent Fable→Opus fallbacks and your headless runners for credit-pool drift.** Today is the one day where both moves *have* to land.

```bash
# 1. Confirm you're on the suspension-aware build:
npm update -g @anthropic-ai/claude-code && claude --version   # expect 2.1.177

# 2. Sweep every plugin/skill/agent that silently routes to Fable:
grep -RIn "claude-fable-5" ~/.claude/ .claude/ 2>/dev/null
# Replace each match with claude-opus-4-8 (or remove the pin to let your
# Default ladder + v2.1.166 fallbackModel handle it). Commit per plugin.

# 3. Verify the Agent SDK credit-pool opt-in landed and check today's burn:
claude /usage              # look at the new "Agent SDK Credits" line
# Then, in any repo using claude-code-action:
gh run list --workflow=claude-code-action.yml --limit 10
# Open the latest run; any `quota_exceeded` in the logs = opt-in didn't land
# or overflow billing is off. Anthropic's opt-in is the one-time email
# click-through from June 8 — auto-refreshes thereafter.

# 4. While you're here: pin the durable model ladder explicitly. With
# Fable gone, your settings.json should be:
#   "model": "claude-opus-4-8",
#   "fallbackModel": ["claude-sonnet-4-6", "claude-haiku-4-5"]
# Drop "claude-fable-5" from any availableModels allowlist —
# v2.1.175's enforceAvailableModels makes this a managed-policy lever now.
```

Why today specifically: the credit-pool transition is *the* one-shot inflection in subscription accounting, and the Fable suspension means every silent fallback in your config is now running at the wrong cost/latency profile. Both fix in under 30 min; both leak silently if you wait.
