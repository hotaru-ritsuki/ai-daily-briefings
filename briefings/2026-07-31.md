## 8. 🎯 One thing to try today (≤30 min)

**Wire Angular's own CLI MCP server into Claude Code and have the agent run one *official* migration on a single component.** In a scratch branch:

```bash
claude mcp add angular -- npx -y @angular/cli mcp
```

Then, in a session, ask the agent to invoke the Angular MCP's migration tools on one narrow target — e.g. move a single component to zoneless via `onpush_zoneless_migration`, or generate one standalone component from an existing NgModule declaration. The point isn't the migration — it's feeling the difference between the agent running Angular's *own tested schematics* (deterministic, upgrade-aware) versus free-handing edits. If it holds up, it becomes a repeatable, reviewable step in the real sweep — and it composes with the verification-loop skill from last week. (Needs Angular CLI v20.2+, Node 18+; [docs](https://angular.dev/ai/mcp).)
