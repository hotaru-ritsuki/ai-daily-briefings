Concrete sweep:

```bash

# fallback explicit (use opus-4-8 in the pin) so future Fable-restoration doesn't surprise?
```

The corollary discipline: **`.claude/` front-matter is now a runtime-coupling surface, not just config.** Any model pin should be reviewed against availability the same way a Maven/npm version pin would be reviewed against an unmaintained dependency.

The clearest single read for non-AI-team stakeholders on the suspension's operational implications.

**`aradotso/trending-skills` updated yesterday with `understand-anything-knowledge-graph`** ([repo](https://github.com/aradotso/trending-skills)) — Claude Code plugin that runs a multi-agent pipeline over your project, builds a knowledge graph of every file/function/class/dependency, and opens an interactive React dashboard for visual exploration.
