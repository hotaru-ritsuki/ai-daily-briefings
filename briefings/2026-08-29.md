## 3. 📋 AI coding tool changelogs

Cutoff: entries published since the 2026-08-28 briefing (which covered CC through v2.1.250).

**Claude Code v2.1.251** (Aug 28) — [changelog](https://code.claude.com/docs/en/changelog). The substantive drop (v2.1.250 was a content-free stub). Highlights:
- ⭐ 🆕 **`PreModelSwitch`/`PostModelSwitch` hooks** — block, confirm, or annotate a model switch; `SessionStart` resume hooks now get session staleness + estimated re-cache cost. *Why it matters: you can now gate/log every Opus↔Sonnet switch in a governed repo.*
- ⭐ 🆕 **Foreground subagent streaming to Remote Control** — a foreground subagent's live tool calls/results now stream to remote clients (background subagents still status-only). *Useful when driving CC from the web/mobile surface.*
- ⭐ 🔧 **`/cost` now shows a per-session prompt-cache line** (hit ratio, misses, tokens re-cached, warm/cold) + a `prompt_cache` status-line object. *Direct visibility into the caching spend you've been tuning.*
- ⭐ 🔧 **`CLAUDE_CODE_SUBAGENT_MODEL` now sets the *default* subagent model** rather than overriding everything — an agent's `model:` and explicit per-spawn model win. *Fixes a footgun where the env var silently overrode subagent definitions.*
- ⭐ 🔧 **`/effort` saves per-model**, and seat-based **Enterprise default model is now Opus 5**.
- 🐛 Several genuine security fixes: file tools following a **symlink swapped inside the working dir after the permission check** (read/write escape); plugin commands pointing **outside the plugin dir** (path traversal); Grep/Glob not applying `Read(...)` **deny rules through symlinked search paths**; project settings escalating **beta tracing / raw-body logging**.
- 🐛 Opus 5 `effort xhigh/max` + thinking-off no longer errors (`effort` downgraded to `high`); conversations no longer stick on "text content blocks must be non-empty" after a thinking-only turn.
- ⚠️ Behavior change: **server-managed settings that terminate sandbox TLS, inject credentials, or weaken sandbox isolation now require approval** before applying; `ANTHROPIC_CUSTOM_HEADERS` setting credential/routing headers now prompts.

## 8. 🎯 One thing to try today (≤30 min)

**Wire a `PreModelSwitch` hook to log/gate model switches.** New in v2.1.251 — a low-friction way to see how often your sessions silently escalate Sonnet→Opus (and what it costs). First step after `claude update`:

```bash
claude update && claude --version   # confirm 2.1.251+
```

Then add to `.claude/settings.json`:

```json
{ "hooks": { "PreModelSwitch": [{ "hooks": [{ "type": "command",
  "command": "echo \"model switch: $CLAUDE_FROM_MODEL -> $CLAUDE_TO_MODEL\" >> ~/.claude/model-switches.log" }] }] } }
```

Run a normal task, then `cat ~/.claude/model-switches.log` and open `/cost` to see the new per-session prompt-cache line. In 20 minutes you'll know whether your effort/model defaults are costing you re-cache churn — and can flip the hook to `confirm` if you want to gate escalations in the regulated repo.
