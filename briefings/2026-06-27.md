## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns
- **[Harness design for long-running application development](https://www.anthropic.com/engineering/harness-design-long-running-apps)** — Anthropic Engineering. A planner decomposes the spec, a generator builds one task per context window and hands off structured artifacts (JSON feature specs, a `claude-progress.txt`), and a separate evaluator judges — using **context resets, not compaction**, to prevent drift. The sharpest insight: as Opus 4.5/4.6 improved, they *deleted* context resets and then sprint-decomposition entirely. Harness complexity is inversely proportional to model capability — build the minimum. ~12 min.
- **[Are AI agents actually slowing us down?](https://newsletter.pragmaticengineer.com/p/are-ai-agents-actually-slowing-us)** — Gergely Orosz, Pragmatic Engineer. The contrarian data point: heavier daily agent use correlating with more sloppy software, outages, and *slower* shipping. The honest counterweight to throughput-maximalism, and the right frame before you hand a migration chunk to an unattended loop. ~10 min.
- **[Best Practices with Claude Code Subagents Part II: From Prompts to Pipelines](https://www.pubnub.com/blog/best-practices-claude-code-subagents-part-two-from-prompts-to-pipelines/)** — PubNub. Turns ad-hoc subagent prompts into a real spec → implement → test → review → PR pipeline where each stage is a subagent with its own context and tools. Practitioner-level, concrete, and maps cleanly onto delegating migration work. ~8 min.
- **[AI Code Review in 2026: How It Works and How to Adopt It](https://sourcegraph.com/blog/ai-code-review)** — Sourcegraph. Start narrow, tune for low false positives, pair with full-codebase context, and measure *outcomes* not comment volume; review as a panel of specialist agents rather than one monologue. The adoption playbook for the agent-PR firehose. ~9 min.

### 6b. General AI engineering reading
- **[AI and Liability](https://simonwillison.net/2026/Jun/25/ai-and-liability/)** — Simon Willison (Jun 25). On a German ruling holding Google liable for errors in AI Overviews, with the load-bearing argument that **an AI agent is an agent of whoever deploys it**. The cleanest articulation of why "the model hallucinated" won't be a defense — and a direct concern for anyone shipping LLM features in financial services. ~4 min.
