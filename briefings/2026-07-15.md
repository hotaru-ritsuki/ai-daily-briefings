## 4. 🛠️ Claude Code & MCP ecosystem (deep dive)

The theme worth real attention is **agent security on GitHub**, and it's now concrete rather than theoretical. The "Comment and Control" research showed all three major coding agents (Claude Code, Gemini CLI, Copilot) can be hijacked *entirely inside GitHub* — a malicious PR title/comment is read as trusted context, the agent runs the attacker's instructions, and secrets are exfiltrated back through another comment or commit, no external server needed ([CSA research note](https://labs.cloudsecurityalliance.org/research/csa-research-note-claude-code-github-action-prompt-injection/), [oddguan write-up](https://oddguan.com/blog/comment-and-control-prompt-injection-credential-theft-claude-code-gemini-cli-github-copilot/)). Anthropic's earlier mitigation blocked `/proc` access (v2.1.128); the Jul-14 `ultracode`-on-webhook and Agent-tool hardening are the next increment. For anyone (me) running PR-subscription automation, the design rule stands: an agent that reads untrusted content **and** holds secrets/file-read/network is the dangerous combination — split those capabilities.

On the tooling side, the practical builder skills to know are Anthropic's official **`mcp-builder`** and **`webapp-testing`** skills (in [`anthropics/skills`](https://github.com/anthropics/skills)) — the former is the fastest scaffold for a spec-2026-compliant MCP server ahead of the Jul-28 cutover, the latter a ready E2E-testing skill that maps onto my Playwright work. Nothing net-new on the `.claude/` config front since 07-11's harness-engineering/VoltAgent items.
