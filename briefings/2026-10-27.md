## 3. 📋 AI coding tool changelogs

Cutoff: 2026-10-24 briefing (covered up to Claude Code 2.1.310).

### Claude Code — [2.1.311](https://code.claude.com/docs/en/changelog) (Oct 26)
- 🆕 New `--hold-idle-file` and `--max-hold-min` flags for `self-hosted-runner` keep an idle session alive while the host reports leftover processes.
- 🔧 ⭐ `ultrathink` in the terminal now runs the turn at xhigh effort on supported models. This is a real behavior change if you use the keyword casually, since it will cost more tokens and time.
- ⚠️ ⭐ On Bedrock, Mantle, Vertex and Foundry, model settings now load from a signed file on downloads.claude.ai. Opt out with `CLAUDE_CODE_MODEL_CATALOG=off`. This matters for locked-down enterprise networks.
- 🔧 JSON and stream-JSON output now escapes some control characters as `\uXXXX`. Parsed values are unchanged, but byte-level diffing in scripts may notice.
- 🔧 `DISABLE_COMPACT` in settings files can only turn compaction off, not back on. The `[1m]` model suffix is dropped from displayed names where it has no effect, but is still accepted.
- 🐛 56 fixes, including a startup freeze with very long CLAUDE.md list items, MCP connection/display issues, and subagent/worktree issues. Also 16 improvements, including faster startup for Pro/Max and better compaction retries.
- 🆕 VS Code gets syntax-colored code blocks and a hook spinner. Claude Tag analytics gains a Skills view.
