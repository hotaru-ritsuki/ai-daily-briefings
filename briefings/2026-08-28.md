## 3. 📋 AI coding tool changelogs

Cutoff = last briefing (08-27: CC **v2.1.247**, Codex **0.150.1** stable).

**Claude Code — v2.1.248 (Aug 27), v2.1.250 (Aug 28)** ([changelog](https://code.claude.com/docs/en/changelog)):

- ⭐ 🆕 **`--restricted` / `CLAUDE_CODE_RESTRICTED=1`** — removes built-in command/code-execution tools and `WebFetch` (unless named in `--tools`), keeps file tools inside the working dir, refuses `bypassPermissions`, and ignores user/project/local settings. *Why:* a first-class read-mostly lockdown for untrusted repos and unattended runs.
- ⭐ 🆕 **`experimental.cacheTtl`** (`"5m"`/`"1h"`) in **agent frontmatter** — a per-agent prompt-cache TTL used when no subagent TTL setting is configured. *Why:* finer cost control than the session-wide `subagentPromptCacheTtl` for fan-out.
- ⭐ 🔧 **Workflow tool prompt footprint ~5.7k → ~1k tokens.** *Why:* direct context savings every session I run a workflow; `/loop` self-paced + no-prompt autonomous modes are now always available too.
- ⭐ 🐛 **`/ultrareview` and locally-seeded cloud sessions no longer upload uncommitted edits to sensitive files** (`prod.env`, credential files). A real leak fix — reason to update today.
- 🐛 **Hourly prompt-cache miss fixed** — tool definitions were being re-rendered after an OAuth token refresh, busting the cache roughly once an hour in long sessions.
- 🆕 Cross-session `SendMessage`/`ListAgents` now works on **Bedrock, Vertex, and Foundry** (and telemetry-off sessions); `self-hosted-runner --client-label`; `/usage-credits` for AWS-Marketplace/Enterprise billing; server-managed-settings load diagnostics in `/doctor` + `/status`.
- 🐛 Long fixes list, incl. `ScheduleWakeup` tool-def drifting across `--resume` under usage overage, background sessions silently waiting on a bad hook answer, and `headersHelper`-`Authorization` servers falling into OAuth discovery on 401.
- v2.1.250 (Aug 28): "bug fixes and reliability improvements" only.

**OpenAI Codex — no new *stable* since last briefing.** Latest stable remains **0.150.1 (Aug 27)** ([releases](https://github.com/openai/codex/releases)). The **0.151.0-alpha** train continues (alpha.5→alpha.8, Aug 27–28) but nothing has been promoted — hold on the stable channel; nothing net-new to adopt today.

## 4. 🛠️ Claude Code & MCP ecosystem (community, deep dive)

- **"Frequent intentional compaction" is crystallizing into the default context-management technique.** HumanLayer's [Advanced Context Engineering for Coding Agents](https://www.humanlayer.dev/blog/advanced-context-engineering) argues you should *deliberately* compact throughout a task — write intermediate state to files, reset context on purpose, feed the agent a curated plan/to-do rather than letting the window fill — instead of relying on auto-compaction. This pairs exactly with today's changelog: **per-agent `cacheTtl` + the Workflow-tool footprint cut** are the harness catching up to the practice. My CLAUDE.md / subagent-context discipline is the same idea by another name.
- **A DeepSeek-native harness ecosystem exploded this month.** "DeepSeek Harness" (dsh) — "everything is a plugin" — spawned curated hubs like [`awesome-dsh-plugin`](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) (13.3k★, created Aug 13) and [`awesome-deepseek-harness`](https://github.com/Dominic789654/awesome-deepseek-harness) (plugins, skills, MCP servers, orchestrators). It mirrors the Claude Code plugin sprawl one model over — worth knowing exists, but the same skill-bloat caveat (08-27's `skills-janitor` point) applies before adopting anything from it.
- **The plugin-marketplace layer keeps hardening.** v2.1.248 rejects invalid `crossSessionInbound` values and escapes marketplace-supplied text; on the community side, [`jeremylongshore/tons-of-skills-marketplace`](https://github.com/jeremylongshore/tons-of-skills-marketplace) (2.7k★) now bundles 471 plugins / 3,069 skills / 347 agents behind a `ccpi` CLI. Treat these as parts bins to search, not payloads to install wholesale.
- **MCP is moving into data-governance territory.** [`dosco/graphjin`](https://github.com/dosco/graphjin) (3.1k★) exposes one governed GraphQL+MCP graph over Postgres/MySQL/Mongo/files/APIs — the "give the agent one scoped, audited data surface" pattern I want near a regulated repo, rather than N ad-hoc DB MCP servers.
