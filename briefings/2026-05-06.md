## 3. 📋 AI coding tool changelogs

_Cutoff: entries after 2026-05-04 (v2.1.128)._

### Claude Code — 2 releases ([changelog](https://code.claude.com/docs/en/changelog))

- **2.1.131 (May 6)** — hotfix
  - 🐛 Fixed VS Code extension failing to activate on Windows (hardcoded build path in bundled SDK).
  - 🐛 Fixed Mantle endpoint authentication (missing `x-api-key` header).

- **2.1.129 (May 6)** — 27 changes, packed release:
  - 🆕 `--plugin-url <url>` for session-only plugin installs from remote archives.
  - 🆕 ⭐ `skillOverrides` setting: `off` hides a skill entirely, `user-invocable-only` hides from the model but keeps it in `/`, `name-only` collapses its description. ⭐ *Finally lets you curate which skills eat context without deleting them.*
  - 🆕 ⭐ `skillListingBudgetFraction` — drops entire low-use skill descriptions from the system prompt (priority by recency/frequency) rather than truncating all descriptions uniformly. Default: 1% of context. ⭐ *If you have 20+ skills, this prevents context bloat from rarely-used ones.*
  - 🔧 ⭐ Gateway model discovery (`/v1/models`) now opt-in via `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` (was automatic in 2.1.126–128). ⭐ *Fixes issues if your gateway's model list was polluting the picker.*
  - 🔧 Ctrl+R history picker defaults to all projects again (pre-2.1.124 behavior); Ctrl+S narrows to current project.
  - 🐛 ⭐ **Fixed 1-hour prompt cache TTL being silently downgraded to 5 minutes.** ⭐ *If you use `ENABLE_PROMPT_CACHING_1H`, it was broken for 3 releases. Upgrade immediately for cost savings.*
  - 🐛 Fixed `/context` dumping ~1.6k wasted tokens of ASCII visualization into conversation.
  - 🐛 Fixed agent panel hidden when subagents run (regression since 2.1.122).
  - 🐛 Fixed OAuth refresh race after wake-from-sleep logging out all sessions.
  - 🐛 Fixed VS Code `/clear` not actually clearing conversation context.
  - 🐛 10+ additional fixes: external-editor blanking history, `/branch` missing session ID, cache-miss warnings after `/clear`, emoji rendering in fullscreen, `mkdir`/`touch` allow rules.

### OpenAI Codex CLI — no new stable release ([source](https://github.com/openai/codex/releases))

Pre-releases `0.129.0-alpha.7` through `alpha.10` published May 5–6 with no release notes. Tags prefixed `rust-v`, confirming the Rust rewrite. Accelerating cadence (4 alphas in 2 days) suggests 0.129.0 stable is imminent.

## 8. 🎯 One thing to try today (≤30 min)

**Configure `skillOverrides` and `skillListingBudgetFraction` in 2.1.129 to reclaim context from unused skills.**

```bash
# 1. Upgrade
claude --upgrade  # confirm 2.1.129+

# 2. List your current skills
claude  # then type /skills — see what's loaded

# 3. Add overrides to .claude/settings.json for skills you rarely use:
#    "skillOverrides": {
#      "rarely-used-skill": "off",
#      "sometimes-useful": "name-only"
#    }

# 4. Optionally tune the budget (default is 1% of context):
#    "skillListingBudgetFraction": 0.02  // 2% if you use many skills

# 5. Also fix the prompt cache — if you had ENABLE_PROMPT_CACHING_1H set,
#    it was silently broken since 2.1.126. Verify it's working now:
export ENABLE_PROMPT_CACHING_1H=1
#    Check /usage after a session — cache_read tokens should be high
```

If you have 20+ skills installed (and the marketplace now lists 4,200+), the default behavior was truncating all descriptions uniformly. The new system drops entire low-priority skills instead, preserving trigger keywords for the ones you actually use. Combined with the prompt cache fix, this is a meaningful cost and quality improvement.
