## 4. 🛠️ Claude Code & MCP ecosystem (deep dive)

**The week's real ecosystem lesson is structural, not a new server: an agent that can run shell as *you* has no boundary between "clean the temp dir" and "delete `$HOME`."** The GPT-5.6 Codex deletions (§1) are the concrete case, and the fix everyone converged on is the same one Claude Code shipped today — **make destructive commands hit a prompt, and keep a sandbox under the agent as the fallback when an *approved* command misbehaves** ([Docker's rm -rf writeup](https://www.docker.com/blog/coding-agent-horror-stories-the-rm-rf-incident/)). Practically for my setup: (1) never run Codex full-access with sandbox+auto-review off; (2) on CC, adopt v2.1.212's runaway caps and confirm plan mode now prompts on `rm`/`touch`; (3) treat the `.claude/worktrees` symlink-escape fix as a reminder that worktree isolation is only as good as the paths it can't follow out of the repo.

On the community side, subagent/skill collections are consolidating into a few high-traffic hubs worth mining rather than authoring cold — **VoltAgent/awesome-claude-code-subagents** (~23.4k★) and its sibling **awesome-agent-skills** (§5) — and the **Playwright MCP** servers now plug the accessibility tree into the agent (reason about "the Sign In button," not a selector), the path to pushing my Playwright E2E into the loop.
