## 3. 📋 AI coding tool changelogs

**Claude Code — v2.1.222 (Aug 4)** ([changelog](https://code.claude.com/docs/en/changelog)). v2.1.221 was covered yesterday; 222 is the net-new diff:

- ⭐ **Worktree isolation now applies to Bash + file edits in every session type** — worktree sessions/subagents can no longer run destructive git against the main checkout. ⚠️-adjacent **fix**. *Why it matters:* directly hardens the isolated-migration-agent pattern I use.
- ⭐ **PreToolUse auto-allow hooks no longer bypass tool restrictions in background tasks** (summaries, compaction, renames). 🐛 security **fix** — background agents were a hole in the permission model.
- ⭐ **Auto mode now runs `SendMessage` through the permission classifier before dispatch** 🔧 — cross-agent messages are adjudicated, not trusted.
- `/usage` no longer over-attributes spend to MCP servers; a server's share now reflects only turns that consumed its results 🔧 — better cost attribution for my MCP-heavy setup.
- Sessions now correctly link to PRs created **after** the branch was pushed (incl. via REST API) 🐛.
- 🚫 **Removed the `ultraplan` feature.**
- Plus: org-restricted `model: opus` aliases now step down to the newest allowed model instead of the parent; HTTPS-proxy startup-check hang fixed; `/diff` uses raw git blob content.

## 4. 🛠️ Claude Code & MCP ecosystem (community deep dive)

**The plugin ecosystem is professionalising.** Two shifts worth noting this week:

- **Package managers over gists.** [`ccpi`](https://github.com/jeremylongshore/claude-code-plugins-plus-skills) gives Claude Code a CLI installer with a real catalog (471 plugins / 3,069 skills / 347 agents, backed by tonsofskills.com). This is the "npm for `.claude/`" pattern finally landing — versioned, discoverable, updatable, instead of copy-pasting SKILL.md files.
- **Cross-harness marketplaces.** [wshobson/agents](https://github.com/wshobson/agents) publishes the *same* subagents/commands to Claude Code, Codex, Cursor, OpenCode, Copilot and Gemini CLI. Combined with [alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills) (345 skills across 12 agents, including compliance/finance packs) and the official [anthropics/skills](https://github.com/anthropics/skills), the "author once, run on every harness" story is now real — matters if you standardise tooling across a team that isn't all on one CLI.

**MCP servers for my stack.** The Atlassian side moved: the official [atlassian/atlassian-mcp-server](https://github.com/atlassian/atlassian-mcp-server) (OAuth 2.1, Jira/Confluence/Bitbucket/Compass) is the sanctioned enterprise route, while community [vish288/mcp-atlassian-extended](https://github.com/vish288/mcp-atlassian-extended) (23 tools: sprints, agile boards, sprint capacity) and [sooperset/mcp-atlassian](https://github.com/sooperset/mcp-atlassian) (v1.37.1, Aug 3) go deeper on agile workflows. For a Spring Boot + Jira shop, the official server for writes and an extended one for read-heavy sprint queries is a reasonable split.
