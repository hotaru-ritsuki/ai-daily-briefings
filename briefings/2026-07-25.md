## 8. 🎯 One thing to try today (≤30 min)

**Encode your migration checks as a verification-loop skill** (per §6a's Anthropic post) so Opus 5 self-checks each AngularJS→Angular conversion instead of you doing it by hand.

1. Create `.claude/skills/verify-migration/SKILL.md`:
   ```md
   ---
   name: verify-migration
   description: After migrating a component, build, run unit tests, and run the Playwright smoke test; fix failures and re-run until green.
   ---
   Run in order, fixing and re-running on any failure:
   1. `npm run build` — must compile with no new errors.
   2. `npm test -- --findRelatedTests <changed files>` — related specs must pass.
   3. `npx playwright test smoke` — the auth + landing smoke flow must pass.
   Report the final status and any assertion that had to change.
   ```
2. In a session: *"Migrate `foo.component`, then invoke the verify-migration skill and don't hand back until it's green."*
3. Confirm the loop actually runs in the output. If it holds, add your lint/format step and make it your standard migration close-out.

First command: `mkdir -p .claude/skills/verify-migration && $EDITOR .claude/skills/verify-migration/SKILL.md`. Payoff: the review gate moves from your memory into the repo.
