## 3. 📋 AI coding tool changelogs (since 2026-11-03 briefing)
### Claude Code — [2.1.318](https://github.com/anthropics/claude-code/releases/tag/v2.1.318) (Nov 4)
Confirmed on both the [docs changelog](https://code.claude.com/docs/en/changelog) and GitHub Releases.
- ⚠️ ⭐ `deniedMcpServers` URL entries now also block Anthropic-provided servers and cloud connectors whose upstream URL matches. If you deny by URL, check you aren't now blocking a connector you use.
- ⚠️ ⭐ Claude Code no longer installs or updates the IDE extension when started in an IDE terminal. Use `/ide` from an outside terminal, or the editor's extensions view. This affects your IntelliJ and Cursor setups.
- 🔧 ⭐ Background subagents move a shell command to the background after 3 minutes on all providers, so the prompt cache doesn't expire while it runs. Long `ng test` or `mvn verify` runs inside subagents should cost less.
- 🆕 Mods can set `effort` on `$.model.fork`, so side jobs can run at `low` whatever the session's effort.
- 🆕 `claude auth status` shows `loginExpiresAt`, and `claude -p` JSON includes `credential_expires_at`. `claude -p` also warns on stderr starting 10 days before a stored sign-in ends, which helps catch scheduled jobs before their sign-in lapses.
- 🔧 `/claude-api managed-agents-onboard` now gives new agents the `auto` ("Judge risky actions") permission policy by default.
- 🐛 ⭐ `--continue` no longer loses earlier conversation after a malformed tool call's retries run out (regression from 2.1.314).
- 🐛 `claude mcp add` and `remove` now wait for the config lock or exit 1. They also no longer report success when the config write failed.
- 🐛 Keys typed just after sending a message, or before a slow permission prompt appears, can no longer answer that prompt.
- 🐛 Non-interactive launches no longer overwrite an invalid `~/.claude.json` with defaults; they fail and explain how to restore it.
- 🐛 Custom slash commands that fail, or that only Claude can invoke, now print output in `claude -p` and SDK sessions instead of nothing.
- 🚫 The 2.1.288 fix that kept earlier thinking when resuming conversations from 2.1.286 or earlier has been removed.

## 8. 🎯 One thing to try today (≤30 min)
**Split your CLAUDE.md into path-scoped rules for the Angular and Spring halves of a repo,** following Anthropic's [steering guide](https://claude.com/resources/articles/steering-claude-code-skills-hooks-rules-subagents-and-more).
1. `claude update && claude --version` should show 2.1.318.
2. `mkdir -p .claude/rules` and create `.claude/rules/angular.md` with frontmatter `paths: ["frontend/**/*.ts", "frontend/**/*.html"]`. Move NgRx, RxJS and PrimeNG conventions there from CLAUDE.md.
3. Create `.claude/rules/spring.md` with `paths: ["backend/**/*.java"]` for Kafka and Spring Boot conventions.
4. Start a session, run `/context`, and compare memory token usage with the same session before the split. Then ask for a change to a `.java` file and check that only the Spring rule loads.

Success: CLAUDE.md is mostly build commands and layout, and memory tokens drop for sessions that only touch one side. If you start Claude from the IntelliJ terminal, also run `/ide` once, since auto-install is gone.
