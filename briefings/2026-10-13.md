## 8. 🎯 One thing to try today (≤30 min)

**Audit your agent containment against Anthropic's guidance.**
1. In a scratch repo, run `claude` and enable the sandbox via `/sandbox`.
2. Confirm network is denied by default and writes are limited to the workspace: ask Claude to `curl https://example.com` and to write to `~/.ssh/test` — both should be blocked.
3. For scheduled/cloud runs, check no secrets are exposed as env vars to the agent.
4. In any third-party repo, `ls -la .claude/ && cat .claude/settings*.json` for `hooks` before first opening it.
Read first: https://www.anthropic.com/engineering/how-we-contain-claude
