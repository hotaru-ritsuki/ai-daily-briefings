## 4. 🛠️ Claude Code & MCP ecosystem (community deep dive)

The week's dominant community thread is **config convergence around AGENTS.md**, and CC 2.1.277 is the catalyst. Two things to know:

1. **The recommended pattern is still an import, not a rename.** Even with native fallback, the durable setup is `AGENTS.md` as the single source of truth + a one-line `CLAUDE.md` that `@AGENTS.md`-imports it — because Codex reads `AGENTS.md` directly while CC's `@import` expansion also picks up your CC-only rules ([sync patterns](https://dev.to/pederaa/how-to-sync-cursor-rules-claudemd-and-agentsmd-across-projects-without-config-drift-23f8), [field guide](https://www.iuriio.com/blog/posts/2026/05/agents-md-field-guide-2026)). Native fallback only helps repos with *no* CLAUDE.md.
2. **The standard now has real governance.** AGENTS.md moved under the Linux Foundation's Agentic AI Foundation (170+ orgs incl. AWS, Anthropic, Google, Microsoft, OpenAI); **60,000+ repos** have adopted it ([standards overview](https://dev.to/ialijr/top-ai-agent-standards-to-know-in-2026-31gm)). This is the closest thing to a settled cross-agent config format.

On the marketplace side, distribution keeps consolidating into **multi-harness** catalogs — [wshobson/agents](https://github.com/wshobson/agents) now packages agents/skills for CC, Codex, Cursor, OpenCode, Copilot, Google Antigravity and Pi from one repo, which is the logical endpoint of the AGENTS.md convergence. Memory-augmented agents are the other rising thread ([thedotmack/claude-mem](https://github.com/thedotmack/claude-mem), [SuperMemoryAI/supermemory](https://github.com/SuperMemoryAI/supermemory)) — persistent cross-session context as a skill/plugin rather than a bigger window.

New MCP servers worth a note: **Docusign's MCP server goes GA Sep 30** (out of beta) ([announcement](https://developer.okta.com/docs/release-notes/2026-okta-mcp-server/)), and [ReleasePad shipped an MCP server](https://www.globenewswire.com/news-release/2026/09/14/3361396/0/en/releasepad-launches-mcp-server-so-ai-agents-can-draft-publish-and-measure-product-changelogs.html) for drafting/publishing changelogs from a conversation — relevant if you want an agent to own this briefing-style workflow end to end.

## 8. 🎯 One thing to try today (≤30 min)

**Consolidate to a single agent-config source with AGENTS.md.** In one repo you work in daily:

```bash
claude update                     # get 2.1.277+ (native AGENTS.md fallback)
# move your existing rules into AGENTS.md as the source of truth:
git mv CLAUDE.md AGENTS.md 2>/dev/null || mv CLAUDE.md AGENTS.md
printf '@AGENTS.md\n' > CLAUDE.md # CC expands the import; Codex/Cursor read AGENTS.md directly
```

Then start a Claude Code session and a Codex session in the same repo and confirm both pick up your conventions (`/config` → "Project instructions" in CC). Add any CC-only rules *below* the `@AGENTS.md` line in `CLAUDE.md`. Net result: one file drives Claude Code, Codex, Cursor and JetBrains — no more drift. ([sync patterns](https://dev.to/pederaa/how-to-sync-cursor-rules-claudemd-and-agentsmd-across-projects-without-config-drift-23f8))
