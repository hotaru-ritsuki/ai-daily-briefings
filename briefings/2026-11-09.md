## 1. 🔥 Top 3 things I shouldn't miss today
- **⚡ [microsoft/TokenEconomizer](https://github.com/microsoft/TokenEconomizer) (5.3k★, Apache-2.0) is a Claude Code/Codex/Copilot CLI plugin that cuts agent cost without touching the agent.** It does three things: prunes tools you never call, catches stuck failure loops, and (opt-in) stores repo facts like "the test command is `npx ng test --watch=false`". Its own SWE-Bench runs report **18–31% lower mean cost** across five agent/model pairs. These are the authors' numbers and I haven't verified them, but it's cheap to measure on your own repo (§5, §8).
- **⚡ The [official MCP reference servers v2.3.0](https://github.com/modelcontextprotocol/servers/releases) (Nov 4) add the hardening flags you'd want before giving an agent filesystem, fetch or git access.** The new flags are filesystem `--read-only` and `--confine-roots`, and fetch `--allowed-hosts` plus a request timeout. Git gets `git_merge`, a read-only `git_remote`, and range diffs (`main..feature`). If any of these sit in your `.mcp.json`, pin the version and add the flags (§4).

## 4. 🛠️ Claude Code & MCP ecosystem (community)
- **MCP reference servers v2.3.0 in practice** ([release notes](https://github.com/modelcontextprotocol/servers/releases)):
  - **Filesystem:** `--confine-roots` stops a client from widening access through Roots beyond the directories on the command line. The allowed-directory log now says where each directory came from. Together those close the "I gave it `src/` and it ended up reading `~`" gap.
  - **Fetch:** `--allowed-hosts` is a cheap guard against prompt-injection data exfiltration (a malicious page telling the agent to fetch an attacker URL with your data in it). The bounded Readability subprocess stops a hostile page from hanging the server.
  - **Sequential Thinking:** caps the thought history kept per connection, which matters on long sessions.
- **Agents talking to agents across machines.** [reason-network](https://github.com/reason-machines/reason-network) (~1.7k★, MIT/Apache-2.0) runs a daemon per laptop and gives each agent MCP tools: `list_team`, `send_message`, `message_status` and `ask_user`. Traffic is end-to-end encrypted and peer-to-peer over iroh. It's an early but concrete take on "my Claude asks your Codex about the API contract". **Don't** use the `curl | bash` install on a work machine without reading the script first.
- **Cost governance as a plugin.** TokenEconomizer's design is a good reference for writing your own hooks:
  - It works out which tools a repo actually calls and drops the rest. Every tool definition loaded is sent on every request, so heavy MCP setups pay for this.
  - Its loop guard only **nudges** the agent and never kills a turn.
  - Everything it learns stays in `~/.tokeneconomizer`.
- **Plan→build→review gates as a plugin.** [rjmurillo/ai-agents](https://github.com/rjmurillo/ai-agents) is small (49★) but neatly structured:
  - It packs 30 agents into one plugin for Claude Code and Copilot CLI.
  - A `critic` agent returns `APPROVED / APPROVED_WITH_CONCERNS / NEEDS_REVISION / BLOCKED`. `NEEDS_REVISION` sends the plan back to the agent that wrote it, and a QA failure sends the work back to the implementer.
  - The typed verdict is the part to copy into your own `/review` command.
- **Trend check:** [weekly trending](https://github.com/trending?since=weekly) is unchanged in shape: NVIDIA/auto-ontology, claude-mem, worktrunk and skill packs. `vercel-labs/agent-browser` (~48k★) shipped [v0.41.2](https://github.com/vercel-labs/agent-browser/releases) (Nov 3), which loads one skill reference at a time (`skills get <name> --ref`) to save context and warns when Chrome is out of date.

## 8. 🎯 One thing to try today (≤30 min)
**Measure TokenEconomizer on your own repo instead of trusting its benchmark.**
1. Get a baseline. In a normal session on your Angular repo, run one realistic task, for example *"Add a PrimeNG `p-table` column filter to `OrdersListComponent`, update the NgRx selector and its spec, run the tests"*. Note the session's tokens and cost from `/usage` and `/context`.
2. Install the plugin:
   ```
   git clone https://github.com/microsoft/TokenEconomizer.git
   claude plugin marketplace add "$PWD/TokenEconomizer"
   claude plugin install tokeneconomizer@tokeneconomizer
   ```
   Restart `claude`, trust the folder, and run `/tokeneconomizer:status`.
3. `git stash` or reset, then run the **same prompt** two or three times. Tool pruning only works after it has seen which tools the repo uses, so the first run won't save much.
4. Compare cost, turns, and whether the result passed the tests. If you have many MCP servers attached (JetBrains, GitHub, Playwright), that's where pruning should show up.
5. Optional: turn on micro-skills. It's off by default because it adds its own model calls, and the plugin counts those in its reports.

**Success criteria:** a measured percentage for *your* repo, and a decision on whether to keep it on for long NgRx/Spring refactors.
