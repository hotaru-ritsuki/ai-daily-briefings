## 4. 🛠️ Claude Code & MCP ecosystem (deep dive)

The week's consolidation is around **portable, installable skill libraries**, and `obra/superpowers` (Jesse Vincent) is the reference implementation worth studying over the aggregate marketplaces:

- **Structure:** the ecosystem is split across a [plugin repo](https://github.com/obra/superpowers), a community-editable [superpowers-skills](https://github.com/obra/superpowers-skills), an experimental [superpowers-lab](https://github.com/obra/superpowers-lab), and a [marketplace](https://github.com/obra/superpowers-marketplace) you add with one command. Install path: add the marketplace, then `/plugin install superpowers`.
- **What's inside:** skills grouped as **Testing** (TDD, async testing, anti-patterns), **Debugging** (systematic root-cause tracing, verification), **Collaboration** (brainstorming, planning, code review, *parallel agents*), and **Meta** (creating/testing/contributing skills). The collaboration group is the interesting part — it encodes subagent coordination as reusable skills rather than one-off prompts.
- **Why it beats the mega-catalogs:** the 400+/3,000+ plugin marketplaces (`tonsofskills.com`, ccpi) are breadth plays with uneven quality; `superpowers` is a small, opinionated, TDD-first core that reads like a real methodology. For a regulated repo, a curated 14-skill library you can audit end-to-end is safer than a 3,000-skill firehose.

Elsewhere: JetBrains MCP support is now GA in AI Assistant across the 2026.1 IDE family (IntelliJ/WebStorm/DataGrip) ([JetBrains/mcp-server-plugin](https://github.com/JetBrains/mcp-server-plugin)), so DataGrip schema-aware queries via a Postgres MCP server are a viable in-IDE path for the Spring Boot side.

4. **[github/spec-kit](https://github.com/github/spec-kit)** — GitHub's structured SDD toolkit (7+ files/feature, immutable "constitution"). *The greenfield/governance counterpart to OpenSpec; useful if I want enforced specs on a regulated repo.*
5. **[langchain-ai/langgraph](https://github.com/langchain-ai/langgraph)** — Graph-based stateful multi-agent orchestration (nodes with own state, conditional edges). *The most mature reference for state-graph agent design if I outgrow CC's in-process `Workflow`.*
6. **[Airtable/typescript-migration-codemod](https://github.com/Airtable/typescript-migration-codemod)** — The codemod Airtable used for its Flow→TypeScript migration. *A real, battle-tested AST-transform harness to crib for large TS migrations.*
7. **[hamidyfine/ts-codemod](https://github.com/hamidyfine/ts-codemod)** — JS→TS codemod that adds type annotations and rewrites imports/syntax. *Pairs with an LLM pass for the mechanical 80% of a TS migration; keep the deterministic transforms deterministic.*
