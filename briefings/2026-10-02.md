## 4. 🛠️ Claude Code & MCP ecosystem (community deep dive)

Mods landed with a community ecosystem already forming the same day — this is where to spend attention:

- **The four official mods are open source in [`anthropics/claude-code`](https://github.com/anthropics/claude-code):** `diff` (the `/diff` view is now *itself* a mod — a reference for drawing panes), `agents-md`, `sec-default` (auto-loads on Team/Enterprise to restrict risky mod behavior — note the trust model), and `telemetry`. Read `diff` first if you want to build UI.
- **[`karanb192/awesome-claude-code-mods`](https://github.com/karanb192/awesome-claude-code-mods)** — a curated directory with a **footprint scanner behind every row** (what each mod can reach). Given mods run arbitrary TS inside your session, the scanner is the governance primitive to use before installing anything — exactly the audit discipline a fintech context demands.
- **[`ShindouMihou/cc-redact`](https://github.com/ShindouMihou/cc-redact)** — redacts secrets/emails/IPs to stable placeholders before the model reads them, *keeping type and structure* so Claude still has context. The most directly useful mod for regulated codebases, and a clean §8 experiment.
- **Mermaid-inline mods** ([`galElmalah/claude-mods`](https://github.com/galElmalah/claude-mods)) render Mermaid fences as box-art in the transcript — small, but a good "read the source to learn the UI API" starter. Directories are already aggregating all of these ([claude-mods.com](https://claude-mods.com/), [aitmpl.com/mods](https://aitmpl.com/mods/)); treat them as menus and vet with the footprint scanner — an installed mod sees your prompts and tool output.

## 8. 🎯 One thing to try today (≤30 min)

**Install your first Claude Code mod — the secret-redactor — so tool output is sanitized before the model sees it.** It's the mod with the clearest payoff for regulated/fintech work, and it doubles as a tour of the mod API.

```bash
# 1. make sure you're on the mods-capable build
npm i -g @anthropic-ai/claude-code@latest   # ≥ 2.1.287

# 2. in Claude Code, browse the community directory and install cc-redact,
#    then read its source to see how a PreToolUse mod rewrites output:
/plugin marketplace add karanb192/awesome-claude-code-mods
/plugin        # find & install cc-redact (ShindouMihou/cc-redact)
```

Then run a session that `cat`s a `.env` or a Spring `application-*.yml` and confirm the values arrive redacted but structurally intact. Before installing, check the entry's footprint in the directory's scanner. Prefer rolling your own? Start from the official [`diff`/`sec-default` mods](https://github.com/anthropics/claude-code) and the [getting-started guide](https://claude.com/blog/claude-code-mods). *(Install syntax may differ slightly — verify against the quickstart.)*
