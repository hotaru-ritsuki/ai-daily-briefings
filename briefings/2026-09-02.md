## 4. 🛠️ Claude Code & MCP ecosystem (community, deep dive)

- **Test-agent packs are becoming a first-party pattern, not a community hack.** Playwright's `init-agents` (v1.56) writes real `.claude/agents/*.md` files — a **Planner** that explores the live app and writes a Markdown test plan, a **Generator** that turns the plan into spec files, and a **Healer** that repairs broken locators on failing runs — and exposes the Playwright MCP so CC drives the browser runtime instead of guessing at markup ([TestDino](https://testdino.com/blog/playwright-test-agents), [QASkills setup](https://qaskills.sh/blog/playwright-test-agents-claude-code)). This is the cleanest reference for how a *vendor* should ship subagents: plan → generate → self-heal, each with scoped tools.
- **"Agent swarm" harnesses keep consolidating around cross-CLI compatibility.** [`HKUDS/ClawTeam`](https://github.com/HKUDS/ClawTeam) frames itself as one-command swarm orchestration that self-organizes agents into teams and runs across **Claude Code, Codex, OpenClaw, nanobot, and Cursor** from the same config. Same fan-out-at-scale shape as DeerFlow/orca (covered), but the interesting bit is harness-portability — worth an hour if I want my plan-on-CC / execute-on-Codex loop to survive a harness swap.
- **Portable skills libraries worth a search (not a wholesale install).** [`VoltAgent/awesome-claude-code-subagents`](https://github.com/VoltAgent/awesome-claude-code-subagents) (100+ scoped subagents), [`netresearch/claude-code-marketplace`](https://github.com/netresearch/claude-code-marketplace) (agentskills.io "open standard", portable across CC/Cursor/Copilot/Codex/Gemini), and [`EricGrill/agents-skills-plugins`](https://github.com/ericgrill/agents-skills-plugins) (TDD/review/"subagent-driven-development" skills). The 08-27 skill-hygiene caveat still holds — install narrow, prune with data.

## 8. 🎯 One thing to try today (≤30 min)

**Install Playwright's built-in agents as Claude Code subagents.** In a project with Playwright ≥1.56:

```bash
npx playwright init-agents --loop=claude
```

It writes `.claude/agents/planner.md`, `generator.md`, and `healer.md` and registers the Playwright MCP server. Then in Claude Code: point the **Planner** at a running instance of the app to generate a Markdown test plan, hand it to the **Generator** for spec files, and let the **Healer** repair a deliberately-renamed locator ([setup guide](https://qaskills.sh/blog/playwright-test-agents-claude-code)). If it's solid, it replaces the ad-hoc Playwright-MCP wiring I've been maintaining by hand — and the three-agent split is a template I can copy for my Handlebars/PDF review skills.
