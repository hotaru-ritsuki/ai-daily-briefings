## 📋 3. AI coding tool changelogs (since 2026-10-19 briefing)

**Claude Code** — [docs changelog](https://code.claude.com/docs/en/changelog) (read via summarizer, first ~100k chars; 2.1.304 is the only version newer than the last briefing):

**2.1.304 (Oct 19)**
- ⭐ 🆕 **Code Review levels** (Quick/Standard/Deep) per org or repo, plus an option to cover every repo in a GitHub org including future ones — lets you tune cost vs depth of the PR-review bot.
- ⭐ 🆕 **`/auto-mode-setup`** — guided setup that tells auto mode about your environment; now also works on Bedrock/Vertex/Foundry/gateway sessions. Useful if auto mode over-prompts on your repo.
- ⭐ 🐛 **Plugins can no longer extend headless runs past `--max-turns`, Stop or ended input** — closes a runaway-cost hole for scheduled runs.
- ⭐ 🐛 **`rm -r` on mounted drives and top-level folders now triggers the safety prompt**; Linux sandbox `denyRead` glob fix for bracketed names.
- ⭐ 🔧 **Tool search is on by default behind a custom `ANTHROPIC_BASE_URL`** (retries without it on 400/422) — relevant if you proxy through a gateway.
- 🔧 Skill hook registration capped at 1,024 hooks / 16,384 matcher characters per source; skills under a hooks-from-plugins-only policy lose `allowed-tools` when their hooks are blocked (⚠️ possible behaviour change for locked-down orgs).
- 🆕 Warning on Pro/Max when resuming an idle conversation would burn a noticeable share of the 5-hour limit; `CLAUDE_CODE_AUTO_COMPACT_WINDOW` suffix parsing fix; `/reload-skills` sends only changed skills; faster resume of large compacted sessions; lower memory with many concurrent subagents.
- 🆕 Mod API additions (`decider: "person"` on `tool.check`, `e.isReadOnly`, `settings.read` can rewrite merged settings) — only if you build mods.
- 43 bug fixes in total; I've listed only the selected ones.

**OpenAI Codex** — [releases](https://github.com/openai/codex/releases): newest are pre-releases 0.164.0-alpha.1–6 (Oct 16–19) without notes. Latest stable 0.163.0 (Oct 15), covered Oct 16. **Nothing new.**

2. In your Angular/Spring repo run `claude`, then `/auto-mode-setup` and describe your environment (test commands, safe dirs, forbidden paths like generated code).
