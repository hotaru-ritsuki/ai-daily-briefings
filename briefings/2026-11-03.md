## 3. 📋 AI coding tool changelogs (since 2026-11-02 briefing)
### Claude Code — [2.1.317](https://github.com/anthropics/claude-code/releases) (Nov 3)
- 🆕 ⭐ `/schedule` now warns when a new cloud scheduled task would get connectors you didn't request. Relevant to scheduled routines like this one: review the connector list when creating tasks.
- ⚠️ ⭐ Web and shell tool calls ask before sending your account email address over the network. Expect new prompts in automation; it also matches the "never send the email to unrelated services" rule.
- ⚠️ Read tool's "file unchanged since your last Read" stub is removed, so re-reads return full content. Token use per re-read goes up; anything keyed on the stub text breaks.
- 🆕 Agent SDK hook callbacks accept `onFailure: "block"`, so a failing hook blocks the action instead of letting it through (fail-closed).
- 🆕 `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID=1` restores the old behaviour where `claude -p` inside a session reuses the parent's session ID and transcript.
- 🔧 Gateway admins get a cost report endpoint (`GET /v1/organizations/analytics/cost`) by total, developer, day or IdP group.
- 🐛 `claude -p` now exits 1 when a full disk or quota blocks transcript writes, instead of 0. Good for CI.

I fetched the GitHub releases page; the docs changelog page was not re-fetched.

## 4. 🛠️ Claude Code & MCP ecosystem (community)
- **[worktrunk](https://github.com/max-sixty/worktrunk)** (~10k★): `wt switch -c -x claude feat` creates a worktree and launches Claude in it; `wt merge` squashes, rebases, merges and cleans up; hooks and copy-on-write caches let new worktrees reuse `node_modules`. This is the parallel-subagent/parallel-session ergonomics layer. Per its README; I haven't run it.

## 8. 🎯 One thing to try today (≤30 min)
**Run two Claude Code agents in parallel on isolated worktrees with worktrunk.**
1. `brew install worktrunk && wt config shell install` (other installers in the [README](https://github.com/max-sixty/worktrunk)).
2. In an Angular repo: `wt switch -c -x claude feat-a` and, in a second terminal, `wt switch -c -x claude feat-b`. Give A a Playwright test-writing task and B a RxJS refactor.
3. `wt list` to compare, then `wt merge` for the one you keep.
Success: two agents with no shared working-tree conflicts, and a sense of whether the copy-on-write cache saves you an `npm install` per worktree. Also run `claude --version` to confirm 2.1.317 first.
