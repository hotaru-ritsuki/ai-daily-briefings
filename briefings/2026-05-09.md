### Claude Code — 3 releases ([changelog](https://code.claude.com/docs/en/changelog))

- **2.1.137 (May 9)** — 🐛 Fixed VS Code extension failing to activate on Windows.
- **2.1.136 (May 8)** — 40+ changes:
  - 🆕 ⭐ `settings.autoMode.hard_deny` — auto mode classifier rules that block unconditionally, no user override. ⭐ *Lets you enforce hard safety boundaries on Auto Mode for sensitive repos.*
  - 🆕 `CLAUDE_CODE_ENABLE_FEEDBACK_SURVEY_FOR_OTEL` env var for enterprise session quality surveys.
  - 🐛 ⭐ **Fixed MCP servers in `.mcp.json`, plugins, and claude.ai connectors silently disappearing after `/clear`** in VS Code, JetBrains, and Agent SDK. ⭐ *If your MCP servers vanished mid-session, this is the fix.*
  - 🐛 ⭐ **Fixed MCP OAuth refresh tokens lost when multiple servers refresh concurrently** — eliminates daily re-auth prompts. ⭐ *Major quality-of-life fix for multi-MCP-server setups.*
  - 🐛 Fixed login loop where concurrent credential write could overwrite freshly-rotated OAuth token.
  - 🐛 Fixed API 400 error when extended thinking emitted a redacted thinking block after a tool call.
  - 🐛 Fixed `--resume`/`--continue` not finding sessions when project path contains underscores.
  - 🐛 Fixed `@` file picker not matching files created mid-session or in directories with 100+ entries.
  - 🐛 Fixed env vars from `CLAUDE_ENV_FILE` going stale after `/resume` or `/clear`.
  - 🐛 Fixed plan mode not blocking file writes when a matching `Edit(...)` allow rule exists.
  - 🔧 WSL2: image paste from Windows clipboard now works via PowerShell fallback.
  - 🐛 ~25 more UI, keyboard, and stability fixes.
- **2.1.133 (May 7)** — 10+ changes:
  - 🆕 ⭐ `worktree.baseRef` setting (`fresh` | `head`) — choose whether worktrees branch from `origin/<default>` or local HEAD. ⭐ *Gives you explicit control over the worktree base for subagent isolation.*
  - 🆕 `sandbox.bwrapPath` and `sandbox.socatPath` managed settings for custom binary locations.
  - 🔧 ⭐ Hooks now receive active effort level via `effort.level` JSON field and `$CLAUDE_EFFORT` env variable. ⭐ *Lets hooks adapt behavior based on current effort — e.g., skip expensive lint on `low`.*
  - 🐛 Fixed parallel sessions dead-ending at 401 after refresh-token race.
  - 🐛 Fixed `HTTP(S)_PROXY`/`NO_PROXY`/mTLS not respected for full MCP OAuth flow.
  - 🐛 Fixed `/effort` unexpectedly changing other concurrent sessions' effort levels.

## 8. 🎯 One thing to try today (≤30 min)

**Upgrade to 2.1.136+ and add the AWS MCP Server to your Claude Code setup.**

```bash
# 1. Upgrade
claude --upgrade  # confirm 2.1.136+

# 2. Add the AWS MCP server (requires AWS credentials configured)
claude mcp add aws -- npx @anthropic-ai/aws-mcp-server

# 3. Test it — ask Claude Code to describe your AWS environment:
#    "List all S3 buckets and Lambda functions in us-east-1"
#    It uses a single call_aws tool that covers 15,000+ API operations

# 4. While you're upgrading, verify your MCP servers survive /clear
#    (the 2.1.136 fix for the disappearing-servers bug):
#    - Start a session with MCP servers
#    - Run /clear
#    - Run /mcp — all servers should still be listed

# 5. If you use Auto Mode, try the new hard_deny setting:
#    Add to .claude/settings.json:
#    "autoMode": {
#      "hard_deny": ["rm -rf", "DROP TABLE", "git push --force"]
#    }
```

The AWS MCP Server is the most broadly useful new MCP server in weeks — it covers every AWS service through a single tool with full IAM and CloudTrail integration. The 2.1.136 upgrade also fixes the daily re-auth annoyance if you run multiple MCP servers with OAuth.
