## 8. 🎯 One thing to try today (≤30 min)

**Wire Chrome DevTools MCP into Claude Code and point it at your Chromium PDF pipeline.** It lets the agent drive a real Chrome — read console/network errors, inspect the rendered DOM — which is exactly the loop you burn time on when a Highcharts render or Handlebars→Chromium PDF looks wrong.

```
claude mcp add chrome-devtools -- npx chrome-devtools-mcp@latest
```

Then ask Claude Code to open your PDF-generation preview URL and diagnose a layout/render bug end-to-end instead of guessing from screenshots. Repo: [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp). *(A stack-native complement to 07-13's context-cost audit and 07-15's PR-security drill — do those too if you haven't.)*
