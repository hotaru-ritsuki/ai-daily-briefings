## 8. 🎯 One thing to try today (≤30 min)

**Audit your MCP config for unredacted secrets and turn on the OTel resource-label pipe.** v2.1.161 makes both a 10-minute job.

```bash
npm update -g @anthropic-ai/claude-code && claude --version   # expect 2.1.161

# 1. Re-print MCP config — credentials now redacted, ${VAR} not expanded.
claude mcp list
claude mcp get <one-server-name>

# 2. Sweep recent transcripts for previously-leaked secrets:
rg -i 'sk-[A-Za-z0-9]{20,}|ghp_[A-Za-z0-9]{20,}|xox[abprs]-' ~/.claude/transcripts/ 2>/dev/null

# 3. Turn on team/repo labels on metrics:
export OTEL_RESOURCE_ATTRIBUTES="team=fe-migration,repo=$(basename "$PWD"),branch=$(git rev-parse --abbrev-ref HEAD)"
export OTEL_LOG_TOOL_DETAILS=1   # from v2.1.157
claude   # metric datapoints now carry the labels
```

If the rg sweep finds anything, that's a credential rotation event today, not next sprint. The OTel labels pay back the next time someone asks "which team is burning the Agent SDK pool" after June 15.
