## 8. 🎯 One thing to try today (≤30 min)

**Stand up a minimal, *bounded* "loop until tests pass" harness on a scratch branch — and find where it should have stopped for a human.** This is the pattern the whole week is arguing about, made concrete in 30 minutes.

```bash
git clone https://github.com/anthropics/cwc-long-running-agents
# In Claude Code, on a throwaway branch (worktree isolation is now safe post-v2.1.210):
# "Run an isolated worktree subagent that migrates ONE AngularJS .controller()
#  in src/ to an Angular component, then loops: run the unit test, read the
#  failure, fix, re-run — MAX 5 iterations — and stop if still red."
```

Watch two things: (1) does it converge, and (2) at which iteration did it start "fixing" the test instead of the code? That second observation is your comprehension-debt boundary — the exact failure mode Ronacher warns about, and the reason the bound (`MAX 5`) and a human checkpoint are non-negotiable before you scale this to a fleet with [agent-orchestrator](https://github.com/AgentWrapper/agent-orchestrator).
