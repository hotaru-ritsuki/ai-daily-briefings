### Claude Code — 2.1.145 (May 19, 21:31 UTC) ([changelog](https://code.claude.com/docs/en/changelog))

- 🆕 `/plugin` Discover/Browse shows a plugin's commands, agents, skills, hooks, MCP/LSP servers before installation.
- 🆕 `claude agents` tab title shows awaiting-input count — see when an agent needs attention without switching windows.
- 🆕 Slash command and @-mention suggestions support mouse hover/click in fullscreen mode.
- 🆕 Stop/SubagentStop hook input includes `background_tasks` and `session_crons` fields.
- 🔧 ⭐ **Read tool returns truncated first page with "PARTIAL view" notice** instead of hard-erroring when a whole-file read exceeds token limit. ⭐ *No more failures when agents try to read large generated files.*
- 🐛 Fixed MCP prompt slash commands showing raw server validation errors — now names the missing argument.
- 🐛 Fixed spinner/timer freezing after terminal resize/refocus.
- 🐛 Fixed Agent Teams teammates with non-ASCII names failing API calls (header encoding).
- 🐛 Fixed `/review` using deprecated `projectCards` GraphQL query.

- 🐛 ~5 additional Windows, voice, task-list, and PR-badge fixes.

- 🔧 Memory summaries versioned and rebuilt when stale — long-lived sessions get leaner context.

## 8. 🎯 One thing to try today (≤30 min)

**Install the push-based Angular Toolkit MCP server and let Claude Code analyze your migration codebase structurally.**

```bash
# 1. Clone and set up the Angular toolkit MCP server
git clone https://github.com/push-based/angular-toolkit-mcp.git
cd angular-toolkit-mcp
npm install && npm run build

# 2. Add to your .mcp.json in your Angular migration repo:
# {
#   "mcpServers": {
#     "angular-toolkit": {
#       "command": "node",
#       "args": ["/path/to/angular-toolkit-mcp/dist/index.js"]
#     }
#   }
# }

# 3. Restart Claude Code, then try:
#    "Use the angular-toolkit tools to analyze the component
#     structure of this project. Find components using deprecated
#     patterns and generate a migration priority list based on
#     dependency count and complexity."

# 4. Compare this structured analysis against a manual grep-based
#    discovery. The MCP server understands Angular semantics
#    (component contracts, dependency graphs, design system patterns)
#    rather than just text patterns.

# 5. Bonus: combine with the Routines feature — set up a
#    GitHub-triggered Routine that runs this analysis on every
#    PR to catch regressions in migration progress.
```

This is the highest-leverage MCP server for your specific migration. The push-based team (known for Angular performance consulting) built it to understand Angular project structure at a semantic level, not just file-pattern matching.
