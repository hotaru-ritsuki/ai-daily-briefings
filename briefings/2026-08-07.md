## 3. 📋 AI coding tool changelogs

**Claude Code — v2.1.224 (Aug 7)** ([changelog](https://code.claude.com/docs/en/changelog))
- ⭐ 🆕 Cross-session **`SendMessage`** + **`ListAgents`** — CC sessions message each other on any of your machines (macOS/Linux). *Why it matters:* the building block for hand-rolled multi-agent pipelines without a wrapper framework.
- ⭐ 🆕 `claude self-hosted-runner` — turn your own machines/containers into hosts for web/mobile/desktop sessions (Team/Enterprise). *Why it matters:* runs cloud sessions against a regulated repo on infra compliance already controls.
- ⭐ 🆕 `archive` **plugin source** — install plugins from a zip over HTTPS with optional **SHA-256 pinning**, no git/npm. *Why it matters:* a pinned, auditable install path after the summer's supply-chain scares.
- 🆕 Richer sandbox credential-masking: `extract`/`onExtractNoMatch`, **`decode: "jwt"` with `maskClaims`**, and `awsPairs`/`sigv4` re-signing — sandboxed commands get sentinel creds, not real ones.
- 🔧 Removed the **200-subagent-per-session spawn cap**; `crossSessionInbound`/`dialogExpiry` settings hold cross-session messages for approval when a target runs bypassed permissions.
- 🐛 Fixes: long project paths, sandbox filesystem deny entries, MCP tool connectivity, paste corruption, Remote Control.

- ⭐ 🆕 **Portable Agent Plugins** — install and search across local, personal, workspace, and remote plugin catalogs.
