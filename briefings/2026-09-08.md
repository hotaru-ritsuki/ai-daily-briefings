Relevant to anyone wiring Playwright specs behind auth (i.e. me).
- **Two community aggregators worth bookmarking, not memorizing.** [`rohitg00/awesome-claude-code-toolkit`](https://github.com/rohitg00/awesome-claude-code-toolkit) (2.6k★) catalogs 135 agents / 35 skills / 42 commands / 20 hooks and recently added `pro-workflow` (autonomous coding loops) and `Bouncer` (an independent quality gate that reviews with a *different* model, Gemini). ## 5. 📦 Useful repos (AI-first, ranked)

1. **[mattpocock/sandcastle](https://github.com/mattpocock/sandcastle)** — 7.9k★, MIT. TS lib to orchestrate sandboxed coding agents: `sandcastle.run()`, swappable sandbox providers (Docker/Podman/Vercel/custom), auto branch + merge. *Why:* the clean primitive for parallel/review-pipeline agent runs from a Node script, in my stack.

3. **[open-multi-agent/open-multi-agent](https://github.com/open-multi-agent/open-multi-agent)** — TS multi-agent framework that runs in your own env, gates consequential actions behind approval, and leaves a verifiable run record; "describe the goal, not the graph." *Why:* the approval-gate + audit-trail posture is exactly what unattended agent runs need.
4. **[rohitg00/awesome-claude-code-toolkit](https://github.com/rohitg00/awesome-claude-code-toolkit)** — 2.6k★. Comprehensive CC extension catalog (agents/skills/commands/hooks). *Why:* mine it for one or two patterns (`Bouncer` cross-model review gate), not wholesale.
5. **[github/spec-kit](https://github.com/github/spec-kit)** — spec-driven `specify → plan → tasks → implement` across 30+ agents including CC + Codex. *Why (incremental):* still the agent-agnostic PRD-drives-implementation toolkit; noted before, listed here as the anchor for the skills-portability theme.
6. **[langfuse/langfuse](https://github.com/langfuse/langfuse)** — OSS LLM observability: tracing, prompt versioning, LLM-as-judge. *Why:* pair with Mastra/deepeval to see what a fan-out actually did across subagents.

### 6a. AI workflows & patterns

- **[Put the files that explain a change first](https://ampcode.com/chronicle)** — Thorsten Ball / Amp. Context ordering matters: lead the agent with the files that *explain* a change (interfaces, docs, the failing test) before the files being changed, and quality jumps. Cheap, immediately applicable to how I stage context in CC. *~5 min.*
- **[6 most popular Playwright MCP servers for AI testing](https://bug0.com/blog/playwright-mcp-servers-ai-testing)** — Bug0. The friction that shaped human tooling choices (familiarity with a language, ergonomics) largely doesn't apply to agents — so the "best" language/stack calculus changes when an agent is the primary author. Opinionated, worth arguing with. *~9 min.*
