### Claude Code — 2.1.140 (May 12) ([changelog](https://code.claude.com/docs/en/changelog))

- 🔧 Agent tool `subagent_type` matching is now case- and separator-insensitive (e.g. `"Code Reviewer"` resolves to `code-reviewer`).
- 🐛 ⭐ Fixed `/goal` silently hanging when `disableAllHooks` or `allowManagedHooksOnly` is set — now shows a clear error instead of a spinner that never resolves. ⭐ *If you tried `/goal` yesterday and it seemed broken with your hook setup, this is why.*
- 🐛 Fixed `claude --bg` failing with "connection dropped mid-request" when the background service was about to idle-exit.
- 🐛 Fixed background service startup failing on machines with enterprise endpoint security (allows more time).
- 🐛 Fixed remote managed settings not retrying on 401 — now retries with a force-refreshed token.
- 🐛 Fixed settings hot-reload where symlinked settings files caused misattributed change events and spurious `ConfigChange` hooks.
- 🐛 Fixed `/loop` scheduling redundant wakeups for background tasks that already notify on completion.
- 🐛 Fixed event-loop stall on Windows when a missing executable (e.g. `gh`) triggered synchronous `where.exe` re-spawns.
- 🐛 Fixed `Read` tool failing when `offset` is passed as whitespace-padded or `+`-prefixed string.
- 🔧 Plugins now warn when a default component folder is silently ignored because `plugin.json` overrides it — shown in `/doctor` and `claude plugin list`.

A stability-focused release. No new features, but the `/goal` + hooks fix is important if you run managed hooks.

## 4. 🛠️ Claude Code & MCP ecosystem

- **CodeScene MCP Server** — open-source, runs fully locally, exposes `code_health_review` and related tools to any MCP-compatible agent. Gives Claude Code a measurable Code Health score (target: 9.5–10) plus specific maintainability issues to fix. In CodeScene's benchmarks, MCP-guided Claude Code achieved 2–5× more code health improvements than unguided attempts, and uplifted codebases consumed ~50% fewer tokens for equivalent tasks. Works with Claude Code, Cursor, Amazon Q, Gemini Code Assist, Sourcegraph Cody. Directly useful for migration work — run it against legacy AngularJS files before and after AI-assisted refactoring ([GitHub](https://github.com/codescene-oss/codescene-mcp-server), [docs](https://codescene.io/docs/developer-tools/mcp/codescene-mcp-server.html)).
- **Compound Engineering Plugin (Every Inc)** — open-source Claude Code/Codex/Cursor plugin implementing a plan → execute → review → compound loop. 26 specialized agents, 14 parallel code reviewers (security, performance, architecture). The "compound" step stores learnings (coding preferences, bug patterns, architectural decisions) in files that future sessions reference — the loop self-improves. This is the most opinionated end-to-end agent workflow plugin I've seen. The philosophy: plan and review should be 80% of engineering time, work and compounding 20% ([GitHub](https://github.com/EveryInc/compound-engineering-plugin), [Knightli overview](https://www.knightli.com/en/2026/05/01/compound-engineering-plugin-ai-coding-workflow/)).
- **Matt Pocock's skills repo** — now at 76.9K stars (+3.9K today), still the #1 reference for agent skill design. 17 production skills including `/grill-me` (requirements interview), `/to-prd`, TDD workflows, and "caveman mode" (75% token reduction). If you haven't adopted the SKILL.md format for your own migration-specific skills, this is the template ([GitHub](https://github.com/mattpocock/skills)).
- **VoltAgent/awesome-agent-skills** — curated collection of 1,000+ agent skills from official dev teams and the community, compatible with Claude Code, Codex, Gemini CLI, Cursor. Useful as a discovery layer if you're looking for domain-specific skills beyond Matt Pocock's set ([GitHub](https://github.com/VoltAgent/awesome-agent-skills)).

**Install the CodeScene MCP server and run a code-health-guided refactoring on one legacy AngularJS file.**

```bash
# 1. Install the CodeScene MCP server
npm install -g @codescene/mcp-server

# 2. Add it to your .mcp.json:
# {
#   "mcpServers": {
#     "codescene": {

#   }
# }

# 3. Restart Claude Code or use /mcp > Reconnect (hot-reload from 2.1.139+)

# 4. Ask Claude Code:
#    "Use the codescene code_health_review tool to analyze

#     Then refactor it to Angular 18 standalone component,
#     re-running code_health_review after each change until
#     the Code Health score is 9.5 or higher."

# 5. Compare the result quality vs. an unguided refactoring.
#    CodeScene's benchmarks show 2-5x more improvements with the MCP.
```
