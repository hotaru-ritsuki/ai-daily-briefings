## 8. 🎯 One thing to try today (≤30 min)

**Pin your approval posture before auto mode flips tomorrow.** In the financial-services repo, open a CC session and run `/config` to see your current mode, then set it explicitly in the repo's `.claude/settings.json` so the Aug-14 default doesn't silently change how agents act there:

```json
{ "permissions": { "defaultMode": "acceptEdits" } }
```

Use `"default"` (ask on each action) if you want to *keep* manual approvals for that repo; `"acceptEdits"`/auto only where you've decided the Trajectory numbers justify it. Two minutes now, and every future session in that repo inherits the choice instead of the org-wide default. *Alt experiment:* `npm install -g @mariozechner/pi-coding-agent` and run one real task through Pi to feel the ~3× context reduction firsthand.

## 9. 📣 Shareable angle

**Hook:** "Same model, same codebase, 2× the bill — the harness is the runtime now."
**Draft:** Databricks benchmarked coding agents on their multi-million-line repo and found the *harness* — not the model — drove a >2× cost swing at identical quality; a sub-1k-token minimal harness (Pi) sent 3× less context and still won on pass-rate. If you're optimizing your AI spend by swapping models, you're tuning the wrong layer.
