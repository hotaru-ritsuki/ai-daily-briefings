## 8. 🎯 One thing to try today (≤30 min)

**Run one real frontend component through Kimi K3 and diff it against Opus 5.** It's #1 on the Frontend Code Arena and ships an OpenAI-compatible API, so you don't need the 1.4TB of weights — hit a hosted endpoint (Moonshot's API or an aggregator like OpenRouter):

```bash
curl https://api.moonshot.ai/v1/chat/completions \
  -H "Authorization: Bearer $MOONSHOT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"kimi-k3","messages":[{"role":"user",
    "content":"Convert this AngularJS component to Angular 18 standalone with signals + NgRx: <paste one small component>"}]}'
```

1. Pick one self-contained component you've *already* migrated with Opus 5, so you have a reference answer.
2. Compare: does Kimi K3 produce idiomatic Angular 18 (standalone, `inject()`, signals) or dated patterns? Where does it hallucinate PrimeNG APIs?
3. If it's close, you've got a cheap open-weight second opinion for mechanical frontend sweeps; if not, you've confirmed Opus 5's lead with your own eval instead of a leaderboard. *(Confirm the exact model slug and endpoint against the [Kimi K3 card](https://huggingface.co/moonshotai/Kimi-K3) before relying on it.)*
