## 4. 🛠️ Claude Code & MCP ecosystem (community)

- **Bundled plugins are the new distribution unit.** [`CloudAI-X/claude-workflow-v2`](https://github.com/CloudAI-X/claude-workflow-v2) ships agents, skills, hooks and commands together (`npx install-claude-workflow-v2@latest`) — the "install one thing, get a whole workflow" pattern, versus assembling `.claude/` piecemeal.
- **Skills discovery is consolidating** into curated indexes: [`ComposioHQ/awesome-claude-skills`](https://github.com/ComposioHQ/awesome-claude-skills) and [`travisvn/awesome-claude-skills`](https://github.com/travisvn/awesome-claude-skills) are both actively maintained. Useful as a shopping list before you write a skill from scratch.
- **Cross-harness MCP auth is maturing** — Codex 0.158's OAuth-client-secret support (§3) means the same secret-bearing MCP server can now be shared cleanly between Codex and Claude Code, rather than duplicating auth wiring per tool.
- **Context-engineering has a shared vocabulary** now — write / select / compress / isolate — with converging production patterns (subagents, file-based memory, todo-list re-injection, aggressive compaction) documented across Claude Code, Cursor, Devin, Manus and Codex ([playbook](https://www.digitalapplied.com/blog/context-engineering-agent-reliability-playbook-2026)). Worth adopting the terms so your CLAUDE.md notes stay legible to teammates.
- **Agent SDK subagent pattern in the wild:** lead agent → three scoped parallel subagents (research / draft / review) with a `SubagentStop` hook gating anything that touches billable resources ([write-up](https://todatabeyond.substack.com/p/context-engineering-in-practice-building)). A clean template for your multi-agent CC runs.
