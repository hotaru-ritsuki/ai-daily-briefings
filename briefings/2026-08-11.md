## 4. 🛠️ Claude Code & MCP ecosystem (community deep dive)

- **[obra/superpowers](https://github.com/obra/superpowers) — Jesse Vincent's agentic skills framework, in the official Anthropic marketplace since Jan.** It's the most complete open multi-agent *methodology* packaged as skills: progressive-disclosure loading (Claude sees only names/descriptions until a task triggers a skill, so 20+ skills cost ~no idle context), then a signature loop of git-worktree setup → subagent-driven execution with fresh context per task → **two-stage review (spec-compliance, then quality)** ([byteiota writeup](https://byteiota.com/claude-code-superpowers-githubs-1-skills-library-for-autonomous-coding/)). This is the closest community answer to "how do I structure a real migration workflow" — worth studying against my hand-rolled `.claude/` setup even if I don't adopt it wholesale. *(Star counts quoted online range wildly ~40k–225k; treat as unreliable.)*
- **[mksglu/claude-context-mode](https://github.com/mksglu/claude-context-mode)** — the counter-move to MCP token bloat: an MCP server that sits between the agent and tool output and returns a compressed handle (Meta claim: 315KB→5.4KB). The [callei/agent-context-mode](https://github.com/callei/agent-context-mode) fork generalizes it beyond Claude Code to other harnesses. Directly targets my Playwright/GitHub-MCP-heavy sessions (§8).
- **Cross-machine session messaging is now real (v2.1.225).** With `SendMessage` able to open a thread to a named Remote Control session on another host, the orchestrator-of-sessions pattern (research box → codebase-scan box → writer box) no longer needs a bespoke harness or QM. Expect slash-command wrappers around this within days — the same wave that started when 224 shipped the same-machine version.

## 8. 🎯 One thing to try today (≤30 min)

**Install `claude-context-mode` and point it at a Playwright-heavy session.** It's the lowest-friction test of whether MCP output compression actually reclaims context on our real flows:

```bash
claude mcp add context-mode -- npx -y context-mode
```

Restart Claude Code, then run a task that pulls a Playwright accessibility snapshot or a batch of GitHub issues and watch the token accounting. If a 56KB snapshot drops to single-digit KB with no loss of what the agent needs, it earns a permanent slot in my MCP config; if the summaries lose signal the agent needs to act, you've learned that in 20 minutes. *(Bonus, if you have a 24GB+ GPU: pull `Muse-Glimmer-30B` GGUF and wire it as a local LLM-as-judge behind the sandbox — a network-free verify tier for the migration.)*
