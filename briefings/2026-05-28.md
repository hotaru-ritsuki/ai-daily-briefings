## 4. 🛠️ Claude Code & MCP ecosystem (community side)

**The Security Guidance plugin architecture is the interesting part.** A `PreToolUse` hook intercepts every `Write`/`Edit`/`MultiEdit`, runs curated regexes against the incoming string, and if any match returns a text block to the model describing the risk + recommended fix — so the *model* sees the warning and rewrites, rather than the user being blocked. Patterns include `eval()`, `new Function()`, `os.system()`, `child_process.exec()`, `pickle`, `dangerouslySetInnerHTML`, `.innerHTML=`, raw SQL concat, and hardcoded API key/secret shapes. Deterministic, zero tokens. The reusable design — *a hook that injects a structured instruction back into the model rather than blocking* — is the pattern, not the regex list. Copy it for PII regex, currency-rounding mistakes, or unsafe Spring Boot patterns in your own stack.

**`anthropics/cwc-workshops` (above)** is the second piece — `agent-decomposition/` is the cleanest public reference for the "break the monolithic prompt into a skill + code-execution tool + `callable_agents` with per-step evals" pattern that harness-engineering literature has been gesturing at since March. Read it before your next 200-line skill.

## 8. 🎯 One thing to try today

**Install the Security Guidance plugin and calibrate it on your stack.**

```bash
# Update Claude Code (need 2.1.153 for the MCP policy-bypass + cache-token fixes)
npm update -g @anthropic-ai/claude-code

# In a Claude Code session at the migration repo root:
/plugins
#  → search "security-guidance" → install (free, all plans)

# Ask Claude to refactor a recent component (any non-trivial Write/Edit).
# Then: "Intentionally write a small example using dangerouslySetInnerHTML
# and innerHTML= with user-controlled input in a sibling file, then revert."
# Confirm the plugin warns on both — that calibrates what it actually catches.
```

The interesting output is the *misses*. Find one pattern in your codebase that should be flagged (unsafe Spring Boot deserialization, raw SQL concat) and isn't, then fork the [plugin source](https://github.com/anthropics/claude-code/tree/main/plugins/security-guidance) locally with one extra regex. That's the starter project for a custom security skill for your stack. ~20 min.
