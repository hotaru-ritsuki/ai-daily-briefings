### Claude Code — 2.1.141 (May 13) ([changelog](https://code.claude.com/docs/en/changelog))

- 🆕 ⭐ **`terminalSequence` field in hook JSON output** — hooks can emit desktop notifications, window titles, and bells without a controlling terminal. ⭐ *Wire this into PostToolUse hooks for migration tasks: get a desktop ping when a long refactoring completes.*
- 🆕 ⭐ **Background agents via `/bg` or `←←` now preserve the current permission mode** instead of reverting to default. ⭐ *No more discovering your background migration agent stalled on a permission prompt because it dropped out of Auto Mode.*
- 🆕 `CLAUDE_CODE_PLUGIN_PREFER_HTTPS` env var — clones plugin sources over HTTPS instead of SSH.
- 🆕 `ANTHROPIC_WORKSPACE_ID` env var — scopes federated tokens to a specific workspace.
- 🆕 `claude agents --cwd <path>` — scope the session list to a directory.
- 🆕 Rewind menu: "Summarize up to here" compresses earlier context while keeping recent turns intact.
- 🆕 Agents that finish work but leave a background shell running now move to Completed in Agent View.
- 🔧 Spinner warms to amber after 10s of thinking — visual feedback that Claude is still working.
- 🔧 ⭐ Bedrock `awsCredentialExport` now always runs when configured (was skipped when ambient credentials resolved). ⭐ *Fixes cross-account access setups.*
- 🐛 Fixed background side-queries sending unavailable Haiku model ID on Bedrock/Vertex/Foundry.
- 🐛 Fixed `/model` in one session silently changing autocompact threshold in other sessions.
- 🐛 ⭐ Fixed markdown tables with cell wrapping falling back to vertical layout (regression from 2.1.136). ⭐ *Tables render as bordered grids again.*
- 🐛 Fixed `Ctrl+C` not interrupting a running turn while in vim INSERT/VISUAL mode.
- 🐛 Fixed alternative submit keybindings (`meta+enter`, `ctrl+enter`) not working when `enter` is rebound.
- 🐛 Fixed Remote Control MCP connectors failing with 401 when worker session token rotated.
- 🐛 ~25 additional UI, keyboard, plugin, and stability fixes.
