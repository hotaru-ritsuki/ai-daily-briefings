## 4. 🛠️ Claude Code & MCP ecosystem (community)

- **Tool Search lazy-loading** is the sleeper feature — Claude Code's MCP client only pulls schemas for tools it needs, cutting tool-description context ~95% and making 10+ server setups realistic ([Prompt Shelf](https://thepromptshelf.dev/blog/claude-code-mcp-setup-guide/)).
- **Playwright CLI vs MCP**: Microsoft shipped `@playwright/cli` as a lower-token companion to `playwright-mcp` — ~27k tokens for a task vs ~114k via MCP, ~4× cheaper ([Bug0](https://bug0.com/blog/playwright-mcp-changes-ai-testing-2026)). Relevant for visual-regression/LLM-judge flows.
- **Playwright Test Agents** (planner / generator / healer) are now first-class in the docs ([Playwright](https://playwright.dev/docs/test-agents)).
- **Spring AI 2.0 M3** (Mar 17) merged MCP into core with first-class annotations — Spring Boot services can be both MCP client and server without a third-party adapter ([Spring blog](https://spring.io/blog/2026/04/15/spring-ai-session-management/)). Directly relevant to your Kafka + Spring stack.
- **[`zilliztech/claude-context`](https://github.com/zilliztech/claude-context)** — code-search MCP that turns a full codebase into retrievable context instead of blind grep.
- **[`steipete/claude-code-mcp`](https://github.com/steipete/claude-code-mcp)** — Claude Code wrapped as a one-shot MCP, so agents in other clients can delegate to it.
- **Subagent concurrency** is now capped at 10 in 2.1.x ([alexop.dev](https://alexop.dev/posts/claude-code-customization-guide-claudemd-skills-subagents/)) — worth redesigning fan-outs around that ceiling.
