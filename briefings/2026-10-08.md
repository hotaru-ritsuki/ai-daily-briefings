## 4. 🛠️ Claude Code & MCP ecosystem (community deep-dive)

- **[dzhng/jevgrep](https://github.com/dzhng/jevgrep)** ships a built-in *skill* so the agent knows when to call `jg` — a clean "retrieval-as-a-skill" example: output is formatted for agents, not humans, and relevance is judged by a small model (Jev) across folders/files/declarations using Tree-sitter WASM grammars ([writeup](https://pyshine.com/Jevgrep-Find-Code-By-Asking-What-It-Does/)). Pairs with **[itsmostafa/typesafe-mcp](https://github.com/itsmostafa/typesafe-mcp)**, an MCP connector exposing the same cheap Jev/open-weight eval models to any agent.
- **MCP protocol — stateless RC (2026):** removes the `initialize` handshake and `Mcp-Session-Id` header, making MCP stateless at the protocol layer so servers no longer need sticky routing ([innvesti summary](https://innvesti.com/reports/mcp-stateless-rc-2026-agent-developers/)). Simplifies hosting remote MCP servers behind a load balancer — track against the official spec.
- **Database/browser MCP:** Google's **AlloyDB** server (agents list tables, run queries, inspect *query plans*) and **Chrome DevTools MCP** (Console/Network/Performance) are the most-cited newer dev-tooling servers this cycle ([Builder.io roundup](https://www.builder.io/blog/best-mcp-servers-2026)) — the AlloyDB one lets an agent reason over plans instead of guessing at indexes.
- **Spec-driven configs:** **[gotalab/cc-sdd](https://github.com/gotalab/cc-sdd)** (TS) packages a spec-driven workflow for CC/Codex/OpenCode, and **[RajdeepDevelopment/smoke-monkey-harness](https://github.com/RajdeepDevelopment/smoke-monkey-harness)** (TS, Oct 3) is a 6-phase state-machine runtime with HITL permissions and an MCP server.

## 8. 🎯 One thing to try today (≤30 min)

**Wire [jevgrep](https://github.com/dzhng/jevgrep) into one repo and let an agent use it instead of blind `grep`.** Needs Node 22+ and a model-provider key. First command, in a repo you know well:

```
npx -y @dzhng/jevgrep "how are database connections created, pooled, and closed?"
```

Then install its bundled skill so Claude Code/Codex knows *when* to call `jg` on its own, and run a task that normally makes the agent thrash through files. Compare token spend against a baseline run. If the ~29% figure holds on your codebase, it's a cheap permanent win; if it doesn't, you've spent 20 minutes learning your retrieval bottleneck is elsewhere.
