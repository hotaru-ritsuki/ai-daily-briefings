## 1. 🔥 Top 3 things I shouldn't miss today

Why it matters: your Angular + Spring Boot monorepos are exactly where test logs, GitHub payloads and MCP output balloon a session past 100k tokens — this isolates them and passes back only handles.

## 3. 📋 AI coding tool changelogs

- **`/doctor prompt-audit`** — audits CLAUDE.md/prompts for older-model patterns. 🆕 ⭐ Run it post-Opus-5.5 (see §1/§8).

- **MCP reliability batch** — HTTP 404 from stateless remote servers no longer bricks the server for the rest of the session; stdio servers no longer left running after exit; progress notifications no longer dropped during long background tools. 🐛 ⭐ These are the flaky-MCP failure modes that bite long sessions.

- **Reverted** 2.1.282's reservation of the `claude-ai` name for skills/commands. ⚠️ (behaviour revert — re-check any skill you renamed around it.)
- Also: `/context` now counts MCP server instructions; SDK sessions no longer lose deferred tool calls when a turn ends early; artifact watching auto-ends after 3.5h idle; Windows PowerShell dangerous-deletion guard. 🐛

## 4. 🛠️ Claude Code & MCP ecosystem (community)

- **[`mksglu/context-mode`](https://github.com/mksglu/context-mode)** is the headline: an MCP + hooks layer that keeps raw tool output (test logs, DOM snapshots, GitHub payloads, scraped pages) out of context, indexes events into FTS5 for BM25 retrieval on compaction, and enforces consistent routing across **17 agent platforms**. It's the community answer to the "your MCP server is eating your context window" problem ([apideck writeup](https://www.apideck.com/blog/mcp-server-eating-context-window-cli-alternative)).
- **Official plugin directory is live**: [`anthropics/claude-plugins-official`](https://github.com/anthropics/claude-plugins-official) — a curated set of vetted CC plugins, a safer default than pulling arbitrary marketplaces given the ongoing skill supply-chain concerns.
- **Orchestration config, not just agent lists**: [`rahul5894/claude-code-orchestration-kit`](https://github.com/rahul5894/claude-code-orchestration-kit) is a drop-in CLAUDE.md + agents + commands where an expensive model plans and pinned cheaper subagents execute, with a *finder + judge* split (adversarial verification) rather than one reviewer — directly stealable for your PR-review agents.
- **Agent memory** is having a moment: [`vectorize-io/hindsight`](https://github.com/vectorize-io/hindsight) (+1.6k stars/day) gives agents persistent cross-session learning — pairs with context-mode's event store.
