### Claude Code ([source](https://code.claude.com/docs/en/changelog))

- **2.1.112 (Apr 16)** — 🐛 Fixed "claude-opus-4-7 is temporarily unavailable" for auto mode. *Hotfix for the Opus 4.7 rollout.*
- **2.1.111 (Apr 16)** — packed release:
  - 🆕 ⭐ **`xhigh` effort level** for Opus 4.7, between `high` and `max`. Available via `/effort`, `--effort`, and model picker. ⭐ *Lets you dial up reasoning for hard migration tasks without paying `max` cost.*
  - 🆕 ⭐ **`/ultrareview`** — parallel multi-agent cloud code review. No args = current branch; `/ultrareview <PR#>` = specific PR. ⭐ *Directly useful for reviewing large Angular migration PRs.*
  - 🆕 ⭐ **`/less-permission-prompts`** — scans transcripts and proposes a prioritized Bash/MCP allowlist for `.claude/settings.json`. ⭐ *Automates the tedious allow-list tuning you'd do manually.*
  - 🆕 **Auto mode GA** for Max subscribers on Opus 4.7 (no longer requires `--enable-auto-mode`).
  - 🔧 `/effort` now opens an interactive slider with arrow keys when called without arguments.
  - 🆕 **"Auto (match terminal)"** theme option in `/theme`.
  - 🔧 Plan files now named after your prompt (e.g. `fix-auth-race-snug-otter.md`) instead of random words.
  - 🔧 Read-only bash with glob patterns and `cd <dir> &&` prefix no longer trigger permission prompts.
  - 🔧 Near-miss typo correction for `claude <word>` subcommands.
  - 🔧 `Ctrl+U` clears entire input buffer; `Ctrl+Y` restores.
  - 🆕 **PowerShell tool** progressive rollout on Windows; opt in on Linux/macOS with `CLAUDE_CODE_USE_POWERSHELL_TOOL=1`.
  - 🆕 `OTEL_LOG_RAW_API_BODIES` env var for full API body logging via OpenTelemetry.
  - 🐛 Fixed LSP diagnostics from before an edit appearing after it (was causing unnecessary file re-reads).
  - 🐛 Fixed `/resume` tab-completion immediately resuming an arbitrary session.
  - 🐛 Hardened "Open in editor" against command injection from untrusted filenames.
  - ⚠️ Reverted v2.1.110 cap on non-streaming fallback retries (was causing more failures during API overload).
