### Claude Code — **v2.1.271 (Sep 14)** and **v2.1.272 (Sep 15)**

2.1.271 is a large release; the entries worth your attention:

- **⭐ 🆕 Per-command `allowed_domains` for Bash, PowerShell and Monitor in auto mode + sandboxing** — a command's required hosts are reviewed with it and opened only for it. *Why:* least-privilege egress per command — the guardrail for agents touching live/staging endpoints, and audit-friendly for regulated work.
- **⭐ 🆕 `omitClaudeMd` agent frontmatter (and `--agents` JSON)** — custom/plugin subagents can run *without* user/project/local `CLAUDE.md` (managed policy files still load). *Why:* stop bloating every subagent's context with your root `CLAUDE.md` in a big Angular/Spring monorepo — real token savings on fan-out.
- **⭐ 🔧 Dynamic workflow sizes cut** — default is now *small* on Pro; the *medium* guideline dropped 15→10 agents. *Why:* the platform is nudging toward fewer, scoped agents — align your `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS` expectations accordingly.
- **⭐ 🔧 Auto-mode subagent hand-back now goes through a dedicated call the safety classifier reviews** (instead of reviewing its last message after the fact); **skill/slash-command inline `!` shell commands now follow default-mode permission rules**, not the classifier. *Why:* if you script permissions tightly, both change what gets prompted vs. auto-run.
- **⭐ 🔧 Monitor watches always have a deadline now** (≤30 min; 10 min in `-p`) and notify to re-arm — the no-timeout `persistent` option is gone. *Why:* breaking-ish if you relied on `persistent`; long watches must re-arm.
- **🆕 Fast mode in Remote/cloud + self-hosted-runner sessions**; **🆕 `--accept-command <sha256>`** to accept exactly the plugin command a prior `--json` run showed (safer than `-y`).
- **🐛 Resume fixes that matter:** `--resume` no longer drops the 1M context window (`[1m]`) when the resumed model family differs from your default; `/resume` and `/teleport` no longer keep the *previous* conversation's file-read tracking (which had let Claude edit files the resumed session never read).
- **🐛 MCP:** fixed high CPU + repeated tool-list requests when a server spams `list_changed`; OAuth client-registration fixes; tool-search matching an MCP tool by bare name.
- **🐛 Code Review:** stopped double/triple-posting findings, and stopped re-posting a security finding a person already resolved after a later push moved its anchor.
- **🔧 Markdown files published as artifacts now render as styled document pages** (title header, doc typography, highlighted code).

**v2.1.272 (Sep 15)** — "Bug fixes and reliability improvements" only.

## 8. 🎯 One thing to try today (≤30 min)

**Slim your subagent context with the new `omitClaudeMd` frontmatter.** After `claude update` to v2.1.271+, pick one custom subagent you fan out a lot (a test-runner or reviewer) and add to its frontmatter:

```yaml
omitClaudeMd: true
```

Then run it on a real task and compare the input-token count against a run with your root `CLAUDE.md` still loading. The thing you're testing: how much of your monorepo's root `CLAUDE.md` was pure overhead for a scoped subagent that only needs its own instructions — and whether stripping it changes output quality at all. If tokens drop and quality holds, make it the default for every scoped subagent. (Managed policy files still load, so you don't lose org guardrails.) Pair it with the lower default workflow size to keep fan-out lean.
