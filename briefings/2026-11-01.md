## 8. 🎯 One thing to try today (≤30 min)
**Run a Claude-plans / Codex-implements loop in Orkas on a throwaway branch.**
1. Make sure `claude` and `codex` are installed and signed in.
2. `git clone https://github.com/Orkas-AI/Orkas.git && cd Orkas && ./run.sh` (needs Node 22.12+). Read `run.sh` first; this is an unreviewed repo.
3. In a scratch clone of a Spring Boot or Angular repo, give the commander: "Add a failing Playwright test for X, have Claude Code review the plan, and have Codex implement the fix."
4. Compare against doing the same by hand: did the commander keep one coherent plan, and how many of its to-dos did you have to correct?
Success: it saves you more coordination effort than it costs in setup. If not, you've learned what a manual `claude -p` + `codex exec` script would need to replicate.
