## 4. 🛠️ Claude Code & MCP ecosystem (community, deep dive)

- ⭐ **Codemod's MCP + Skills bundle is the standout for my stack.** `npx codemod ai` wires Codemod's [MCP server](https://docs.codemod.com/model-context-protocol) (AST analysis + codemod authoring) and a Skill/command into any agent — Claude Code, Cursor, OpenCode — so the agent *writes and runs* a reviewable codemod per transformation rather than editing files ad hoc. *Why it matters:* deterministic, reusable-across-repos migration steps with a test gate — the opposite of the "the agent silently rewrote 40 files" failure mode, and it composes with my existing verification-loop skill.
- **ACE (Agentic Context Engineering) is now open source** — a Generator/Reflector/Curator loop that treats context as an *evolving playbook* the agent updates after each task instead of a static prompt, claiming +10.6% on agent benchmarks with a smaller model ([SambaNova write-up](https://sambanova.ai/blog/ace-open-sourced-on-github); paper is [arXiv 2510.04618](https://arxiv.org/abs/2510.04618), so the *idea* predates the code drop — flagging that). A practical, provider-agnostic implementation lives at [`kayba-ai/agentic-context-engine`](https://github.com/kayba-ai/agentic-context-engine).
- **Two fresh community Claude Code toolkits worth a skim** (not vetted — pin SHAs, read before installing, per last week's supply-chain note): [`rohitg00/awesome-claude-code-toolkit`](https://github.com/rohitg00/awesome-claude-code-toolkit) (agents/skills/commands/hooks/MCP configs in one catalog) and [`alirezarezvani/claude-skills`](https://github.com/alirezarezvani/claude-skills) (~345 skills incl. an engineering/compliance/finance bundle that maps to a fintech codebase).

## 8. 🎯 One thing to try today (≤30 min)

**Point a coding agent at *one* AngularJS component via Codemod instead of free-form editing.** In a scratch branch:

```
npx codemod ai
```

This installs the Codemod MCP server + Skill into Claude Code, then ask the agent to *build a codemod* for a single narrow transformation (e.g. one `.directive()` → standalone component, or `$http` → `HttpClient` in one service) and run it with its test check. The goal isn't the migration — it's to feel the difference between a reviewable, re-runnable codemod and a 40-file silent rewrite. If it holds up, that codemod becomes a repeatable step for the real sweep. ([docs](https://docs.codemod.com/model-context-protocol))

## 9. 📣 Shareable angle

**Hook:** "AI didn't migrate my AngularJS app. A codemod it *wrote* did."

**Draft:** The failure mode of 'migrate this project' isn't that the agent is dumb — it's that free-form edits aren't reviewable or re-runnable.
