## 4. 🛠️ Claude Code & MCP ecosystem (community)

**Dynamic workflows are an architectural change, not a feature.** Until now every orchestration pattern (skills, subagents, Routines, `/goal`) had Claude in the loop turn-by-turn — context grew with every result. A *workflow* is a JS script Claude writes once and a separate runtime executes; subagent results stay in the script's memory, only the rolled-up answer reaches Claude. Same shape as LangGraph's "graph-as-program" but generated on demand. For the migration: the Bun port's three-stage shape (map lifetimes → port files in parallel → fix-loop the build) transposes directly to "map AngularJS components → port to standalone signal-based Angular → fix-loop ng build + Playwright" ([case study](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code)). Caveats: 1,000-subagent cap per workflow, Pro tier excluded, `/usage` gets a new "workflows" bucket ([MarkTechPost](https://www.marktechpost.com/2026/05/28/anthropic-ships-claude-opus-4-8-alongside-dynamic-workflows-and-cheaper-fast-mode-with-workflows-capped-at-1000-subagents/)).

**Quarkus Agent MCP** ([InfoQ](https://www.infoq.com/news/2026/05/java-news-roundup-may04-2026/)) — standalone MCP (not in-process) for managing Quarkus apps. Closest published precedent if the Spring Boot side ever wants an MCP for project ops.

## 8. 🎯 One thing to try today

**Upgrade to v2.1.156 and prototype a dynamic workflow against one feature module of the migration repo** — smallest reasonable test of whether the Bun pattern transposes to your stack.

```bash
# Upgrade — v2.1.156 fixes the Opus 4.8 thinking-block bug from 2.1.154
npm update -g @anthropic-ai/claude-code
claude --version  # confirm 2.1.156
```

Then in Claude Code, against one feature module: *"Create a dynamic workflow that (a) maps every AngularJS component and service in src/app/features/<X>/, (b) ports each to a standalone signal-based Angular 18 component with two reviewer subagents per file, and (c) runs a fix-loop driving `ng build` + the Playwright suite until both pass. Use `/effort xhigh` on Opus 4.8. Cap at 50 subagents for this test run."*

Watch `/usage` — the new "workflows" bucket shows how budget splits. The point is to find out **before** you stake a real sprint whether the Bun-style port loop survives contact with your harness (PrimeNG, NgRx, Spring Boot endpoints). If it doesn't, you find out in 30 minutes against a small module instead of a week against a big one. ([workflows docs](https://code.claude.com/docs/en/workflows))
