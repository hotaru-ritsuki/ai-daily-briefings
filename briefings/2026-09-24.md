## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns
- **[Harness Engineering: A Guide to AI Coding Agents](https://www.faros.ai/blog/harness-engineering)** (Faros) — the clearest statement of the discipline: *"anytime an agent makes a mistake, engineer a solution so it never makes that mistake again"* — usually via the harness (feedback loops, safety boundaries, verification), not the model or prompt. The framing to organise your CC + CI reliability work around. *(Published May 2026 — outside the 72h window but net-new to these briefings and squarely on-topic.) ~10 min.*
- **[AI Coding Agents Need Specs, Not Main Character Energy](https://clord.dev/blog/spec-driven-agent-workflows-2026/)** (Clord) — two portable rules: *if the agent can't restate the spec, it doesn't touch the code*, and scope tools **per phase** — read-only during discovery, scoped edits during implementation, test commands during verification, publishing only after checks pass. *(Egress to clord.dev was blocked this run — takeaway drawn from search summary, not a direct read; verify before quoting.) ~8 min.*
- **[Everything Is a Ralph Loop](https://ghuntley.com/agent/)** (Geoffrey Huntley) — the counter-intuitive pattern name-checked from the AI Engineer World's Fair stage: restart the agent against the *same* spec every iteration with a **fresh context window**, one task per loop. The apparent waste is the point — refeeding the full spec each time sidesteps the context-rot/compaction decay that quietly degrades long sessions. *~9 min.*
- **[Harness Engineering: Anatomy, Architecture, and Evolution of Coding Agents](https://arxiv.org/pdf/2609.00006)** (arXiv, Sep 2026) — a source-code study of eleven real coding-agent systems, breaking down how each wires subagents, context management, tool systems, and safety. Skim for the comparative tables; it's the empirical grounding under all the harness-engineering essays. *~20 min.*

### 6b. General AI engineering reading
- **[5 Trends That Defined AI Engineering at World's Fair 2026](https://www.latent.space/p/aiewf26trends)** (Latent Space) — the year's throughlines from practitioners who ship: harnesses/loops over model-chasing, evals as the real moat, and the shift from prompt to context to harness engineering. Good orientation piece if you only read one broad essay this week. *~12 min.*
