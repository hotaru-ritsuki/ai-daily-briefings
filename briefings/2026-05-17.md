## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns

- **"Context Engineering for Coding Agents"** — [Martin Fowler](https://martinfowler.com/articles/exploring-gen-ai/context-engineering-coding-agents.html). "Context is the bottleneck for coding agents now." Performance ceiling at ~1M tokens regardless of nominal window. The skill that separates 10x from 2x value is context design, not prompt tricks. ~10 min.
- **"Harness Engineering for Coding Agent Users"** — [Martin Fowler](https://martinfowler.com/articles/harness-engineering.html). The practice of building feedforward guides and feedback sensors around coding agents. Distinguishes computational controls (linters, tests) from inferential controls (LLM-based judgment) — argues both are necessary. The term "harness engineering" is gaining traction as a discipline name. ~12 min.
- **"Scaling Managed Agents: Decoupling the Brain from the Hands"** — [Anthropic Engineering (Apr 8)](https://www.anthropic.com/engineering/managed-agents). Session (append-only event log) + Harness (stateless control loop) + Sandbox (isolated execution). p50 TTFT dropped ~60%, p95 dropped 90%+. The architecture behind Claude's Managed Agents — applicable if you're building your own orchestration. ~15 min.
- **"Agentic Engineering: How Swarms of AI Agents Are Redefining Software Engineering"** — [LangChain Blog](https://www.langchain.com/blog/agentic-engineering-redefining-software-engineering). System-level collaboration over task-level execution. Reference architecture using LangGraph + LangSmith + LangMem. Proposes a transition from single-agent to multi-agent coordinated frameworks. ~10 min.
- **"What Anthropic's $200 Agent SDK Credit Means If You Run claude -p in Production"** — [DEV Community](https://dev.to/vainamoinen/what-anthropics-200-agent-sdk-credit-means-if-you-run-claude-p-in-production-ce2). Token math for common workloads, mitigation strategies (batch API, caching, effort tuning). Directly actionable if you run any `claude -p` automation. ~8 min.

### 6b. General AI engineering reading

## 8. 🎯 One thing to try today (≤30 min)

**Install the codesearch MCP server and give your migration agents semantic codebase search.**

```bash
# 1. Clone and build (requires Rust toolchain)
git clone https://github.com/flupkede/codesearch.git
cd codesearch
cargo build --release

# 2. Add to your .mcp.json in your Angular migration repo:
# {
#   "mcpServers": {
#     "codesearch": {
#       "command": "/path/to/codesearch/target/release/codesearch",
#       "args": ["--repo", "."]
#     }
#   }
# }

# 3. Start Claude Code and try:
#    "Using the codesearch tool, find all AngularJS directives
#     that use $scope.$watch and list them with their file paths.
#     Then pick the simplest one and migrate it to an Angular 18
#     standalone component using signals."

# 4. Compare: without codesearch, Claude needs you to @-mention
#    files or read directories. With it, the agent finds migration
#    targets by meaning across the entire codebase — useful for
#    AngularJS idioms that don't follow consistent naming.

# Alternative if you don't have Rust: try claude-context (Zilliz)
# pip install claude-context
```
