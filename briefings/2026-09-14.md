## 8. 🎯 One thing to try today (≤30 min)

**Bring spec-driven development to one real change with OpenSpec.** It's tool-agnostic and drives Claude Code / Codex directly, so it slots into what you already use:

```bash
npm install -g @fission-ai/openspec@latest && openspec init
```

Then, in Claude Code, propose a *delta* for one small change you were going to make anyway (a component refactor, a Kafka consumer tweak), let it write the spec, review the spec before any code, then have the agent implement against it and verify. The payoff you're testing: does grounding the agent in a reviewable delta-spec kill the "plausible but wrong" drift on a task from *your* codebase? (Verify the exact CLI verbs against the [getting-started docs](https://github.com/Fission-AI/OpenSpec/blob/main/docs/getting-started.md) — the workflow commands are evolving.)
