## 4. 🛠️ Claude Code & MCP ecosystem (community)

## 8. 🎯 One thing to try today (≤30 min)

**Decide your auto-mode posture before a fresh session decides for you.** Since Aug 14, new Pro/Max/Team sessions default to auto mode. Spend 20 minutes hardening the boundary for the financial repo:

1. In the repo, check the current mode with `/permissions`.
2. Add explicit guardrails to `.claude/settings.json` — e.g. a `deny` entry for `Bash(git push:*)` and any prod/credential paths, and set the project default mode if you want `plan`/`default` instead of `auto`:
   ```json
   { "permissions": { "defaultMode": "plan", "deny": ["Bash(git push:*)", "Read(./.env*)"] } }
   ```
3. Run a throwaway task in auto mode and watch what the classifier waves through vs. blocks — that's your real threat model now, not the per-call prompt.
