## 4. 🛠️ Claude Code & MCP ecosystem (community, deep dive)

- **GhostSplice is the week's MCP-security story, and it's a design lesson, not just a CVE.** The attack (§1) works because a description scanner sees "just a schema," a keyword filter sees "populate the parameters," and the model's refusal never fires — *no single channel is malicious* ([The Hacker News](https://thehackernews.com/2026/08/malicious-mcp-servers-can-split.html)). The mitigation is the rule I should already enforce: **treat MCP server output as data, never as instructions**, and never let one tool's output flow unchecked into another tool's arguments. The reassuring bit for a Claude Code user: whole-sequence evaluation (Sonnet/Opus) is exactly what defeats it.
- **MCP roadmap refresh (Aug 22)** from the Core Maintainers, now under the Linux Foundation's AAIF ([blog.modelcontextprotocol.io](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/)). Three threads worth tracking: a **Server Card** working group defining `.well-known` metadata for connectionless server discovery, enterprise-auth hardening (issuer validation, issuer-bound client credentials, Client ID Metadata Documents), and a Contributor Ladder + SEP triage governance model. The auth work is the piece that decides whether I can safely register vendor MCP servers behind our SSO.
- **The "codemode" pattern is spreading to Claude Code.** [`janwilmake/agent-codemode`](https://github.com/janwilmake/agent-codemode) lets scripts the agent writes call your *already-connected* MCP servers directly (no extra auth), cutting per-tool token overhead versus round-tripping every call through the tool schema — the same token-efficiency argument that pushed Playwright-as-CLI over Playwright-MCP.
- **Cross-model subagents without an API key:** [`Sateezg/codex-bridge`](https://github.com/Sateezg/codex-bridge) (~250★) exposes GPT-5 subagents (and image gen) *inside* Claude Code via an existing Codex CLI login. A concrete pattern for the plan-on-Claude / execute-on-GPT split, minus a second key to rotate.
- **The anti-slop skill wave keeps growing** — output-style/prompt-contract "routines" aimed at what agents over-produce: [`alexgreensh/attention-span`](https://github.com/alexgreensh/attention-span) (~850★, terse output styles), [`wanshuiyin/HERO-Anti-OverDefense`](https://github.com/wanshuiyin/HERO-Anti-OverDefense) (~307★, a cross-harness contract targeting over-engineering: needless hashing, edge-case bloat, overbuild), and [`UditAkhourii/neuroarxiv`](https://github.com/UditAkhourii/neuroarxiv) (~393★, forces an arXiv prior-art check before coding from scratch). Cheap to lift into a `.claude/` output style for migration work.
- **Session observability:** [`furkankly/zoetrope`](https://github.com/furkankly/zoetrope) (~241★, Rust) renders a live Claude Code session as a flow graph in the terminal or browser — useful for auditing what a long unattended run actually did.

## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns

- **[More than just code review](https://simonwillison.net/2026/Aug/22/more-than-just-code-review/)** — Simon Willison, Aug 22 (~5 min). The productive coding-agent skill is confidently *instructing* a change and then *verifying* it landed — via tests and tooling, not line-by-line reading. *Takeaway:* invest in the verification harness, not the eyeball.
- **[Fast and Hard Code](https://lucumr.pocoo.org/2026/8/22/fast-hard-code/)** — Armin Ronacher, Aug 22 (~8 min). Once agents write the code, language *familiarity* stops gating the choice — so selection shifts toward performance and what the agent generates well; he's seeing people ship Rust they'd never have picked. *Takeaway:* re-weigh "use the language the team knows" for agent-heavy work.
- **[Maximizing the value of your Claude Code sessions](https://claude.com/blog/maximizing-the-value-of-your-claude-code-sessions)** — Anthropic, Aug 14 (~6 min). Six context-hygiene tactics: `/clear` between tasks, set model + effort *up front* (mid-session changes bust the prompt cache), `@`-mention files, quiet noisy commands, audit startup payload with `/context`, `/compact` before stepping away. *Takeaway:* treat a session as a token budget — directly cuts cost on my unattended runs.
- **[Evals Skills for Coding Agents](https://hamel.dev/blog/posts/evals-skills/)** — Hamel Husain & Shreya Shankar, updated Aug 15 (~10 min). A packaged set of eval "skills" that brings measurement discipline into coding-agent workflows instead of vibe-checking output. *Takeaway:* pairs with `microsoft/waza` (§5) for skill quality.
- **[smolmachines: a sandbox for untrusted agent code](https://simonwillison.net/2026/Aug/19/smolmachines-untrusted-sandbox/)** — Simon Willison, Aug 19 (~7 min). First-hand: had Claude Code stress-test a hardware-isolated sandbox (no network, CPU/RAM/timeout caps, read-only mounts) for running agent-generated code — ~0.6–1.5s cold, ~50ms warm. *Takeaway:* concrete option for hardening AI-in-CI execution.

### 6b. General AI engineering reading

- **[Don't classify. Hallucinate!](https://simonwillison.net/2026/Aug/14/dont-classify-hallucinate/)** — Simon Willison, Aug 14 (~5 min). Instead of forcing a model to classify against a fixed vocabulary, let it freely generate tags, then resolve them to your real taxonomy via vector nearest-match. *Takeaway:* a reusable, counterintuitive pattern for messy extraction/tagging tasks.

## 9. 📣 Shareable angle
