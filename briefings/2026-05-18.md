## 4. 🛠️ Claude Code & MCP ecosystem

- **Codegraph — pre-indexed code knowledge graph MCP server** — parses your codebase with tree-sitter into a SQLite graph, exposes `codegraph_search`, `codegraph_callers`, `codegraph_callees`, and `codegraph_impact` tools. Agents query the graph instead of scanning files with grep/glob/Read. ~3.6K stars, npm-installable (`@colbymchenry/codegraph`). For a large Angular migration, this eliminates the token-heavy discovery phase. The `codegraph_impact` tool is particularly useful before migrating a directive — it shows exactly what depends on it ([GitHub](https://github.com/colbymchenry/codegraph)).
- **CLI-Anything (HKUDS)** — ~36K stars, trending. Makes any GUI software agent-controllable through auto-generated structured CLIs. Plugin creates CLI wrappers for apps (GIMP, Blender, LibreOffice, OBS Studio, Kdenlive) with 1,100+ passing tests. All skills installable via `npx skills add`. The pattern — "give agents CLI access to non-API software" — is relevant if your workflow involves desktop tools that lack programmatic interfaces ([GitHub](https://github.com/HKUDS/CLI-Anything)).
- **Tech Leads Club agent-skills** — ~3.7K stars, trending. Security-first skill registry: 100% open source, static analysis in CI, immutable integrity via lockfiles and content hashing, human-curated prompts. Addresses a real gap — 13%+ of marketplace skills contain critical vulnerabilities per Adversa AI's audit. Supports Claude Code, Cursor, Copilot, Windsurf, Cline. Includes a spec-driven development skill (`tlc-spec-driven`) ([GitHub](https://github.com/tech-leads-club/agent-skills)).
- **Codex mobile changes the multi-tool evaluation story** — with Codex now monitorable from your phone and Claude Code manageable from Agent View on desktop, you can genuinely run both tools on different tasks simultaneously. The Remote SSH GA means Codex connects to the same dev environments Claude Code uses. For migration work, the practical test is: dispatch a directive migration to each tool, compare output quality and token cost.

## 8. 🎯 One thing to try today (≤30 min)

**Install Codegraph and give Claude Code a structural map of your migration codebase.**

```bash
# 1. Install globally
npm install -g @colbymchenry/codegraph

# 2. Index your codebase (runs tree-sitter, builds SQLite graph)
codegraph index .

# 3. Add to your .mcp.json:
# {
#   "mcpServers": {
#     "codegraph": {
#       "command": "codegraph",
#       "args": ["mcp"]
#     }
#   }
# }

# 4. Restart Claude Code or /mcp > Reconnect

# 5. Test it — ask Claude Code:
#    "Use codegraph_search to find all AngularJS directives in this
#     codebase. Then use codegraph_callers to show me which components
#     depend on the user-profile directive. Finally, use codegraph_impact
#     to check what would be affected if I migrated it."

# 6. Compare token usage vs. the same question without codegraph.
#    The agent should skip the usual grep/glob/Read discovery loop
#    and go straight to answering from the graph.
```

Codegraph complements the semantic code search MCP servers covered yesterday (codesearch, claude-context, Elastic) — those find code by meaning, Codegraph maps structural relationships (who calls what, what depends on what). For migration work, `codegraph_impact` before starting and `codegraph_callers` to trace dependencies are the high-value tools.

## 9. 📣 Shareable angle

**Hook:** "Your AI coding agent spends most of its tokens just figuring out where things are."

**Draft:** In benchmarks, Claude Code without a code knowledge graph spent the majority of tool calls on discovery — find, ls, grep, Read — before it could even start answering the actual question. With Codegraph's MCP server (tree-sitter parsing into a queryable SQLite graph), the same question took one graph query. For large codebases, the token savings are dramatic and the answer quality improves because the agent works from structural relationships, not file scanning. If you're running AI agents on anything bigger than a toy repo, giving them a pre-indexed map of the code is the highest-ROI optimization available right now.
