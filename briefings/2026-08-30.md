- ⭐ 🆕 **Extensions can inspect/replace MCP tool results before the model sees them** — programmatic interception of tool output. *Why it matters:* the hook-style control you have in CC, now in Codex; use it to redact/sanitize or shrink verbose MCP responses.
- 🆕 **Configurable grace period for discovering tools from optional MCP servers** — slow/optional servers no longer block session start on a fixed timeout.
- 🔧 **`/cd` no longer reduces sandbox protections** — permission profiles now hold for the whole TUI session (previously a directory change could quietly weaken isolation).
- 🔧 **Nested subagent token usage now counts toward the parent goal's budget** — accurate accounting for fan-out workflows.
- 🐛 **Guardian classifications no longer authorize actions after a permission change** — closes a stale-authorization gap.

## 4. 🛠️ Claude Code & MCP ecosystem (community)

- **Codex's new MCP-result interception spotlights a gap in community MCP proxies.** Most MCP-middleware today wraps *servers*; harness-level result rewriting (redaction, truncation, PII scrubbing) is now a first-class Codex extension point. Worth watching whether CC formalizes the same beyond `PostToolUse`.
- **`obra/superpowers` remains the reference skills framework** ([repo](https://github.com/obra/superpowers), ~41k★ per July listings) — composable skills (brainstorm → plan → worktree → TDD → review) that auto-trigger without being named. Companion [`superpowers-marketplace`](https://github.com/obra/superpowers-marketplace) and experimental [`superpowers-lab`](https://github.com/obra/superpowers-lab) track new techniques.
- **`trace-mcp`** ([repo](https://github.com/nikolai-vysotskyi/trace-mcp)) — an MCP server for CC *and* Codex that claims "one tool call replaces ~42 minutes of agent exploration" by giving the agent a code-trace instead of blind file reads. Relevant for your Spring Boot/monorepo work.
- **Subagent depth is now a documented production parameter** — the [Totalum playbook](https://www.totalum.app/blog/claude-code-subagents-totalum) notes CC caps nested subagents at depth 5 and can fan out tens–hundreds via Dynamic Workflows; use subagents primarily for *context control* (fresh window for search/summarize), not just parallelism.
- **`webpro255/awesome-ai-agent-attacks`** ([repo](https://github.com/webpro255/awesome-ai-agent-attacks)) — a dated, sourced timeline of real agent/MCP security incidents. Useful reference before you wire a new MCP server into a regulated codebase.
