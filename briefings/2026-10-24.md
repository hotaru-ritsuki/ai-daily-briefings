## 🎯 8. One thing to try today (≤30 min)

**Add an Anthropic-style "disprove it" verifier to your PR review.** Install Cloudflare's skill in a throwaway branch of a Spring Boot or Angular repo and read how it splits hunter and verifier:

```bash
npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit
```

Then run it on one module and compare findings before vs after the verifier phase. Note how many get dropped as false positives — that ratio tells you if the pattern is worth copying into your own `.claude/agents/` reviewer. Pair with the Anthropic essay's warning that adversarial review over-adds defensive checks: grade the output for noise.
