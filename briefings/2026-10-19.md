## 🎯 8. One thing to try today (≤30 min)

1. Pick a rule you currently ask the model to follow (e.g. "never edit `*.generated.ts`" or "run `ng lint` before finishing").
2. Add a `PreToolUse` hook in `.claude/settings.json` for `Edit|Write` that runs a small script exiting non-zero (exit code 2 blocks and feeds stderr back to the model) on matching paths.
3. First command: `claude` then `/hooks` to open the hook editor; then try to make Claude violate the rule.
