## 8. 🎯 One thing to try today (≤30 min)

**Ask Claude Code for HTML output instead of markdown.**

```bash
# 1. Pick something complex you need explained — a tricky
#    RxJS operator chain, an NgRx state flow, a migration pattern.

# 2. Add this to your prompt:
#    "Explain this as a self-contained HTML page with interactive
#     elements, styled layout, and embedded JavaScript where helpful.
#     Output to explanation.html"

# 3. Open the file in your browser. Compare the result against
#    what you'd get from a standard markdown explanation.

# 4. Try it on a migration contract:
#    "Generate an interactive HTML page showing the AngularJS
#     directive → Angular 18 component migration for [your directive].
#     Include before/after code with syntax highlighting, a visual
#     data flow diagram using inline SVG, and clickable annotations
#     explaining each change."

# 5. If it works well, add a skill or CLAUDE.md instruction:
#    "When generating explanations or documentation, prefer
#     self-contained HTML with interactive elements over markdown."
```

This comes from Thariq Shihipar on the Claude Code team. HTML lets Claude use the full expressiveness of CSS/JS — styled tables, interactive toggles, embedded visualizations — instead of being limited to markdown's flat structure. The cost is the same tokens; the output quality is dramatically higher for complex explanations.
