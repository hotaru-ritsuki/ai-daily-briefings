## 6. 📰 Articles & essays worth reading

### 6a. AI workflows & patterns
- **[Use a lower-power model in a subagent for coding tasks](https://simonwillison.net/2026/Jul/3/)** — Simon Willison (Jul 3). A crisp operating rule: implementation rarely needs the top model, so hand it to a Sonnet/Haiku subagent with a self-contained prompt and keep judgment/review in the main loop. *Takeaway:* the cheapest quality-and-cost lever for anyone running an agent all day. ~3 min.
- **[Code Review in the Age of AI](https://addyo.substack.com/p/code-review-in-the-age-of-ai)** — Addy Osmani. AI drafts features well but errs ~75% more often on *logic* alone; the engineers shipping fast at quality are the ones who built verification systems, not faster generators. *Takeaway:* budget your agent spend on checking, not producing — pairs with §8. ~9 min.
- **[Agentic AI Weekly (Jul 8)](https://berkeleyrdi.substack.com/p/agentic-ai-weekly-berkeley-rdi-july-f9d)** — Berkeley RDI. A high-signal academic-adjacent roundup of the week's agent research and releases; better dedup than the aggregator firehose. *Takeaway:* a weekly to subscribe to for eval/memory/workflow papers without paper-hunting. ~7 min skim.
- **[The AI code review checklist that prevents the next $1M incident](https://www.the-ai-corner.com/p/ai-code-review-checklist-2026-failure-modes-prompts)** — The AI Corner. Concrete failure-mode catalog + prompts; its sharpest point is that `AGENTS.md`/instruction files *rot fast* (a Jest→Vitest migration the agent never learns about). *Takeaway:* treat agent instruction files as code with an owner and a review cadence. Aggregator-tier source, practical content. ~8 min.

## 8. 🎯 One thing to try today (≤30 min)

**Adopt Simon's lower-power-subagent split in Claude Code and measure it.** Pick a mechanical migration chore (convert one AngularJS controller to an Angular 18 component, or generate Playwright specs for one page), then:

> *"Spawn a subagent on a cheaper model (`sonnet` for real implementation, `haiku` for trivial edits) with a self-contained prompt to do this task end-to-end. When it returns, review the diff in the main loop before committing — don't accept blind."*

Do the same task once on the default model and once via the subagent split, and compare tokens + wall-clock in `/status`. You'll get a concrete read on where the cheaper tier holds up on your codebase — data you can point to when you standardize the pattern. Reference: [Willison's note](https://simonwillison.net/2026/Jul/3/).

## 9. 📣 Shareable angle

**Hook:** "The cheapest AI-coding win of 2026 isn't a better model — it's a *worse* one, used deliberately."
**Draft:** Implementation work rarely needs your top-tier model; hand it to a cheaper subagent and keep judgment, review, and synthesis in the main loop. You cut cost and, counter-intuitively, tighten quality — because you've forced a human-reviewed checkpoint between generation and commit.
