## 8. 🎯 One thing to try today (≤30 min)

**Add an "LLM-as-judge grounds every finding against the diff" pass to your review workflow.** Clone the reference implementation and read how it scores findings before they're posted:

```bash
git clone https://github.com/cassioalmeron/CodeReviewAgent && cd CodeReviewAgent
```

The pattern worth stealing: a second (stronger) model reviews each finding against the actual diff and **drops anything not genuinely grounded in it** — which also catches prompt-injection attempts before they reach a PR comment. For your Spring/PDF review pipeline this turns "the bot flagged 20 things, 6 were real" into a testable, golden-set-backed harness. ~20 min to read the eval loop and decide whether to port the judge step into your own CC `/code-review` flow.
