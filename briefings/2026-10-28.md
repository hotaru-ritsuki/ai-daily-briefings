## 3. 📋 AI coding tool changelogs (since 2026-10-27 briefing)

### Claude Code — 2.1.312 (Oct 27) ([GitHub releases](https://github.com/anthropics/claude-code/releases), [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))
- 🔧 ⭐ Prompt and agent hooks now run at most 24 at a time per session, plus 12 that have exceeded their timeout. A `timeout` under 1s counts as 1s. This matters if you fan out hooks in subagent-heavy sessions.
- 🐛 ⭐ Claude no longer clobbers a huge CLAUDE.md, rules file or `@`-included file after seeing only its start. Write now asks it to read the whole file or edit in place.
- 🐛 Per-directory and `paths:` skills are now discovered after a Bash `cd` deeper into a repo. This helps monorepos.
- 🔧 Bedrock/Vertex/Foundry/Mantle use a shorter system prompt for unrecognized model names (custom deployment names, inference-profile ARNs). Restore the full prompt with `CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0`. Relevant only if you run through a cloud provider.
- 🔧 Automatic model switch after a flagged message now covers unrecognized model names. Opt out with `CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1`.
- 🐛 A command with an invalid name no longer stops all commands loading, which previously could leave `claude -p` with no output.
- 🚫 The `claude_code.safety_event` OpenTelemetry event is no longer emitted. It was added in 2.1.307, so anyone who built a dashboard on it should drop it.
- 🆕 `oidc.user_id_claim` for the Claude apps gateway (e.g. Entra `oid`). Cloud routines also get an effort level in the model picker.

### OpenAI Codex — [0.165.0 stable (Oct 27)](https://github.com/openai/codex/releases/tag/rust-v0.165.0)
- 🆕 Built-in Google Cloud Vertex AI provider (`model_provider = "gcp"`).
- 🆕 ⭐ Reasoning effort can be changed mid-conversation by default. Memory v2 is on for fresh profiles, with import of other agents' memories.
- 🆕 Repo filter in the session picker, and directory grouping in the agent command center across linked worktrees.
- 🐛 ⭐ Remote MCP tool requests are cancelled when the local response future is dropped. Queued agent messages no longer restart work after an interrupt or a switch to Plan mode.
- 🐛 "Model not found" errors are no longer retried. A marketplace-URL validation gap that could let Git connect to a different host is closed.
- 0.166.0 alphas 1–5 followed on Oct 27–28 with no notes, so nothing to adopt.

## 8. 🎯 One thing to try today (≤30 min)
**Audit your own hook concurrency and CLAUDE.md size against the 2.1.312 changes.**
1. `claude --version` — confirm you're on 2.1.312.
2. `wc -c CLAUDE.md .claude/rules/* 2>/dev/null | sort -n | tail` — find your largest instruction files.
3. In a scratch repo, add a prompt hook with a 0.5s timeout and confirm it behaves as a 1s timeout.
4. Ask Claude to edit your largest rules file and check that it reads the whole file first.
5. If you use ECC or SkillSpector-style scanners, run the scan on your `.claude/` dir before adding any new hooks.
