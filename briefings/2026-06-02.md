## 8. 🎯 One thing to try today (≤30 min)

**Audit your `.claude/` for stale `workflow` triggers, then enable v2.1.160's new write-prompt list.**

```bash
npm update -g @anthropic-ai/claude-code && claude --version
rg -i '\b(workflow|run a workflow|do this as a workflow)\b' .claude/ CLAUDE.md
```

For each hit, decide: (a) it's prose about the concept → leave (the rename means it no longer triggers), (b) it's an intentional invocation → rename to `ultracode`, (c) it's accidental → delete. Then in a fresh session, deliberately ask Claude to edit `.npmrc` in a sandboxed test repo and confirm you get the new permission prompt. Total time: ~20 min. Net result: you've eliminated the "talking about workflows triggered a workflow" silent failure mode *and* validated that your shell-startup / build-config write gate is on.
