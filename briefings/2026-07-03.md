## 8. 🎯 One thing to try today (≤30 min)

**Steal Simon Willison's eval loop for one migration prompt.** Instead of tweaking your "convert this `$scope` controller to a signal store" prompt by vibes, build a tiny gold set and score it:

```bash
pip install dspy   # or: uv pip install dspy
```

1. Pick **5** representative AngularJS files you've already migrated *by hand* (these are your gold outputs).
2. Write a metric that checks the agent's output for the invariants that actually matter to you (no `any`, no deprecated PrimeNG imports, effect converted, tests still green).
3. Run your current prompt against the 5 inputs, score it, then let DSPy propose a revised prompt and re-score.

Even a 5-case harness will surface a concrete weakness — the way Simon found his schema-listing advice was causing retry loops — and gives you a repeatable check that catches regressions when the default model changes under you (which it just did, to Sonnet 5). ([write-up](https://simonwillison.net/2026/Jul/2/dspy-datasette-agent-prompts/))
