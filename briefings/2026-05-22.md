## 4. 🛠️ Claude Code & MCP ecosystem

**MCP Tunnels + self-hosted sandboxes — the actual story.** A lightweight gateway opens one outbound TLS connection from your network; agents call MCP tools through it as if they were public APIs, with no inbound firewall rules. Self-hosted sandboxes let the tool-execution layer run in Cloudflare Workers, Daytona, Modal, or Vercel — Anthropic still owns orchestration/context/recovery, but code and credentials stop leaving your perimeter ([Anthropic blog](https://claude.com/blog/claude-managed-agents-updates), [The New Stack](https://thenewstack.io/anthropic-mcp-tunnels-sandboxes/)). For a fintech platform, this is what makes Managed Agents pass a security review without a six-week sandbox audit.

**Microsoft now recommends Playwright CLI over Playwright MCP for coding agents.** Same browser-automation surface area, ~4× fewer tokens per session because there's no protocol round-trip overhead ([TestDino](https://testdino.com/blog/playwright-ai-ecosystem)). If you use Playwright MCP in your e2e workflow, swap the agent-facing interface to the CLI; keep MCP for interactive use.

**howborisusesclaudecode.com** scraped 89 of Boris Cherny's tips into one organized site — worktrees, plan mode, CLAUDE.md patterns, hooks, MCP integrations. Higher signal than the Threads drip ([site](https://howborisusesclaudecode.com/)).

**Routines GitHub triggers — explicit setup gotcha.** `/web-setup` from the CLI only grants clone access; GitHub-event Routines require installing the Claude GitHub App separately (the setup wizard prompts when you add the trigger). Worth knowing before debugging why your `pull_request.opened` Routine isn't firing ([Anthropic docs](https://code.claude.com/docs/en/routines)).

## 5. 📦 Useful repos

1. **[angular/angular-cli (MCP package)](https://angular.dev/ai/mcp)** — Official Angular MCP server with stable tools for generation/migration plus experimental `modernize` tool (`-E modernize`) that emits `ng generate migration` commands for decorator→signal and NgModule→standalone conversions. *Closest thing to a turn-key Angular migration assistant; downside is it expects ≥ v20.2.*
2. **[ghuntley/ralph](https://agent-wars.com/news/2026-03-15-ralph-autonomous-subagent-codebase-porting)** — Geoffrey Huntley's autonomous codebase-porting loop. Compresses test suite + source into language-agnostic markdown specs in `/specs/`, then re-implements against the specs with subagents. *Conceptually the cleanest framing of AngularJS→Angular as a spec-mediated port rather than a syntax transform.*
3. **[mattpocock/skills](https://github.com/mattpocock/skills)** — Now ~40k stars and adding ~1,600/week; the de facto TypeScript skill registry for Claude Code. *Drop-in skills for TS-heavy projects; useful baseline before authoring your own.*
4. **[anomalyco/opencode](https://github.com/anomalyco/opencode)** — Past 150K stars. Model-agnostic CLI agent with a read-only Plan Agent and Copilot partnership for auth. *Best harness for running the same migration prompt against Sonnet, GPT-5.5, and Gemini 3.5 Flash without switching CLIs.*
5. **[google/playwright-cli for agents](https://playwright.dev/docs/release-notes)** — Microsoft's official recommendation now points coding agents at the Playwright CLI (not MCP) for token efficiency. *If your Playwright suite already exists, agents can drive it through plain shell with 4× cheaper sessions.*
6. **[push-based/angular-toolkit-mcp](https://github.com/push-based/angular-toolkit-mcp)** *(repeat, still under-starred)* — semantic Angular project analysis (deprecated patterns, component contracts, design-system migration). Pairs cleanly with the official Angular MCP; this one handles AngularJS-flavored legacy that the official tool ignores.
7. **[zilliztech/claude-context](https://github.com/zilliztech/claude-context)** — Milvus-backed semantic code search as MCP. *Reasonable middle ground between full-codebase reads and grep for large multi-package monorepos.*
8. **[vercel/ai](https://github.com/vercel/ai)** — AI SDK changelog now includes `grok-build-0.1` and `gemini-3.5-flash` via AI Gateway. *If you build Angular UIs that call models directly, the unified provider interface keeps you off provider-specific SDKs.*

## 8. 🎯 One thing to try today

**Try the experimental Angular `modernize` MCP tool against a small Angular module — even though you're on 18, run it against a throwaway upgrade to v20.2 to see the migration commands it generates.**

```bash
# In a temp branch (don't commit):
ng update @angular/core @angular/cli  # bring a sample module to v20.2
npx @angular/cli mcp -E modernize     # start the experimental MCP server

# Then in Claude Code, add to .mcp.json:
# {
#   "mcpServers": {
#     "angular-modernize": {
#       "command": "npx",
#       "args": ["@angular/cli", "mcp", "-E", "modernize"]
#     }
#   }
# }

# Ask Claude: "Use the angular-modernize tools to plan a migration
#  of this module from NgModules + decorator inputs to standalone
#  components + signal-based inputs. List the exact ng generate
#  migration commands and the order to run them."
```

This is a ~30 min experiment that gives you a concrete artefact: the gap between Angular's own recommended modernization path and what you'd write by hand. Even if you can't yet land v20.2, the output is useful planning input for the next migration phase.
