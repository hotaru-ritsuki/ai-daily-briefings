## 4. 🛠️ Claude Code & MCP ecosystem (community, deep dive)

- **"File-based planning" has hardened into a named pattern this week, and the mechanism is the interesting part.** `planning-with-files` ([repo](https://github.com/OthmanAdi/planning-with-files)) isn't just "write a plan file" — it wires the plan into the harness: a `UserPromptSubmit` hook re-injects `task_plan.md` at the **start of every turn** so phase status stays in-attention as the window fills, session recovery re-reads the files from disk after `/clear`, and `--gated` adds a `Stop`-hook completion gate that only fires when *all* conditions hold (so an unfinished plan alone can't trap the loop). The author's own number: **5.0 turns to resume vs 13.3 for a raw agent.** This is the concrete, installable version of the "persist decisions outside the conversation" discipline your CLAUDE.md already gestures at.
- **Adversarial-skill packs are a small but real sub-genre.** [`Pyroxin/opinionated-claude-skills`](https://github.com/Pyroxin/opinionated-claude-skills) (9★, EPL-2.0) encodes a house philosophy — "attack your own code, verify assumptions, finish like a senior engineer" — across TDD, formal-reasoning, and language-idiom skills that deliberately push Claude out of its hedge-toward-generality default. Low stars, but the *shape* (skills that make the agent argue with itself before finishing) is worth cribbing for your review/migration skills.
- **The CC toolkit directories keep consolidating.** [`rohitg00/awesome-claude-code-toolkit`](https://github.com/rohitg00/awesome-claude-code-toolkit) (2.6k★, updated Aug 30) now indexes 135 agents / 35 skills / 42 commands / 176+ plugins / 20 hooks / 14 MCP configs. Treat these as a searchable parts bin, not a config to adopt wholesale — the skill-hygiene caveat still holds.
- **MCP-side, no major new dev-tooling server in the last 72h.** The reference E2E wiring is unchanged (Playwright MCP + Postgres MCP + GitHub MCP: drive browser → verify DB → file bug), and Playwright MCP is now auto-configured for Copilot's coding agent — a useful datapoint if you standardize your own Playwright MCP setup across harnesses.

## 7. 💼 AI in fintech

- **Inference hooks are becoming a portable DLP standard, and the vendors are integrating.** Anthropic's [inference hooks](https://claude.com/blog/claude-enterprise-inference-hooks) (beta since Aug 5) post the conversation transcript to a security server your org runs and proceed only on an allow — covering chat, Claude Code, Cowork, **and MCP/skill/plugin tool results**. For a regulated financial codebase, this is the concrete answer to "how do we let engineers use Claude without prompts/secrets leaking to the model."

## 8. 🎯 One thing to try today (≤30 min)

**Install `planning-with-files` and run one real task through it.** It's the cleanest way to test whether hook-based plan re-injection fixes the context-rot you hit on long sessions.

```
/plugin marketplace add OthmanAdi/planning-with-files
/plugin install planning-with-files@planning-with-files
```

Then start a multi-step task (a migration slice, a Playwright suite scaffold) with `/plan`, do a `/clear` mid-way, and watch whether the agent recovers its phase/progress from `task_plan.md` without you re-priming it. If it works, the `--gated` completion gate is the next knob — it blocks `Stop` only when every completion condition holds, which is exactly the "don't declare done early" guardrail for unattended runs. ([repo + docs](https://github.com/OthmanAdi/planning-with-files))
