## 3. 📋 AI coding tool changelogs

_Cutoff: entries after 2026-05-13 (v2.1.141 / Codex 0.131.0-alpha.9)._

### Claude Code — 2.1.142 (May 14) ([changelog](https://code.claude.com/docs/en/changelog))

- 🆕 ⭐ **`claude agents` dispatch flags**: `--model`, `--effort`, `--mcp-config`, `--settings`, `--plugin-dir`, `--permission-mode`, `--add-dir`, `--dangerously-skip-permissions`. ⭐ *Launch migration subtasks with specific model/effort/MCP configs from Agent View without editing global settings.*
- 🆕 ⭐ **Fast mode now uses Opus 4.7 by default** (was Opus 4.6). Override: `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1`. ⭐ *Opus 4.7's stronger vision and long-running agent stability are now the fast-mode baseline.*
- 🆕 Plugins with a root-level `SKILL.md` and no `skills/` subdirectory now surface as a skill.
- 🆕 `/plugin` details and `claude plugin details` show LSP servers a plugin provides.
- 🆕 `/web-setup` warns before replacing an existing GitHub App connection.
- 🐛 ⭐ Fixed `MCP_TOOL_TIMEOUT` not raising the per-request fetch timeout for remote HTTP/SSE MCP servers (was capped at 60s regardless). ⭐ *If your remote MCP servers were timing out despite config, this is the fix.*
- 🐛 Fixed background sessions not recognizing pre-existing git worktrees, blocking Edit.
- 🐛 ⭐ Fixed background sessions disappearing after macOS sleep/wake — daemon now detects clock jumps. ⭐ *No more losing overnight migration agents to laptop sleep.*
- 🐛 Fixed daemon not exiting cleanly after binary upgrade, causing dispatched agents to crash-loop.
- 🐛 Fixed background agents crash-looping when Chrome extension connected without a shared tab.
- 🐛 Fixed `claude agents` link clicking, editor selection (`$EDITOR`), Windows deadlock, and 256-color terminal bleed.
- 🐛 Fixed `--bg --dangerously-skip-permissions` not persisting across retire/wake.
- 🔧 Improved reactive compaction: first summarize attempt seeds from overflow size, avoiding a wasted retry.
- 🔧 Hook config error now shows "use a command-type hook" for SessionStart/Setup/SubagentStart.
- 🔧 Removed stale `/model claude-sonnet-4-20250514` suggestion from refusal messages.

claude --upgrade  # confirm 2.1.142

claude agents

# 3. Dispatch a migration task with specific config:
#    From the Agent View input, try:
#    claude agents --model opus --effort high \

#      "Migrate src/app/legacy/user-profile.directive.js

#    claude agents --model sonnet --effort medium \

# 5. The key improvement: each dispatched session gets its own
#    model, effort level, and MCP config without affecting your
#    interactive session. Previously you'd need separate terminals
