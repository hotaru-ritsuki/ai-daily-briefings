## 4. 🛠️ Claude Code & MCP ecosystem (community deep dive)

With official releases quiet, the signal this cycle is in **memory and self-evaluation patterns** — both directly relevant to your long, MCP-heavy sessions:

- **Evals as a Claude Code *skill* (Hamel Husain, [hamel.dev](https://hamel.dev/blog/posts/evals-skills/)).** Rather than bolt on an eval harness, you ship a `SKILL.md` that teaches the agent to *write and run product evals on its own output* — error analysis, then targeted assertions. This is the cleanest framing I've seen for making a coding agent judge itself inside the loop, and it drops straight into your `.claude/skills/`. Pairs with his broader stance that eval-*driven* dev (evaluators before features) over-promises ([evals FAQ](https://hamel.dev/blog/posts/evals-faq/)). See §8.
- **[thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)** — persistent cross-session memory as a plugin (Claude Code, Codex, Gemini CLI, OpenCode, Copilot). The interesting bit for you is the **three-layer MCP search**: `search` returns a compact index (~50–100 tokens/result), `timeline` gives chronological context, `get_observations` fetches full detail only for the IDs you pick (~500–1,000 tokens each) — roughly 10× token savings vs. naive injection, all in **local SQLite** (no cloud). It's a maturing project rather than brand-new, but the token-tiering design is the part worth copying even if you don't adopt the plugin.
- **[Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach)** — a CLI that lets agents search multiple web platforms **without paid search APIs**; relevant if you're wiring research subagents and don't want a per-query bill. (Trending-list star counts this week are unreliable — I'm not quoting them.)
- Context note: Anthropic's **Agent Skills open-standard** push continues ([The New Stack](https://thenewstack.io/agent-skills-anthropics-next-bid-to-define-ai-standards/)) — progressive disclosure (name/description loaded first, body only on match) is the mechanic the evals-skill above exploits.
